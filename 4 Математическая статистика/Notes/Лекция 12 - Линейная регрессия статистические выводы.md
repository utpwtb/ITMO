## 📋 本讲概览 (Обзор лекции)

本讲是线性回归的第二部分，聚焦于**统计推断**（статистические выводы）。在上一讲获得参数估计量之后，本讲补全了推断链条：估计误差方差 $\sigma^2$ → 推导估计量的精确抽样分布 → 构建置信区间 → 进行假设检验。

同时扩展到预测层面——对给定 $X_0$ 处的均值响应 $E(Y \mid X_0)$ 构造置信区间。最后说明线性模型的"线性"是对**参数**而非对 $X$，因此可以通过 $X$ 的非线性变换（多项式、对数、指数、三角等）来拟合复杂趋势，同时保持推断框架不变。

---

## 🎯 核心知识点 (Ключевые понятия)

### 知识点 1: 误差方差估计 / Оценка дисперсии ошибок

**定义 (Определение):**
> **Остаток** $e_i$ — это разность между фактическим и прогнозным значением:
> $$e_i = Y_i - \hat{Y}_i = Y_i - (\hat{\theta}_0 + \hat{\theta}_1 X_i)$$

**定理 (Теорема).** 误差方差 $\sigma^2$ 的无偏估计量为：
$$s^2 = \frac{SSE}{n-2} = \frac{\sum_{i=1}^{n} e_i^2}{n-2}$$

**中文解释:**
- 残差 $e_i$ 衡量模型对第 $i$ 个观测的预测误差
- 分母 $n-2$（而非 $n$）是因为估计 $\theta_0, \theta_1$ 时"消耗"了 2 个自由度
- 可以证明 $E(SSE) = (n-2)\sigma^2$，因此 $E(s^2) = \sigma^2$（无偏）

> Заметим, что остатки зависят от $\hat{\theta}_0, \hat{\theta}_1$, которые сами вычисляются по тем же данным. При вычислении оценок МНК мы «потратили» 2 степени свободы.

---

### 知识点 2: 估计量的抽样分布 / Выборочные распределения оценок

**定理 (Теорема).** 在假设 (1)–(5)（含误差正态性）下：
$$\hat{\theta}_1 \sim N\left(\theta_1, \frac{\sigma^2}{S_{xx}}\right), \quad \hat{\theta}_0 \sim N\left(\theta_0, \sigma^2\left(\frac{1}{n} + \frac{\bar{X}^2}{S_{xx}}\right)\right)$$

где $S_{xx} = \sum_{i=1}^{n} (X_i - \bar{X})^2$

**推导思路 (Идея доказательства):**
- $\hat{\theta}_1 = \theta_1 + \sum w_i \varepsilon_i$，其中 $w_i = \frac{X_i - \bar{X}}{S_{xx}}$
- 正态随机变量的线性组合仍为正态 → $\hat{\theta}_1 \sim N$
- $\hat{\theta}_0 = \bar{Y} - \hat{\theta}_1 \bar{X} = \theta_0 + \bar{\varepsilon} - (\hat{\theta}_1 - \theta_1)\bar{X}$，也服从正态

**用 $s^2$ 替代 $\sigma^2$ 后——t 分布:**

**定理 (Теорема).** 用 $s$ 替代 $\sigma$ 后：
$$t_1 = \sqrt{S_{xx}} \cdot \frac{\hat{\theta}_1 - \theta_1}{s} \sim T_{n-2}$$
$$t_0 = \frac{\hat{\theta}_0 - \theta_0}{s\sqrt{\frac{1}{n} + \frac{\bar{X}^2}{S_{xx}}}} \sim T_{n-2}$$

**推导关键:**
- $\sqrt{S_{xx}}(\hat{\theta}_1 - \theta_1)/\sigma \sim N(0,1)$（标准正态）
- $(n-2)s^2/\sigma^2 \sim \chi^2_{n-2}$（卡方分布，因为 SSE 是正态残差的平方和）
- 两者独立，故比值 $\frac{Z}{\sqrt{V/\nu}} \sim T_{\nu}$

---

### 知识点 3: 置信区间 / Доверительные интервалы

**定理 (Теорема).** 参数 $\theta_1$ 的 $1-\alpha$ 置信区间：
$$\left( \hat{\theta}_1 - t_{1-\frac{\alpha}{2}, n-2} \cdot \frac{s}{\sqrt{S_{xx}}};\; \hat{\theta}_1 + t_{1-\frac{\alpha}{2}, n-2} \cdot \frac{s}{\sqrt{S_{xx}}} \right)$$

参数 $\theta_0$ 的 $1-\alpha$ 置信区间：
$$\left( \hat{\theta}_0 - t_{1-\frac{\alpha}{2}, n-2} \cdot s\sqrt{\frac{1}{n} + \frac{\bar{X}^2}{S_{xx}}};\; \hat{\theta}_0 + t_{1-\frac{\alpha}{2}, n-2} \cdot s\sqrt{\frac{1}{n} + \frac{\bar{X}^2}{S_{xx}}} \right)$$

**推导:** 由 $P(-t_{\alpha/2} \leq t_1 \leq t_{\alpha/2}) = 1 - \alpha$，代入 $t_1$ 的定义后解出 $\theta_1$。

---

### 知识点 4: 回归系数的假设检验 / Проверка гипотез

**检验线性关系的显著性:**
$$H_0: \theta_1 = 0 \quad \text{(没有线性关系)}$$
$$H_1: \theta_1 \neq 0 \quad \text{(存在线性关系)}$$

**检验统计量:**
$$t_{\text{набл}} = \sqrt{S_{xx}} \cdot \frac{\hat{\theta}_1}{s}$$

**决策规则:** 若 $|t_{\text{набл}}| > t_{1-\frac{\alpha}{2}, n-2}$，拒绝 $H_0$。

**直觉理解:**
- $t$ 值大 → 估计的斜率远大于其标准误 → 不太可能是纯粹的随机噪声 → 拒绝 $H_0$
- $t$ 值小 → 斜率不显著异于零 → 不能排除 $X$ 和 $Y$ 无线性关系

---

## 📝 重要定理与结论 (Теоремы и выводы)

### 均值响应的置信区间 / Доверительный интервал для среднего

**定理 (Теорема).** 在固定 $X_0$ 处，$E(Y \mid X_0)$ 的 $1-\alpha$ 置信区间为：
$$\left( \hat{Y}_0 - t_{1-\frac{\alpha}{2}, n-2} \cdot s\sqrt{\frac{1}{n} + \frac{(X_0 - \bar{X})^2}{S_{xx}}};\; \hat{Y}_0 + t_{1-\frac{\alpha}{2}, n-2} \cdot s\sqrt{\frac{1}{n} + \frac{(X_0 - \bar{X})^2}{S_{xx}}} \right)$$

где $\hat{Y}_0 = \hat{\theta}_0 + \hat{\theta}_1 X_0$

**推导关键:**
$$D(\hat{Y}_0) = D(\hat{\theta}_0 + \hat{\theta}_1 X_0) = D(\hat{\theta}_0) + X_0^2 D(\hat{\theta}_1) + 2X_0 \text{Cov}(\hat{\theta}_0, \hat{\theta}_1)$$
最终可得 $D(\hat{Y}_0) = \sigma^2\left(\frac{1}{n} + \frac{(X_0 - \bar{X})^2}{S_{xx}}\right)$。用 $s$ 替代 $\sigma$ 后，$\frac{\hat{Y}_0 - E(Y \mid X_0)}{s\sqrt{\frac{1}{n} + \frac{(X_0 - \bar{X})^2}{S_{xx}}}} \sim T_{n-2}$

**中文解释:** 置信区间在 $\bar{X}$ 附近最窄（因为 $(X_0 - \bar{X})^2$ 最小），越远离样本均值越宽——预测的精度在数据密集区最高。

### 非线性变换：保持参数线性 / Нелинейные преобразования в линейной модели

> Линейная регрессия называется линейной потому, что она линейна по **параметрам** $\theta_i$, а не обязательно по переменной $X$.

**一般形式:**
$$Y_i = \theta_1 \varphi_1(X_i) + \theta_2 \varphi_2(X_i) + \cdots + \theta_m \varphi_m(X_i) + \varepsilon_i$$

其中 $\varphi_j(X)$ 是 $X$ 的任意函数。

**常见变换:**

| 类型 | 模型 | 应用场景 |
|:--|:--|:--|
| 多项式 (Полиномиальная) | $Y = \theta_0 + \theta_1 X + \theta_2 X^2 + \theta_3 X^3$ | 物理学：电阻-温度非线性 |
| 对数 (Логарифмическая) | $Y = \theta_0 + \theta_1 \ln X$ | 经济学：学习曲线 |
| 指数/对数线性化 | $\ln Y = \theta_0 + \theta_1 X$ | 化学：Arrhenius 方程 |
| 三角 (Тригонометрическая) | $Y = \theta_0 + \theta_1 \sin X + \theta_2 \cos X$ | 信号处理 |
| 倒数 (Обратная) | $Y = \theta_0 + \theta_1 \cdot \frac{1}{X}$ | 物理学 |

**推断框架不变:**
1. OLS 估计: 最小化 $SSE = \sum (Y_i - \hat{Y}_i)^2$
2. 自由度: $n - m$（$m$ 为参数个数）
3. 置信区间: $\hat{\theta}_i \pm t_{1-\frac{\alpha}{2}, n-m} \cdot \sqrt{D(\hat{\theta}_i)}$
4. 假设检验: $H_0: \theta_i = 0$，统计量 $t = \hat{\theta}_i / \sqrt{D(\hat{\theta}_i)} \sim T_{n-m}$

> Слишком низкая степень → не уловим сложную зависимость (большое смещение). Слишком высокая степень → модель будет «ловить шум».
