## Приложение А. Теоретическая справка

### А.1. Простая линейная регрессия

Рассматривается модель
$$Y_i = \theta_0 + \theta_1 X_i + \varepsilon_i, \quad i = 1, \ldots, n,$$

где $Y_i$ — зависимая переменная, $X_i$ — объясняющая переменная, $\theta_0, \theta_1$ — неизвестные параметры, $\varepsilon_i$ — случайные ошибки.

Функцией регрессии случайной величины $Y$ на $X$ называется функция
$$m(x) = \mathrm{E}(Y \mid X = x),$$

если соответствующее условное математическое ожидание существует.

### А.2. Оценки МНК для линейной модели

Пусть
$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i, \quad \bar{y} = \frac{1}{n}\sum_{i=1}^{n} y_i,$$
$$S_{xx} = \sum_{i=1}^{n}(x_i - \bar{x})^2, \quad S_{xy} = \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y}).$$

Тогда оценки коэффициентов линейной регрессии имеют вид
$$\hat{\theta}_1 = \frac{S_{xy}}{S_{xx}}, \quad \hat{\theta}_0 = \bar{y} - \hat{\theta}_1\bar{x}.$$

Итоговое уравнение линейной регрессии:
$$\hat{y} = \hat{\theta}_0 + \hat{\theta}_1 x.$$

### А.3. Остатки и оценка дисперсии ошибок

Остаток для $i$-го наблюдения:
$$e_i = y_i - \hat{y}_i.$$

Остаточная сумма квадратов:
$$RSS = \sum_{i=1}^{n} e_i^2.$$

Несмещённая оценка дисперсии ошибки:
$$s^2 = \frac{RSS}{n-2}, \quad s = \sqrt{s^2}.$$

### А.4. Доверительные интервалы для коэффициентов линейной модели

Стандартные ошибки коэффициентов:
$$SE(\hat{\theta}_1) = \frac{s}{\sqrt{S_{xx}}},$$
$$SE(\hat{\theta}_0) = s\sqrt{\frac{1}{n} + \frac{\bar{x}^2}{S_{xx}}}.$$

Пусть $t = t_{1-\alpha/2; n-2}$ — квантиль распределения Стьюдента. Тогда 95% доверительные интервалы имеют вид
$$\hat{\theta}_1 \pm t \cdot SE(\hat{\theta}_1), \quad \hat{\theta}_0 \pm t \cdot SE(\hat{\theta}_0).$$

Если доверительный интервал для коэффициента $\theta_1$ не содержит ноль, то линейная зависимость между $x$ и $y$ считается статистически значимой на соответствующем уровне значимости.

### А.5. Проверка гипотезы о значимости коэффициента при $x$

Для линейной модели при проверке статистической значимости коэффициента наклона рассматриваются гипотезы
$$H_0: \theta_1 = 0, \quad H_1: \theta_1 \neq 0.$$

Используется статистика Стьюдента
$$t_{\text{набл}} = \frac{\hat{\theta}_1}{SE(\hat{\theta}_1)},$$

которая при справедливости гипотезы $H_0$ имеет распределение Стьюдента с $n-2$ степенями свободы.

На уровне значимости $\alpha$ гипотеза $H_0$ отвергается, если
$$|t_{\text{набл}}| > t_{1-\alpha/2; n-2}.$$

Эквивалентно, гипотеза $H_0$ отвергается тогда и только тогда, когда ноль не попадает в доверительный интервал для коэффициента $\theta_1$.

### А.6. Коэффициент детерминации

Общая сумма квадратов:
$$TSS = \sum_{i=1}^{n}(y_i - \bar{y})^2.$$

Коэффициент детерминации:
$$R^2 = 1 - \frac{RSS}{TSS}.$$

Коэффициент $R^2$ показывает, какая доля изменчивости зависимой переменной объясняется построенной моделью.

### А.7. Модели, допускаемые в РГР №3

В работе используются следующие типы моделей:

| Модель | Уравнение |
|--------|-----------|
| линейная: | $y = a + bx$ |
| квадратичная: | $y = a + bx + cx^2$ |
| показательная: | $y = ae^{bx}$ |
| степенная: | $y = ax^b$ |
| полулогарифмическая: | $y = a + b\ln x$ |
| гиперболическая: | $y = a + \dfrac{b}{x}$ |

При оценивании параметров следующие модели могут быть приведены к линейному виду:

- **показательная модель:** $\ln y = \ln a + bx$;
- **степенная модель:** $\ln y = \ln a + b\ln x$;
- **полулогарифмическая модель** уже имеет вид $y = a + b\ln x$;
- **гиперболическая модель:** $y = a + bz$, где $z = 1/x$.

> **Важно.** При использовании преобразований необходимо следить за областью допустимых значений переменных. Например, в показательной и степенной моделях должны быть корректно определены логарифмы.

### А.8. Средняя ошибка аппроксимации

В качестве одной из мер качества модели можно использовать среднюю относительную ошибку аппроксимации
$$A = \frac{100\%}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right|,$$

если значения $y_i$ ненулевые.
