\subsection{Выбор модели для прогноза}

В качестве основной модели для прогноза выбирается \textbf{степенная модель} \(y = 0.6945 \, x^{1.0402}\). Обоснование выбора:

\begin{enumerate}
    \item степенная модель имеет наименьшую среднюю ошибку аппроксимации (\(A = 16.74\%\));
    \item остатки степенной модели распределены наиболее равномерно, без выраженного систематического паттерна;
    \item показатель степени \(\hat{b} = 1.0402 \approx 1\) указывает на почти пропорциональную зависимость, что является естественным и содержательно интерпретируемым;
    \item квадратичная модель, имеющая чуть более высокий \(R^2\), содержит отрицательный квадратичный член, приводящий к убыванию прогноза при больших \(x\), что может противоречить содержательному смыслу задачи.
\end{enumerate}

Таким образом, прогнозное значение результата при \(x^* = 1207.9904\) составляет:

\[
\hat{y}(x^*) = 0.6945 \cdot (1207.9904)^{1.0402} \approx 1116.07.
\]

Интерпретация на языке предметной области: при значении фактора, равном \(1207.99\) (на 7\% выше среднего уровня), ожидаемое значение результата составляет примерно \(1116\) единиц.

\subsection{Итоговый вывод}

В рамках расчётно-графической работы №3 по регрессионным моделям (вариант A-5, \(n = 54\), \(\alpha = 0.05\)) было выполнено исследование зависимости результативного признака \(y\) от фактора \(x\) на основе реального набора данных, указанного в карточке варианта.

По диаграмме рассеяния была выдвинута гипотеза о положительной связи между переменными, близкой к линейной. Для проверки гипотезы построены три регрессионные модели: \textbf{линейная} (\(y = -24.358 + 0.9879x\)), \textbf{квадратичная} (\(y = -291.300 + 1.6032x - 0.000243x^2\)) и \textbf{степенная} (\(y = 0.6945x^{1.0402}\)). Все три модели показали умеренное качество аппроксимации (\(R^2 \approx 0.74\text{--}0.75\), \(A \approx 17\text{--}19\%\)).

Сравнение моделей по совокупности критериев (\(R^2\), RMSE, средней ошибке аппроксимации и анализу остатков) показало, что \textbf{степенная модель является предпочтительной}: она демонстрирует наиболее равномерное распределение остатков и наименьшую среднюю ошибку аппроксимации. Квадратичная модель, несмотря на чуть более высокий \(R^2\), даёт неестественное убывание при больших \(x\). Линейная модель уступает двум другим, однако она остаётся статистически значимой: коэффициент при \(x\) значимо отличается от нуля (\(t_{\text{набл}} = 12.31\), \(p < 0.0001\)), что подтверждает наличие положительной связи между \(x\) и \(y\).

Для заданного прогнозного значения \(x^* = 1207.9904\) (107\% от среднего) получен прогноз \(\hat{y} \approx 1116.07\) по степенной модели. Результаты исследования могут быть использованы для прогнозирования значений результативного признака в указанном диапазоне фактора с учётом выявленной неопределённости (гетероскедастичности при больших \(x\)).
