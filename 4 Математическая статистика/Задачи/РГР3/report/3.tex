\section{Сравнение моделей}

\subsection{Показатели качества}

Для трёх построенных моделей вычислены следующие показатели качества:

\begin{itemize}
    \item \textbf{Коэффициент детерминации} \(R^2\):
    \[
    R^2 = 1 - \frac{RSS}{TSS}, \quad
    RSS = \sum_{i=1}^{n}(y_i - \hat{y}_i)^2, \quad
    TSS = \sum_{i=1}^{n}(y_i - \bar{y})^2 = 34\,322\,573.926.
    \]

    \item \textbf{Средняя ошибка аппроксимации}:
    \[
    A = \frac{100\%}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right|.
    \]

    \item \textbf{Корень из среднеквадратичной ошибки (RMSE)}:
    \[
    RMSE = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}.
    \]
\end{itemize}

\subsection{Анализ остатков}

На рисунке~\ref{fig:residuals} представлены графики остатков для трёх моделей.

\begin{figure}[H]
\centering
\includegraphics[width=0.95\textwidth]{residuals.png}
\caption{Графики остатков \(e_i = y_i - \hat{y}_i\) для трёх моделей}
\label{fig:residuals}
\end{figure}

Анализ графиков остатков показывает:
\begin{itemize}
    \item \textbf{Линейная модель:} остатки демонстрируют систематический паттерн — при малых \(x\) остатки положительны, в средней области — отрицательны или близки к нулю, при больших \(x\) — вновь положительны и значительно возрастают по абсолютной величине. Это указывает на недостаточность линейной модели для описания данных во всём диапазоне \(x\).
    \item \textbf{Квадратичная модель:} характер остатков схож с линейной моделью — квадратичный член практически не улучшает ситуацию с систематическим отклонением.
    \item \textbf{Степенная модель:} остатки распределены более равномерно, без выраженного систематического паттерна, хотя при больших \(x\) также наблюдается увеличение разброса (гетероскедастичность).
\end{itemize}

\subsection{Выбор лучшей модели}

По совокупности критериев:
\begin{itemize}
    \item по коэффициенту детерминации \(R^2\) и RMSE наилучшей является \textbf{квадратичная} модель (\(R^2 = 0.7542\), \(RMSE = 395.27\));
    \item по средней ошибке аппроксимации \(A\) наилучшей является \textbf{степенная} модель (\(A = 16.74\%\));
    \item линейная модель уступает двум другим по всем показателям, однако различие невелико (\(R^2 = 0.7446\) против 0.7542 у лучшей).
\end{itemize}

С учётом графиков остатков, просто́ты интерпретации и устойчивости к гетероскедастичности, \textbf{степенная модель \(y = a x^b\) представляется наиболее предпочтительной}. Она имеет наименьшую среднюю ошибку аппроксимации, а её остатки распределены наиболее равномерно. Квадратичная модель, несмотря на чуть более высокий \(R^2\), содержит отрицательный квадратичный член, который приводит к неестественному убыванию прогноза при больших \(x\), что может быть сомнительным с содержательной точки зрения (если предметная область не предполагает наличия оптимума).

Линейная модель при этом остаётся полезной как наиболее простая и хорошо изученная; для неё далее будет выполнен подробный статистический анализ.
