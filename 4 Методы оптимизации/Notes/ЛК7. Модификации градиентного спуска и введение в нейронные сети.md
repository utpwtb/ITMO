### 知识点 1: 经典梯度下降的局限性 / Недостатки классического градиентного спуска

**Замечания (备注):**

> 1. Метод сходится медленно в случае оврагов. Вдоль направлений, характеризующих «дно оврага», «овражная» функция меняется незначительно, а в других направлениях, характеризующих «склон оврага», происходит резкое изменение значений функции.
> 2. Чувствителен к погрешностям вычислений (особенно сильно этот недостаток сказывается в малой окрестности точки минимума).
> 3. Может сходиться к седловой точке, «застревать в локальных минимумах», плохая сходимость для областей, где функция не является выпуклой.

**中文解释：**

经典梯度下降法存在三大核心缺陷：

1. **峡谷效应（овражная функция）**：当损失函数的等高线呈狭长椭圆形（即峡谷地形），梯度下降会在"峡谷壁"方向来回震荡，而在"谷底"方向进展缓慢。解决方法：特征缩放（масштабирование признаков）或坐标下降法（покоординатный спуск）。

2. **对计算误差敏感**：在极小值点附近的小邻域内，梯度值很小，计算误差可能导致算法在真实最小值周围振荡而无法收敛。

3. **局部极小值与鞍点**：对于非凸函数，梯度下降可能陷入局部极小值或鞍点。在高维空间中，鞍点实际上比局部极小值更普遍，这是一个严重问题。

### 知识点 2: 条件数与数据层面的问题 / Число обусловленности матрицы «объект-признак»

**定义 (Определение):**

> Число обусловленности характеризует чувствительность решения СЛАУ при малом варьировании матрицы коэффициентов (чувствительность функции к изменению аргумента — насколько может измениться значение функции при небольшом изменении аргумента). Больше число обусловленности — больше чувствительность — хуже для практики!

**中文解释：**

在数据层面，矩阵"对象-特征"的条件数（число обусловленности, condition number）反映了问题的病态程度。在线性回归中，使用伪逆矩阵（псевдообратная матрица Мура-Пенроуза）求解时，条件数 $\mu$ 通过矩阵的特征值定义：

$$
\mu = \frac{\lambda_{\max}}{\lambda_{\min}}
$$

其中 $\lambda_{\max}$ 和 $\lambda_{\min}$ 分别为最大和最小特征值。条件数越大，问题越病态，对数据中的微小扰动越敏感。

**改进条件数的方法：**

| 层面 | 方法 |
|------|------|
| **数据层面** | (1) 增加新数据，验证现有数据的质量 |
| **模型层面** | (1) 正则化（L1/L2 — 通过减小权重使得 $w_i x_i$ 对 $x_i$ 变化不那么敏感） |
| | (2) 预处理（去除特征中的噪声） |
| | (3) 使用 PCA 减少特征数量（将某些特征视为噪声） |
| | (4) 定制化的特征工程策略（特征生成 + 特征选择） |

> **Практическое замечание (实践备注):** По числу обусловленности задачи можно судить о том, насколько линии уровня вытянуты в окрестности оптимума!

### 知识点 3: 随机梯度下降与批次更新 / Стохастический градиентный спуск (SGD). Обновление по батчам

**定义 (Определение):**

> Экономим ресурсы и не переобучаемся!
>
> Повторять эпохи до выполнения критерия останова. Содержание одной эпохи:
> 1. Перемешать объекты обучающей выборки (перенумерация).
> 2. Рассматривать подвыборки из последовательно взятых $B$ объектов (батчи), подвыборки не пересекаются, обновить веса градиентным спуском для каждого батча.

**中文解释：**

SGD 的核心思想是：不使用全部训练数据计算真实梯度，而是在每个批次（батч, batch，含 $B$ 个样本）上计算梯度的近似值，据此更新参数。这样做有两个好处：
- **节省计算资源**（无需遍历全部数据即可更新一次）
- **防止过拟合**（梯度中的随机性起到了隐式正则化的作用）

**一纪元（эпоха, epoch）** 指遍历整个训练集一次。每纪元内的流程为：shuffle → 分批 → 逐批更新。

> **备注 (Замечание):** 由于只在子样本上工作，所计算的梯度只是真实梯度的近似（аппроксимация градиента），因此更新方向可能不完全准确。

### 知识点 4: 动量法 / Момент инерции (momentum)

**定义 (Определение):**

> Уменьшим эффект от градиента на текущей итерации (нужна память о предыдущих направлениях!)
>
> Физическая аналогия: мячик, который катится с горы (гора — линии уровня функции потерь, траектория мячика — ломаная последовательных приближений). Мячик не застрянет в небольшой ложбине, перелетит её в направлении низины; нужно приложить существенное усилие, чтобы поменять его траекторию. Работает: сумма сил, кинетическая энергия, импульс, движение по инерции.

**中文解释：**

动量法的物理直觉来自滚动小球：一个滚下山坡的小球不会在小的凹陷处停下，而是借助惯性"飞过"小坑洼，继续向山脚前进。在优化中，这意味着算法能够：
- 在狭长峡谷中减少垂直于谷底方向的震荡
- 越过小的局部极小值
- 在平坦区域加速前进

动量法的数学实现有三种经典变体：

#### 4.1 重球法 / Метод тяжелого шарика (метод Поляка)

**公式：**

$$
v_{k+1} = \beta v_k - \alpha \nabla f(x_k)
$$
$$
x_{k+1} = x_k + v_{k+1}
$$

其中 $\beta \in [0, 1)$ 为动量系数（通常取 0.9），$v_k$ 为"速度"（累积的梯度方向），$\alpha$ 为学习率。

#### 4.2 动量法 + 最速下降（自适应学习率）

在学习率方面引入自适应机制——随着迭代调整步长。

#### 4.3 涅斯捷罗夫加速梯度法 / Метод Нестерова (NAGD, Nesterov Accelerated Gradient Descent)

**公式：**

$$
v_{k+1} = \beta v_k - \alpha \nabla f(x_k + \beta v_k)
$$
$$
x_{k+1} = x_k + v_{k+1}
$$

**关键区别：** 标准动量在 $x_k$ 处计算梯度，而 Нестеров 法在"前瞻点" $x_k + \beta v_k$（即沿上一轮动量方向前进一步后的位置）处计算梯度。这就像"先看一步再修正"，能够更准确地预测下一步方向。

> **几何解释:** 讲义第14页的图示展示了两种方法的区别——Поляк 使用当前点的梯度（法线方向），Нестеров 使用沿动量方向前进一步后的点的梯度（法线方向）。Нестеров 的"前瞻"使其收敛更快，特别是在凸优化中具有理论上更好的收敛率。

**对 SGD 的改进效果：** 动量能有效减少 SGD 中的"寄生震荡"（паразитические составляющие），特别是在某些方向上的高频震荡会随着迭代次数增加而逐渐衰减。

### 知识点 5: Adagrad — 自适应学习率 / Adagrad (адаптивная скорость обучения)

**迭代公式 (Формулы итерационного процесса):**

$$
G_k = G_{k-1} + g_k \odot g_k
$$
$$
x_{k+1} = x_k - \frac{\alpha}{\sqrt{G_k + \varepsilon}} \odot g_k
$$

其中 $\odot$ 表示逐元素乘法（покомпонентное умножение），$g_k = \nabla f(x_k)$，$\varepsilon$ 为防止除零的小常数。

**核心思想 (Суть метода):**

- 对每个参数分量独立调整学习率
- 梯度历史平方和 $G_k$ 大的分量 → 学习率自动减小（该方向变化剧烈，需要谨慎步伐）
- 梯度历史平方和 $G_k$ 小的分量 → 学习率自动增大（该方向变化平缓，可以迈大步）
- 这引入了某种"拟牛顿"特性（квазиньютоновость），因为利用了梯度的二阶信息（通过平方近似）

**缺点：** $G_k$ 单调递增，导致学习率只减不增，在训练后期可能过小，使学习过早停滞。

---

### 知识点 6: RMSProp — 指数滑动平均的自适应学习率 / RMSProp (сглаживание в окне)

**迭代公式 (Формулы итерационного процесса):**

$$
G_k = \rho G_{k-1} + (1 - \rho) \cdot g_k \odot g_k
$$
$$
x_{k+1} = x_k - \frac{\alpha}{\sqrt{G_k + \varepsilon}} \odot g_k
$$

其中 $\rho \in [0, 1)$ 为衰减系数。

**核心思想 (Суть метода):**

与 Adagrad 的关键区别：使用**指数滑动平均（простое экспоненциальное сглаживание）**而非累加和来计算 $G_k$。这意味着：
- 旧的梯度平方信息会指数衰减，最终被"遗忘"
- 学习率的衰减不会像 Adagrad 那样快
- 实际上是一个"滑动窗口"内的梯度平方统计

> **Эмпирическое замечание (经验备注):** 速度 обучения уменьшается не так быстро, как для Adagrad, потому считается более предпочтительным.

### 知识点 7: Adam — 自适应动量估计 / Adam = ADAptive Momentum

**定义 (Определение):**

> - 1-й момент: агрегат направлений (уменьшить вклад нового вектора градиента)
> - 2-й момент: агрегат градиентов (сумма на истории) для скорости обучения (RMSProp, компенсирующий эффект для шага в направлении)
> - нормализация (bias correction — обеспечение несмещенной оценки)

**迭代公式 (Формулы итерационного процесса):**

$$
m_k = \beta_1 m_{k-1} + (1 - \beta_1) g_k \quad \text{(1-й момент — 动量项)}
$$
$$
v_k = \beta_2 v_{k-1} + (1 - \beta_2) g_k \odot g_k \quad \text{(2-й момент — RMSProp项)}
$$
$$
\hat{m}_k = \frac{m_k}{1 - \beta_1^k} \quad \text{(偏差校正)}
$$
$$
\hat{v}_k = \frac{v_k}{1 - \beta_2^k} \quad \text{(偏差校正)}
$$
$$
x_{k+1} = x_k - \frac{\alpha \cdot \hat{m}_k}{\sqrt{\hat{v}_k} + \varepsilon}
$$

**中文解释：**

Adam 是当前最流行的神经网络优化器之一，将动量法（一阶矩）和 RMSProp（二阶矩）的思想结合起来：

| 组件 | 含义 | 作用 |
|------|------|------|
| $m_k$（一阶矩） | 梯度方向的指数滑动平均 | 提供动量/惯性，平滑震荡 |
| $v_k$（二阶矩） | 梯度平方的指数滑动平均 | 自适应调整每参数的学习率 |
| $\hat{m}_k, \hat{v}_k$（偏差校正） | 对初始迭代的修正 | 保证 $m_0=0, v_0=0$ 时估计无偏 |
| $\beta_1$ | 一阶矩衰减系数 | 通常 $= 0.9$ |
| $\beta_2$ | 二阶矩衰减系数 | 通常 $= 0.99$ |

**偏差校正（Bias Correction）的必要性：**

因为 $m_0 = 0$ 且 $v_0 = 0$，在训练初期（$k$ 较小），$m_k$ 和 $v_k$ 会严重偏向零。除以 $(1 - \beta^k)$ 可以补偿这种初始偏差，使得 $m_k$ 和 $v_k$ 成为 $M(g)$ 和 $M(g^2)$ 的无偏估计（несмещённая оценка）。

**推导思路（来自讲义第19-20页）：**

展开递推式：
$$
m_k = (1 - \beta_1) \sum_{i=1}^k \beta_1^{k-i} g_i
$$

取数学期望：
$$
\mathbb{E}[m_k] = \mathbb{E}[g] \cdot (1 - \beta_1^k)
$$

因此 $\hat{m}_k = m_k / (1 - \beta_1^k)$ 的数学期望等于 $\mathbb{E}[g]$，即无偏估计。

> **Практическое замечание:** Обычно $\beta_1 = 0.9$, $\beta_2 = 0.99$. Требуется выбрать только базовую скорость обучения $\alpha$. Иногда начинают с числа Андрея Карпаты (пост 2016 года) = $3 \times 10^{-4}$.

### 知识点 8: Weight Decay（权重衰减）与 AdamW

**定义 (Определение):**

> Weight Decay (затухание весов):
> (1) ввести в функцию потерь регуляризатор со смыслом «маленький по модулю вес — это хорошо»,
> (2) на каждом шаге уменьшать вес пропорционально коэффициенту регуляризации

**中文解释：**

Weight Decay 本质上就是 **L2 正则化**在梯度下降框架中的实现：

$$
L_{\text{total}} = L_{\text{original}} + \frac{\lambda}{2} \|w\|^2
$$

每次参数更新时额外减去 $\lambda w$（权重衰减项），使得权重趋向于零。这防止权重过大，提高模型泛化能力。

**AdamW** 是 Adam 的一种重要修正：将 weight decay 从自适应学习率的计算中解耦出来，直接在权重上施加衰减，而非将其混入损失函数的梯度中。实验证明这样做的泛化效果更好。

**对比：**

| 方法 | Weight Decay 位置 |
|------|-------------------|
| L2-正则化的 Adam | 与损失梯度混合，经过自适应学习率缩放 |
| AdamW | 直接作用于权重，不受自适应学习率影响 |

### 知识点 10: МакКаллок-Питтс 神经元模型 / Модель МакКаллока-Питтса

**定义 (Определение):**

> Нелинейность от линейной комбинации над входом.

**数学表示：**

$$
y = \varphi\left(\sum_{i=1}^{n} w_i x_i + b\right)
$$

其中：
- $x_i$ — 输入信号（входы）
- $w_i$ — 权重（веса, обучаемые параметры）
- $b$ — 偏置（смещение, bias）
- $\varphi(\cdot)$ — 激活函数（функция активации, нелинейность）
- $y$ — 输出（выход нейрона）

**中文解释：**

神经元模型的核心是两个操作的组合：(1) 输入的线性组合（взвешенная сумма），(2) 经过非线性激活函数的变换。如果没有非线性激活函数，多层网络将等效于单层线性模型，无法学习复杂的非线性映射。

---

### 知识点 11: 激活函数 / Функции активации

讲义中重点介绍了以下激活函数：

| 函数 | 公式 | 特点 |
|------|------|------|
| **Sigmoid** | $\sigma(x) = \frac{1}{1 + e^{-x}}$ | 输出 $(0, 1)$，有梯度消失问题 |
| **Tanh** | $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 输出 $(-1, 1)$，零中心，仍有梯度消失 |
| **ReLU** | $\text{ReLU}(x) = \max(0, x)$ | 计算简单，缓解梯度消失，但存在"死亡神经元"问题 |
| **Leaky ReLU** | $\text{LeakyReLU}(x) = \max(\alpha x, x)$, $\alpha \ll 1$ | 解决 ReLU 在负区间的"死亡"问题，保留微小梯度 |

**中文解释：**

- **ReLU (Rectified Linear Unit)** 是目前最常用的激活函数，因其简单高效且能缓解深层网络的梯度消失问题。
- ReLU 的缺点是当输入为负时梯度为零，导致"死亡神经元"（Dying ReLU）——对应权重不再更新。
- **Leaky ReLU** 通过引入一个小的负斜率 $\alpha$（如 0.01）解决此问题，使负区间仍有微小梯度。

### 知识点 12: 全连接层与多层感知机 / Fully Connected Layer (FC). Multilayer Perceptron (MLP)

**定义 (Определение):**

> 1. Нейрон текущего слоя имеет связь СО ВСЕМИ нейронами следующего слоя (Fully Connected, FC, Linear).
> 2. Первый слой (входной) не считается слоем — на рисунке ДВУХСЛОЙНЫЙ ПЕРСЕПТРОН!
> 3. Основа вычислений для слоя (для каждого нейрона): скалярное произведение (линейная комбинация) + нелинейная функция активации. Обучаемые веса — коэффициенты линейной комбинации.
> 4. Совокупность таких слоёв называется Multilayer Perceptron (MLP) — частный случай Feedforward Network (сеть прямого распространения, без циклов).

**中文解释：**

FC 层（全连接层 / полносвязный слой）具有以下关键特性：

1. **全连接性**：当前层的每个神经元与下一层的每个神经元都有连接，每条连接对应一个可学习的权重。

2. **层计数惯例**：输入层（входной слой）不计入层数——它将输入数据传递给下一层，但不执行计算。因此，讲义中图示的网络称为**两层感知机**。

3. **每层计算**：对于每个神经元，先计算输入的线性组合（скалярное произведение），再通过非线性激活函数输出。

4. **MLP 结构**：
   - 输入层 → 隐藏层(ы) → 输出层
   - 属于前馈网络（сеть прямого распространения），无循环连接
   - 权重更新通过反向传播算法（Backpropagation）完成

### 知识点 13: 卷积神经网络 / Convolutional Neural Network (CNN)

#### 13.1 卷积变换 / Преобразование «свёртка»

卷积运算本质上是**滤波器窗口内的标量积**（скалярное произведение в окне）。对于图像处理，卷积核（ядро свёртки）在图像上滑动，在每个位置计算卷积核权重与对应像素值的加权和，生成特征图（Feature Map, карта признаков）。

#### 13.2 滤波器 / Фильтр

**关键属性：**

| 属性 | 说明 |
|------|------|
| 形状 | 方阵（如 $5 \times 5$），实际为 $5 \times 5 \times C_{\text{in}}$（含所有输入通道） |
| 系数 | 可为空/非空，可训练/不可训练 |
| 偏置 weight | 通常忽略 bias 权重 |
| 操作 | 在每个通道独立进行窗口变换（如卷积） |

> **重要:** 在卷积层中，"神经元"的定义是一次完整的卷积窗口操作（对所有输入通道），产生输出特征图的一个像素值。该"神经元"并非接收整个图像作为输入——不是 FC！

#### 13.3 卷积层 / Convolutional Layer

**定义 (Определение):**

> Свёрточный слой — это совокупность свёрточных фильтров с одинаковыми размерами и разными коэффициентами, применяемых к одному изображению/псевдоизображению (Feature Map). Число каналов выходного псевдоизображения = число фильтров.

**关键要点：**

- 一个卷积层包含多个滤波器，每个滤波器有自己的一组可学习权重
- 输出通道数（число каналов Feature Map） = 滤波器个数
- 每个滤波器对输入的所有通道执行卷积，产生一个输出通道
- 可学习参数 = 所有滤波器的所有系数

> **区别于其他滤波器：** 中值滤波器（медианный фильтр）权重固定（始终取中位数），无学习参数，不用于卷积层。类似的还有 min/max/average 滤波器。

#### 13.4 池化层 / Pooling Layer (Слой пуллинга)

**核心特征：**
- 无学习参数（веса отсутствуют）
- 不属于卷积操作
- 对窗口内像素执行 max / min / average 操作
- 作用：降采样（уменьшение размерности），提取主要特征，增强平移不变性

#### 13.5 CNN 用于图像分类 / CNN для задачи классификации изображений

**典型架构：**

```
[输入图像] → [卷积层1] → [池化层] → [卷积层2] → [池化层] → ... → [Flatten] → [FC层] → [Softmax输出]
```

**关键设计：**
- 前半部分（卷积+池化）：处理"伪图像"（Feature Maps / карты признаков），提取空间特征
- Flatten：将三维特征图展平为一维向量
- 后半部分（FC 层）：处理向量，完成分类决策
- 输出层：神经元数 = 类别数，激活函数 = softmax（输出各类别的概率/分数）

**术语对照：**
- 感知图 (перцептивные карты) = 特征图 (карты признаков) = 伪图像 (псевдоизображения)

## 🔗 知识关联 (Связи знаний)

```
梯度下降法 (Лекция 6, 经典)
    │
    ├── 条件数 → 数据质量 → 正则化 (L1/L2, PCA)
    │
    ├── SGD ──→ 小批量梯度 → 计算效率 + 防止过拟合
    │     │
    │     └── 动量法 (Momentum)
    │           ├── 重球法 / Поляк (动量直接叠加)
    │           └── Нестеров (前瞻点梯度 + 动量)  → 更快收敛
    │
    ├── 自适应学习率
    │     ├── Adagrad (梯度平方累加 → 各参数独立学习率)
    │     ├── RMSProp (指数滑动平均 → 避免学习率过快衰减)
    │     └── Adam = Momentum + RMSProp + Bias Correction
    │           └── AdamW (Weight Decay 解耦) → 更好泛化
    │
    └── 神经网络 (本讲第二部分)
          ├── 神经元模型 (МакКаллок-Питтс)
          ├── 激活函数 (Sigmoid, Tanh, ReLU, Leaky ReLU)
          ├── MLP = FC 层堆叠 + 激活函数
          │     └── 反向传播 (Backpropagation, 见补充材料)
          │
          └── CNN
                ├── 卷积层 = 多个可学习滤波器
                ├── 池化层 (max/average pooling, 无参数)
                └── 分类头 (Flatten → FC → Softmax)
```
