# ⭐常用计算留数的方法总结

---

## 🔹**方法 1：直接用定义（适用于一阶极点）**

如果 (z=a) 是 **一阶极点** ：

[

\text{Res}(f,a)=\lim_{z\to a}(z-a)f(z)

]

📌 **最常用、最直接、最常考的方法**

✔ 适用：一阶极点

✖ 不适用：高阶极点或本性奇点

📌 例：

(f(z)=\frac{e^z}{z-1})

留数 = (e^1)

---

---

## 🔹**方法 2：n阶极点的导数公式（高阶极点必备）**

若 (z=a) 是  **n 阶极点** ：

[

\text{Res}(f,a)=

\frac{1}{(n-1)!}\lim_{z\to a}

\frac{d^{,n-1}}{dz^{,n-1}}

\Big[(z-a)^n f(z)\Big]

]

✔ 必用：**二阶或更高阶极点**

📌 例如：

(f(z)=\frac{1}{z^2\sin z}) 在 0 点求留数

0 为二阶极点 → 用此法。

---

---

## 🔹**方法 3：利用 Laurent 展开取系数**

展开 (f(z)) 在 (z=a) 附近的 Laurent 级数：

[

f(z)=\sum_{k=-\infty}^{\infty} c_k (z-a)^k

]

其中

[

\text{Res}(f,a)=c_{-1}

]

✔ 特别适用于函数容易展开的情况：

* (\frac{1}{1-z})
* (\frac{1}{1+z^2})
* (e^z, \sin z, \cos z)
* 幂乘组合如 (z e^z)

📌 例：

[

\frac{z}{1-z} = z(1+z+z^2+...)=z+z^2+... \Rightarrow c_{-1}=0

]

---

---

## 🔹**方法 4：分式分解法（特别适用于有理函数）**

若

[

f(z)=\frac{P(z)}{Q(z)}

]

并且 (Q(z)) 在 (a) 有简单零点（只一阶）：

[

\text{Res}(f,a) = \frac{P(a)}{Q'(a)}

]

✔ 适用：**有理函数 + 一阶极点**

📌 例：

[

\frac{2z+1}{z^2+1}

]

极点在 (z=i,-i)，

留数 = (\frac{2i+1}{2i})

---

---

## 🔹**方法 5：构造 (g(z)/(z-a)^n) 型分解**

如果能写成：

[

f(z)=\frac{g(z)}{(z-a)^n}

]

且 (g(z)) 解析

* n=1 → 一阶极点直接求：留数 = (g(a))
* n>1 → 用导数公式

✔ 实际例子很多：例如频繁出现在积分题中

---

---

## 🔹**方法 6：用已知函数的留数表/对称性**

例如

[

\text{Res}\left(\frac{1}{z},0\right)=1

]

其他能用替换的方法快速获得：

* ( \frac{1}{z-a} \Rightarrow 1 )
* ( \frac{e^{z}}{z-a} \Rightarrow e^{a} )
* ( \frac{\sin z}{(z-a)} \Rightarrow \sin a )

✔ 用于“结构像 (\frac{g(z)}{z-a})”型的题

---

---

## 🔹**方法 7：利用乘积结构**

如果

[

f(z)=g(z)h(z)

]

其中：

* (g(z)) 在 (a) 有一阶极点，
* (h(z)) 解析，

则

[

\text{Res}(f,a) = \text{Res}(g,a)\cdot h(a)

]

✔ 有时可以让一部分取极限、另一部分直接代值。

---

---

## 🔹**方法 8：利用积分（留数定理逆用）**

针对困难情况：

[

\text{Res}(f,a)=\frac{1}{2\pi i}\oint_{|z-a|=\epsilon} f(z),dz

]

✔ 理论上通用，但考试中少数情况用

✔ 多用于构造性证明，而非直接计算

---

---

# 🔥如何考试中选择方法？（超实用总结）

| 情况         | 最快方法                          |
| ------------ | --------------------------------- |
| 一阶极点     | 直接极限法 或 P/Q 分式法          |
| 高阶极点     | 导数公式                          |
| 幂级数好展开 | Laurent 展开法                    |
| 有理函数结构 | (P/Q') 法                         |
| 奇点是简单型 | 直接套结构：(\frac{g(z)}{z-a}) 型 |

---

---

# 📌一句话总记版

✔ 一阶极点 → 极限法 / (P(a)/Q'(a))

✔ n 阶极点 → 用导数公式

✔ 结构好展开 → Laurent 展开取 (1/(z-a)) 系数
