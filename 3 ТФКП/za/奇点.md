# 📌复变函数奇点分类与极点对比表

---

## ✅ **1. 概念层面对比**

| 类型     | 中文名称              | 定义                                             |
| -------- | --------------------- | ------------------------------------------------ |
| 可去奇点 | removable singularity | 函数虽在该点不定义，但可通过补定义使其解析       |
| 极点     | pole                  | 在该点函数趋于无穷（吹起来），可用有限阶负幂表示 |
| 本性奇点 | essential singularity | 行为极复杂，没有简单极限或有限阶展开形式         |

---

## ✅ **2. Laurent 级数结构比较**

| 类型           | Laurent 级数形式                                                                   | 负幂部分                       |
| -------------- | ---------------------------------------------------------------------------------- | ------------------------------ |
| 可去奇点       | (f(z)=a_0 + a_1(z-z_0)+\cdots)                                                     | **没有负幂**             |
| 极点（阶为 n） | (f(z)=\dfrac{a_{-n}}{(z-z_0)^n}+\cdots + a_{0}+\cdots)                             | **负幂有限项（到阶 n）** |
| 本性奇点       | (f(z)=\cdots +a_{-3}(z-z_0)^{-3}+a_{-2}(z-z_0)^{-2}+a_{-1}(z-z_0)^{-1}+a_0+\cdots) | **负幂无限项**           |

---

## ✅ **3. 极限行为比较**

| 类型         | 行为                                     |
| ------------ | ---------------------------------------- |
| 可去奇点     | (\lim_{z\to z_0} f(z)) 存在且有限        |
| 极点（阶 n） | (\lim_{z\to z_0}                         |
| 本性奇点     | 极限不存在、振荡复杂、值在邻域内非常密集 |

---

## ✅ **4. 留数特性**

| 类型           | 留数（Residue）                                                                                        |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 可去奇点       | 留数=0                                                                                                 |
| 一阶极点       | 留数 = (\lim_{z\to z_0} (z-z_0)f(z))                                                                   |
| n阶极点（n>1） | 留数可用导数公式： (\dfrac{1}{(n-1)!}\lim_{z\to z_0}\dfrac{d^{n-1}}{dz^{n-1}}\big[(z-z_0)^n f(z)\big]) |
| 本性奇点       | 有有限留数，但结构复杂                                                                                 |

---

## ✅ **5. 判断方式对比**

| 类型     | 判断指标                                   |
| -------- | ------------------------------------------ |
| 可去奇点 | 乘 ((z-z_0)) 不趋于无穷，且极限有限        |
| 一阶极点 | ((z-z_0)f(z)) 在 (z_0) 有极限且有限不零    |
| n阶极点  | ((z-z_0)^n f(z)) 在 (z_0) 有极限且有限非零 |
| 本性奇点 | 任意乘阶都不能去掉负幂，不出现有限阶极限   |

---

## ✅ **6. 图像/直觉理解**

| 类型     | 直觉理解                       |
| -------- | ------------------------------ |
| 可去奇点 | “洞可以补上”                 |
| 极点     | “出现垂直无穷柱状发散”       |
| 本性奇点 | “完全混乱，附近可取任意复值” |

---

## ✅ **7. 典型例子**

| 类型     | 示例函数           | 奇点位置                  |
| -------- | ------------------ | ------------------------- |
| 可去奇点 | (\frac{\sin z}{z}) | (z=0) 可补为 1            |
| 一阶极点 | (\frac{1}{z})      | (z=0)                     |
| 二阶极点 | (\frac{1}{z^2})    | (z=0)                     |
| n阶极点  | (\frac{1}{z^n})    | (z=0)                     |
| 本性奇点 | (e^{1/z})          | (z=0)（值密集逼近复平面） |

---

## ✅ **8. 这些奇点的差异总结**

| 维度             | 可去奇点   | 极点     | 本性奇点        |
| ---------------- | ---------- | -------- | --------------- |
| Laurent 负幂     | 无         | 有限个   | 无限个          |
| 行为             | 可补为解析 | 吹向无穷 | erratic / dense |
| 局部可否解析延拓 | 可以       | 不行     | 不行            |
| 例子             | sin(z)/z   | 1/(z-a)  | e^{1/z}         |

---

## 📌特别重点：**极点内部又有阶数区别**

我们再补一个关于不同阶极点的细表：

| 极点类型 | 定义                      | 判断方式                        | 例子                           |
| -------- | ------------------------- | ------------------------------- | ------------------------------ |
| 一阶极点 | 负幂只有 ((z-z_0)^{-1})   | ((z-z_0)f(z)) 有有限非零极限    | (\frac{1}{z}，\frac{e^z}{z-1}) |
| 二阶极点 | 负幂最大是 ((z-z_0)^{-2}) | ((z-z_0)^2f(z)) 有有限非零极限  | (\frac{1}{z^2})                |
| n阶极点  | 负幂最大是 ((z-z_0)^{-n}) | ((z-z_0)^n f(z)) 有有限非零极限 | (\frac{1}{z^n})                |

---

# 📌一句话记忆版本

> **可去奇点 = 可以补上；极点 = 吹到无穷，有阶数；本性奇点 = 行为无序、极限不存在、负幂无穷。**
