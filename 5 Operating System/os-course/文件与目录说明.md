# 文件与目录逐项说明

这是一份中文内容索引，逐项对应远程仓库的 `doc` 和 `lab`。代码与配置只解释用途，不复制实现；文档链接进入本地中文译文，原文件链接进入已核对版本。

整理日期：2026-10-05（Europe/Moscow）。来源：[secs-dev/os-course](https://github.com/secs-dev/os-course/tree/main)。

核对版本：`dee17bc418979ecbae3b45db74cdc1494bdc9bb1`。范围：**32 个目录、92 个文件，其中 17 份 Markdown 文档均有完整中文译文**；另译根 README，PDF 差异、附图标签与工具参数有中文补充。
