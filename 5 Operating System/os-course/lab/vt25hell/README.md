# Shell：基础命令行解释器

> 中文全译：[原文](https://github.com/secs-dev/os-course/blob/dee17bc418979ecbae3b45db74cdc1494bdc9bb1/lab/vt25hell/README.md)。这是独立于 `vtsh` 的另一个 Shell 实验版本。

## 引言

终端是操作系统的基本用户界面。它让用户与操作系统交互、发出命令、运行程序，并观察结果。能够运行程序，也就能扩展操作系统的能力。本实验要求实现类似 Bash 的简单命令行解释器。

## 第一部分：运行程序

实现自己的 shell。用户应能在计算机上运行程序，传入命令行参数，并看到执行时间；执行时间按结束时间减去开始时间计算。

## 第二部分：逻辑运算符

按分配的变体，为 shell 加入类似 Bash 的控制运算符：

1. `&&`：逻辑与（AND）。
2. `||`：逻辑或（OR）。
3. `;`：顺序执行。
4. `&`：后台执行。

## 实现要求

1. 程序或程序组必须使用 C 语言。
2. 按变体指定的操作系统系统调用创建子进程，保证进程正确启动和结束。禁止使用系统调用之上的高级抽象；应使用 libc 提供的调用入口。

## 变体说明

子程序启动方式（**proc** 组）：

- `proc-fork`：使用 `fork` 系统调用启动子进程。
- `proc-vfork`：使用 `vfork` 系统调用启动子进程。
- `proc-clone`：使用 `clone` 系统调用启动子进程。
- `proc-clone3`：使用 `clone3` 系统调用启动子进程。

额外的 Shell 控制运算符（**shell** 组）：

- `shell-and`：逻辑 AND 执行（Bash 的 `&&`）。
- `shell-or`：逻辑 OR 执行（Bash 的 `||`）。
- `shell-seq`：顺序执行（Bash 的 `;`）。
- `shell-bg`：在后台进程中执行（Bash 的 `&`）。
