# 基础路线：实验 3（内核模块）

> 中文全译：[原文](https://github.com/secs-dev/os-course/blob/dee17bc418979ecbae3b45db74cdc1494bdc9bb1/lab/vtkm/README.md)。

## 任务

开发一组分别运行在用户态和内核态的程序，在内核侧收集信息，将信息传给用户态，并以便于人阅读的形式输出。

用户态程序接收命令行参数（**不是内存地址！**），这些参数应能标识从系统表到目标结构的查找路径。用户程序将参数传入内核，取得目标结构的信息，再把结构打印到标准输出。

可加载内核模块通过指定接口接收请求，根据请求确定目标结构的路径，并将结果返回用户态。

用户程序与内核之间的传输接口、目标结构由教师指定。可选接口包括：

- `syscall`：系统调用接口。
- `ioctl`：通过文件/设备控制调用传递参数。
- `procfs`：通过写入 `/proc` 文件系统中的文件传递参数。
- `debugfs`：通过写入 `/sys/kernel/debug` 调试文件系统中的文件传递参数。

目标结构有两种指定方式：

1. Linux 头文件中的结构体名称。
2. `/proc` 中的文件。此时需要根据 `/proc` 文件路径和输出数据，推断目标内核结构。
