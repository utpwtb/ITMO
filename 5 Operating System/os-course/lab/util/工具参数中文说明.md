# 实验辅助工具：参数与配置说明

本文件翻译工具中的说明性文字并概括配置用途。代码本身仍在远程仓库。

## graphgen.py

[源文件](https://github.com/secs-dev/os-course/blob/dee17bc418979ecbae3b45db74cdc1494bdc9bb1/lab/util/graphgen.py)。用途：生成页缓存测试用的二进制图文件。

| 参数 | 中文含义与默认值 |
|---|---|
| `-o` / `--output` | 输出文件路径；默认 `graph.bin` |
| `-s` / `--size` | 目标文件大小，必填；例如 `64M`、`2G`、`1000000` |
| `-f` / `--fanout` | 每顶点最大出边数；默认 1，表示线性列表 |
| `-b` / `--backprob` | 跳向较小物理偏移的概率，范围 0–1，默认 0.5；帮助文本称 0 为向前、1 为向后 |
| `--seed` | 随机种子，用于复现；`--describe-only` 不需要种子 |
| `--page-size` | 操作系统/文件系统页大小，单位字节；默认 4096 |
| `--min-step-pages` | 随机跳转至少跨越多少页；默认 2.0；原帮助称用于保证缓存未命中 |
| `--topology` | `sequential`：`0→1→…→N-1`；`chain`：强制 fanout=1，并随机排列顶点形成 Hamilton 路径；`graph`：使用指定 fanout |
| `--min-nodes` | 最少允许的顶点数量；默认 64 |
| `--value-mode` | 顶点载荷初始化方式：`zero` 全零、`index` 按编号、`random` 随机；默认 random |
| `--value-min` | 随机载荷下界；默认 $-2^{31}$ |
| `--value-max` | 随机载荷上界；默认 $2^{31}-1$ |
| `--verify` | 生成后检查连通性与无环性 |
| `--describe-only` | 不生成文件，只计算布局（顶点数、记录大小、最少跨越顶点数），输出文件头与顶点记录的 C 结构描述 |
| `--struct-out` | 另外把 C 结构描述保存为 `.h` 文件 |

`sequential` 和 `chain` 都会强制 `fanout=1`。两者区别是**物理访问次序**：`chain` 并不等于顺序磁盘访问。

内部主要组件包括 SplitMix64 随机数生成器、Fenwick 树、尺寸解析、布局计算、图生成、二进制输出、验证，以及 C 结构输出。

> 译者注：跨越不同文件页不自动保证 CPU 缓存或操作系统页缓存未命中；是否命中仍取决于此前访问和工作集状态。

## perfetto/config.txtpb

[源配置](https://github.com/secs-dev/os-course/blob/dee17bc418979ecbae3b45db74cdc1494bdc9bb1/lab/util/perfetto/config.txtpb)。使用步骤见 [Perfetto 中文说明](perfetto/README.md)。

原配置说明性注释的中文含义与参数：

- 跟踪时长和输出：`duration_ms: 10000`，采集 10 秒；写入文件，每 1000 ms 刷新。
- 中央内存缓冲区：`size_kb: 65536`，即 64 MiB；`RING_BUFFER` 为环形缓冲。
- CPU 调度与进程生命周期：采集 `sched_switch`、`sched_wakeup`、进程退出/释放、新任务、CPU 频率和空闲事件。
- 进程树元数据：开始时扫描全部进程，用名称解释 PID。
- 系统内存计数器：每 100 ms 采样总内存、空闲内存、Buffers、Cached、Swap 总量和空闲量。
