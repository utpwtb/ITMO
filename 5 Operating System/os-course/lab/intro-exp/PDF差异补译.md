## PDF 第 4.5 节：交错执行

应交错执行 `graph-seq` / `graph-rand`，而不是按配置分块执行。这样可减少系统性漂移。

补充句：在更复杂的实验中，甚至可能需要使用不同的物理随机数发生器。

## PDF 第 4.8 节：分析测量

对 `graph-seq.bin` 和 `graph-rand.bin` 计算平均值、标准差与置信区间，方法见[统计指南](../../doc/experiments/statistics.md)。明确说明如何处理异常值和预热。

绘制平均值柱状图，并附置信区间误差棒。由于这里是点估计，而非随参数变化的函数关系，不需要展开参数曲线。

为了更直观，可以请自己的“Jarvis”（助手）绘制分布图。可以是简单直方图，或更细致的 KDE；这样能看到两组测量的差异。

当前 README 的相应段落强调：把两组分布叠加在同一张图上，并思考直方图与 KDE 的区别，以及为何不能默认测量分布为正态。

## PDF 第 6 节：汇总四组

将全部四组结果（`graph_traverse` 两组、`graph_traverse_mmap` 两组）整理在一张表和一张图中。

当前 README 的相应段落要求把所有组的图放在一起，作定性与定量比较。
