请使用以下技术重写前一实验作业的应用程序：

- 后端层应基于 ***Java EE***（需使用 ***EJB***）。
- 前端层应基于 ***Vue.js* **构建，并使用***普通的 HTML 输入字段***。
- 后端与前端层之间的交互应通过 ***REST API* **进行组织。

应用程序仍需包含两个页面：起始页和应用程序主页面。两个页面均需适配以下三种显示模式：

1. **“桌面模式”** — 适用于屏幕宽度大于或等于 1028 像素的设备。
2. **“平板模式”** — 适用于屏幕宽度大于或等于 836 像素但小于 1028 像素的设备。
3. **“移动模式”** — 适用于屏幕宽度小于 836 像素的设备。

**起始页应包含以下元素：**

- 包含学生姓名、小组编号和选项编号的“页眉”。
- 用于输入登录名和密码的表单。系统中已注册用户的信息应存储在一个独立的数据库表中（密码需以哈希值形式存储）。未经授权的用户禁止访问应用程序的主页面。

**应用程序主页面应包含以下元素：**

- 一组输入字段，用于根据任务选项设置点的坐标和区域半径：
  - 坐标 X：按钮 {'-2','-1.5','-1','-0.5','0','0.5','1','1.5','2'}。
  - 坐标 Y：文本输入框（-3 到 3）。
  - 区域半径：按钮 {'-2','-1.5','-1','-0.5','0','0.5','1','1.5','2'}。
    如果输入字段允许输入明显无效的数据（例如坐标中输入字母或半径为负值），应用程序需进行验证。
- 动态更新的图片，显示根据选项编号在坐标平面上的区域及用户输入坐标的点。点击图片应触发脚本，确定新点的坐标并将其发送到服务器以检查其是否在区域内。点的颜色应根据是否在区域内而变化。更改半径也应触发图片的重新绘制。
- 显示先前检查结果列表的表格。
- 一个按钮，允许已认证用户关闭会话并返回应用程序的起始页。

**应用程序的额外要求：**

- 所有检查结果必须保存在 ***H2 数据库管理系统***中。
- 访问数据库需使用 ***JPA***。

**实验作业答辩问题：**

1. Java EE 平台。规范及其实现。
2. IoC、CDI 与位置透明性原则。组件与容器。
3. 组件的生命周期管理。部署描述符。
4. Java EE API。组件类型。Java EE 平台配置文件。
5. EJB 组件。无状态与有状态会话 Bean。EJB Lite 与 EJB Full。
6. 在 Java EE 中处理电子邮件。JavaMail API。
7. JMS。消息队列的实现。消息传递到客户端的方式。消息驱动 Bean。
8. 事务的概念。Java EE 中的事务管理。JTA。
9. Web 服务。JAX-RS 与 JAX-WS 技术。
10. Spring 平台。与 Java EE 的异同。
11. Spring 模块。Spring 运行时架构。Spring Security 与 Spring Data。
12. Spring 中 IoC 与 CDI 的实现。与 Java EE 的异同。
13. Java EE 与 Spring 中 REST API 的实现。
14. React JS。应用程序的架构与主要开发原则。
15. React 组件。State 与 props。"智能"组件与"木偶"组件。
16. React 应用程序中的页面标记。JSX。
17. React 应用程序中的导航。React Router。
18. 界面状态管理。Redux。
19. Angular：架构与主要开发原则。
20. Angular：模块、组件、服务与依赖注入（DI）。
21. Angular：页面模板、组件生命周期、CSS 引入。
22. Angular：客户端-服务器交互、表单数据的创建、发送与验证。
