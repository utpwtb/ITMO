
- **State**：组件内部管理的数据，可变（用 `useState`修改），谁的数据谁管理
- **Props**：父组件传给子组件的数据，只读，子组件不能改
- **展示组件**：只管界面显示，数据来自 `props`，一般没有 `state`（或有UI状态）
- **容器组件**：管业务逻辑和数据，管理 `state`，通过 `props`传给展示组件
- **关系**：容器组件拥有 `state`，展示组件接收 `props`，二者通过 `props`连接

---


- **State (состояние)** — данные внутри компонента, можно изменять (через `useState`), управляется самим компонентом
- **Props (свойства)** — данные от родительского компонента, **только для чтения**, дочерний компонент не меняет
- **Презентационные компоненты** — только внешний вид, данные из `props`, обычно без `state`
- **Компоненты-контейнеры** — логика и данные, управляют `state`, передают `props` презентационным
- **Связь** — контейнер управляет `state`, презентационный получает `props`, связь через `props`
