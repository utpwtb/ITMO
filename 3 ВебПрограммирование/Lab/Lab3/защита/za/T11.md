# Библиотеки ORM Hibernate и EclipseLink: Особенности, API, сходства и отличия

Hibernate和EclipseLink是Java生态中两个主要的JPA实现。Hibernate更早出现，功能丰富，社区活跃；EclipseLink是JPA的参考实现，更严格遵循规范。

Hibernate и EclipseLink — это две основные реализации JPA в экосистеме Java. Hibernate появился раньше, имеет богатые функции и активное сообщество; EclipseLink является эталонной реализацией JPA и строже следует спецификации.

---

## **1. 主要特点 / Основные особенности**

### **Hibernate**

**中文特点：**

* 2001年诞生，历史最悠久的ORM框架之一
* 提供超出JPA规范的功能（"Hibernate扩展"）
* 强大的缓存机制（一级、二级、查询缓存）
* 丰富的关联关系映射支持
* 活跃的社区和大量文档
* 与Spring框架集成紧密

**Особенности на русском:**

* Появился в 2001 году, один из старейших фреймворков ORM
* Предоставляет функции, выходящие за рамки спецификации JPA ("расширения Hibernate")
* Мощный механизм кэширования (уровни 1, 2, кэш запросов)
* Богатая поддержка отображения связей
* Активное сообщество и обширная документация
* Тесная интеграция с фреймворком Spring

### **EclipseLink**

**中文特点：**

* JPA 2.0+的官方参考实现
* 由Eclipse基金会维护
* 严格遵守JPA规范
* 支持多种持久化标准（JPA、JAXB、SDO等）
* 优秀的XML持久化支持
* 性能优化特性丰富

**Особенности на русском:**

* Официальная эталонная реализация JPA 2.0+
* Поддерживается фондом Eclipse
* Строгое соблюдение спецификации JPA
* Поддержка нескольких стандартов персистентности (JPA, JAXB, SDO и др.)
* Отличная поддержка XML-персистентности
* Богатые возможности оптимизации производительности

## **2. API比较 / Сравнение API**

### **2.1 JPA标准API（两者都支持）**

**java**

```
// Оба поддерживают стандартный API JPA
// Оба поддерживают стандартный API JPA

// Persistence context management
EntityManager em = emf.createEntityManager();
em.persist(entity);      // Сохранение
em.merge(entity);        // Обновление
em.find(Entity.class, id); // Поиск по ID

// Query

    "SELECT u FROM User u WHERE u.age > :age", User.class);
typedQuery.setParameter("age", 18);

```

### **2.2 特有API / Специфичные API**

#### **Hibernate特有API:**

**java**

```
// Использование собственного API Hibernate
Session session = sessionFactory.openSession();

// 1. Session-specific methods
session.save(entity);           // Аналог persist, но с возвратом ID
session.update(entity);         // Более строгий, чем merge
session.saveOrUpdate(entity);   // Универсальный метод
session.get(Entity.class, id);  // Немедленная загрузка
session.load(Entity.class, id); // Ленивая загрузка (прокси)

// 2. Criteria API (более старый)
Criteria criteria = session.createCriteria(User.class);
criteria.add(Restrictions.gt("age", 18));
criteria.addOrder(Order.asc("name"));
List<User> users = criteria.list();

// 3. Query API (HQL)
Query hqlQuery = session.createQuery(
    "FROM User u WHERE u.name LIKE :name");
hqlQuery.setParameter("name", "%John%");

// 4. Native SQL с поддержкой объектов
SQLQuery sqlQuery = session.createSQLQuery(
    "SELECT * FROM users WHERE age > ?");
sqlQuery.addEntity(User.class);
sqlQuery.setInteger(0, 18);

// 5. Filter (фильтры коллекций)
session.enableFilter("activeFilter")
       .setParameter("active", true);
```

#### **EclipseLink特有API:**

**java**

```
// Использование собственного API EclipseLink
JpaEntityManager em = (JpaEntityManager) entityManager;
UnitOfWork uow = em.getUnitOfWork();

// 1. UnitOfWork (работа с изменениями)
uow.registerNewObject(entity);      // Регистрация нового
uow.registerObject(entity);         // Регистрация измененного
uow.deepMerge(entity);              // Глубокое слияние
uow.deleteObject(entity);           // Пометка на удаление

// 2. Expression Framework (альтернатива Criteria)
ExpressionBuilder builder = new ExpressionBuilder();
Expression whereClause = builder.get("age").greaterThan(18)
    .and(builder.get("status").equal("ACTIVE"));

ReadAllQuery query = new ReadAllQuery(User.class);
query.setSelectionCriteria(whereClause);
List<User> users = (List<User>) uow.executeQuery(query);

// 3. Custom SQL (Expression Framework)
SQLCall call = new SQLCall("SELECT * FROM users WHERE age > ?");
call.setBindingStyle(SQLCall.BINDING_STYLE);
DataReadQuery query = new DataReadQuery();
query.setCall(call);
query.addArgument("age");
List results = uow.executeQuery(query, 18);

// 4. Fetch Groups (оптимизация выборки)
FetchGroup fetchGroup = new FetchGroup();
fetchGroup.addAttribute("name");
fetchGroup.addAttribute("email");

ReadAllQuery query = new ReadAllQuery(User.class);
query.setFetchGroup(fetchGroup);

// 5. Cache API
CacheHandler cacheHandler = uow.getParent().getCacheHandler();
cacheHandler.invalidate(User.class, userId); // Инвалидация кэша
```

                  value="org.hibernate.cache.ehcache.EhCacheRegionFactory"/>

## **4. 相似之处 / Сходства**

### **共同特点：**

1. **两者都实现了JPA 2.0+规范**
2. **支持标准注解** ：`@Entity`、`@Table`、`@Id`、`@Column`等
3. **具有相似的实体生命周期** ：瞬时态、托管态、游离态、删除态
4. **支持JPQL** （有微小的方言差异）
5. **提供事务管理**
6. **支持延迟加载** （Lazy Loading）
7. **具有缓存机制**
8. **可与Java EE和Spring容器集成**

### **Общие черты:**

1. **Оба реализуют спецификацию JPA 2.0+**
2. **Поддерживают стандартные аннотации** : `@Entity`, `@Table`, `@Id`, `@Column` и т.д.
3. **Имеют схожий жизненный цикл сущностей** : Transient, Managed, Detached, Removed
4. **Поддерживают JPQL** (с небольшими диалектными различиями)
5. **Обеспечивают управление транзакциями**
6. **Поддерживают ленивую загрузку** (Lazy Loading)
7. **Имеют механизмы кэширования**
8. **Интегрируются с контейнерами Java EE и Spring**

### **Пример общего кода:**

**java**

```
// Следующий код работает одинаково в обоих

// 1. Определение сущности
@Entity
@Table(name = "users")
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
  
    @Column(name = "user_name", nullable = false)
    private String name;
  
    @OneToMany(mappedBy = "user", cascade = CascadeType.ALL)
    private List<Order> orders;
  
    // Геттеры и сеттеры
}

// 2. Использование EntityManager
EntityManagerFactory emf = Persistence.createEntityManagerFactory("myPU");
EntityManager em = emf.createEntityManager();

em.getTransaction().begin();
User user = new User();
user.setName("Иван");
em.persist(user);
em.getTransaction().commit();
```

## **5. 主要区别 / Основные отличия**


| **方面**     | Hibernate            | EclipseLink                     |
| ------------------ | -------------------- | ------------------------------- |
| **设计理念** | "尽其所能"，扩展规范 | "遵循规范"，更保守的方法        |
| **起源**     | 社区，Red Hat        | Oracle，后转由Eclipse基金会维护 |
| **主要焦点** | 功能丰富的ORM        | 多种持久化技术                  |
| **缓存机制** | 更复杂，三级缓存     | 更简单但灵活可配置              |

### **5.1 架构和设计理念 / Архитектура и философия дизайна**

| Аспект                          | Hibernate                                                                             | EclipseLink                                                                                         |
| ------------------------------------- | ------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Философия**          | "Делать всё возможное", расширяет спецификацию | "Следовать спецификации", более консервативный подход |
| **Происхождение**  | Сообщество, Red Hat                                                         | Oracle, затем Eclipse Foundation                                                               |
| **Основной фокус** | ORM с богатыми возможностями                                    | Множество технологий персистентности                              |
| **Кэширование**      | Более сложное, три уровня                                        | Проще, но гибко настраиваемое                                              |
