# RISC-IV 指令集架构 (ISA) 文档

RISC-IV ISA 是一个简单的基于寄存器的指令集，灵感来自 RISC-V 架构。本文档概述了 RISC-IV ISA 中可用的指令、它们的语法和语义。

## 架构概述

RISC-IV 架构是一个 32 位 RISC（精简指令集计算机）架构，灵感来自 RISC-V 规范。它具有以下特点：

- 32 个通用寄存器（包括一个硬连线的零寄存器）
- 固定长度的 4 字节指令
- 加载-存储架构（内存访问只能通过特定指令）
- 简单的寻址模式
- 内存映射 I/O
- 通过跳转并链接指令支持函数调用和返回
- 算术、逻辑和控制流操作

该架构提供了一个干净、正交的指令集，体现了 RISC 设计原则，使其非常适合教育目的，同时仍然足够强大以用于实际应用。

RISC-IV 汇编代码中的注释由 `;` 字符表示。

灵感来源：[RISC-V](https://riscv.org/wp-content/uploads/2017/05/riscv-spec-v2.2.pdf)

## 立即数重定位指令

RISC-IV 汇编语言提供了特殊的指令，用于处理无法放入标准指令格式的较大立即数值：

- **%hi(符号)**

  - **描述：** 用于提取 32 位地址或立即数的高 20 位
  - **用法：** `lui rd, %hi(符号)`
  - **操作：** `rd <- (符号 & 0xFFFFF000)`
- **%lo(符号)**

  - **描述：** 用于提取 32 位地址或立即数的低 12 位
  - **用法：** `addi rd, rs, %lo(符号)`
  - **操作：** `rd <- rs + (符号 & 0x00000FFF)`

这些指令通常一起使用，将一个完整的 32 位地址加载到寄存器中：

```assembly
lui  a0, %hi(地址)       ; 将高 20 位加载到 a0
addi a0, a0, %lo(地址)   ; 将低 12 位加到 a0
```

## 指令

指令大小：4 字节。

### 数据传送指令

- **加载高位立即数** 

  - **语法：** `lui <rd>, <k>`
  - **描述：** 将左移 12 位的立即数值加载到目标寄存器。
  - **操作：** `rd <- k << 12`
- **移动**

  - **语法：** `mv <rd>, <rs>`
  - **描述：** 将值从源寄存器移动到目标寄存器。
  - **操作：** `rd <- rs`
- **存储字**

  - **语法：** `sw <rs2>, <偏移量>(<rs1>)`
  - **描述：** 将源寄存器的值存储到内存中，地址通过将偏移量加到基址寄存器计算得出。
  - **操作：** `M[偏移量 + rs1] <- rs2`
- **存储字节**

  - **语法：** `sb <rs2>, <偏移量>(<rs1>)`
  - **描述：** 将源寄存器值的低 8 位存储到内存中，地址通过将偏移量加到基址寄存器计算得出。
  - **操作：** `M[偏移量 + rs1] <- rs2 & 0xFF`
- **加载字**

  - **语法：** `lw <rd>, <偏移量>(<rs1>)`
  - **描述：** 从内存中加载一个字到目标寄存器，地址通过将偏移量加到基址寄存器计算得出。
  - **操作：** `rd <- M[偏移量 + rs1]`

### 算术指令

- **加立即数**

  - **语法：** `addi <rd>, <rs1>, <k>`
  - **描述：** 将立即数值加到源寄存器，并将结果存储在目标寄存器中。只存储结果的低 12 位（高 20 位根据立即数的符号设置）。
  - **操作：** `rd <- rs1 + k`
- **加法**

  - **语法：** `add <rd>, <rs1>, <rs2>`
  - **描述：** 将两个源寄存器的值相加，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 + rs2`
- **减法**

  - **语法：** `sub <rd>, <rs1>, <rs2>`
  - **描述：** 从第一个源寄存器的值中减去第二个源寄存器的值，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 - rs2`
- **乘法**

  - **语法：** `mul <rd>, <rs1>, <rs2>`
  - **描述：** 将两个源寄存器的值相乘，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 * rs2`
- **高位乘法**

  - **语法：** `mulh <rd>, <rs1>, <rs2>`
  - **描述：** 将两个源寄存器的值相乘，并将结果的高位部分存储在目标寄存器中。
  - **操作：** `rd <- (rs1 * rs2) >> (字长)`
- **除法**

  - **语法：** `div <rd>, <rs1>, <rs2>`
  - **描述：** 将第一个源寄存器的值除以第二个源寄存器的值，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 / rs2`
- **取余**

  - **语法：** `rem <rd>, <rs1>, <rs2>`
  - **描述：** 计算第一个源寄存器除以第二个源寄存器的余数，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 % rs2`

### 位运算指令

- **逻辑左移**

  - **语法：** `sll <rd>, <rs1>, <rs2>`
  - **描述：** 将第一个源寄存器的值左移由第二个源寄存器指定的位数，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 << rs2`
- **逻辑右移**

  - **语法：** `srl <rd>, <rs1>, <rs2>`
  - **描述：** 将第一个源寄存器的值右移由第二个源寄存器指定的位数，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 >> rs2`
- **算术右移**

  - **语法：** `sra <rd>, <rs1>, <rs2>`
  - **描述：** 将第一个源寄存器的值右移由第二个源寄存器指定的位数，保留符号位，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 >> rs2`
- **按位与**

  - **语法：** `and <rd>, <rs1>, <rs2>`
  - **描述：** 对两个源寄存器的值执行按位与操作，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 & rs2`
- **按位或**

  - **语法：** `or <rd>, <rs1>, <rs2>`
  - **描述：** 对两个源寄存器的值执行按位或操作，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 | rs2`
- **按位异或**

  - **语法：** `xor <rd>, <rs1>, <rs2>`
  - **描述：** 对两个源寄存器的值执行按位异或操作，并将结果存储在目标寄存器中。
  - **操作：** `rd <- rs1 ^ rs2`

### 控制流指令

- **跳转**

  - **语法：** `j <k>`
  - **描述：** 跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `pc <- pc + k`
- **跳转并链接**

  - **语法：** `jal <rd>, <k>`
  - **描述：** 将下一条指令的地址存储在目标寄存器中，并跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `rd <- pc + 4, pc <- pc + k`
- **跳转寄存器**

  - **语法：** `jr <rs>`
  - **描述：** 跳转到存储在源寄存器中的地址。
  - **操作：** `pc <- rs`
- **等于零时分支**

  - **语法：** `beqz <rs1>, <k>`
  - **描述：** 如果源寄存器中的值为零，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 == 0 then pc <- pc + k`
- **不等于零时分支**

  - **语法：** `bnez <rs1>, <k>`
  - **描述：** 如果源寄存器中的值不为零，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 != 0 then pc <- pc + k`
- **大于时分支**

  - **语法：** `bgt <rs1>, <rs2>, <k>`
  - **描述：** 如果第一个源寄存器的值大于第二个源寄存器的值，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 > rs2 then pc <- pc + k`
- **小于等于时分支**

  - **语法：** `ble <rs1>, <rs2>, <k>`
  - **描述：** 如果第一个源寄存器的值小于或等于第二个源寄存器的值，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 <= rs2 then pc <- pc + k`
- **无符号大于时分支**

  - **语法：** `bgtu <rs1>, <rs2>, <k>`
  - **描述：** 如果第一个源寄存器的无符号值大于第二个源寄存器的无符号值，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 > rs2 then pc <- pc + k`
- **无符号小于等于时分支**

  - **语法：** `bleu <rs1>, <rs2>, <k>`
  - **描述：** 如果第一个源寄存器的无符号值小于或等于第二个源寄存器的无符号值，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 <= rs2 then pc <- pc + k`
- **相等时分支**

  - **语法：** `beq <rs1>, <rs2>, <k>`
  - **描述：** 如果第一个源寄存器的值等于第二个源寄存器的值，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 == rs2 then pc <- pc + k`
- **不相等时分支**

  - **语法：** `bne <rs1>, <rs2>, <k>`
  - **描述：** 如果第一个源寄存器的值不等于第二个源寄存器的值，则跳转到通过将立即数值加到当前程序计数器计算得出的地址。
  - **操作：** `if rs1 != rs2 then pc <- pc + k`
- **停机**

  - **语法：** `halt`
  - **描述：** 停止机器运行。

## ISA 特定状态视图

- `<reg>:dec`, `<reg>:hex` -- 以十进制或十六进制格式查看特定寄存器的值。

可用寄存器：`Zero`, `Ra`, `Sp`, `Gp`, `Tp`, `T0`, `T1`, `T2`, `S0Fp`, `S1`, `A0`, `A1`, `A2`, `A3`, `A4`, `A5`, `A6`, `A7`, `S2`, `S3`, `S4`, `S5`, `S6`, `S7`, `S8`, `S9`, `S10`, `S11`, `T3`, `T4`, `T5`, `T6`。
