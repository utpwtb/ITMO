# M68k 指令集架构（ISA）文档

M68k ISA 是一个简单的类 CISC 指令集，其灵感来源于摩托罗拉 68000 架构。本文档概述了 M68k ISA 中可用的指令、它们的语法及语义。

## 架构概述

M68k 架构是一种受摩托罗拉 68000 系列启发的 32 位 CISC（复杂指令集计算机）架构。它具有以下特点：

- 8 个通用数据寄存器（D0-D7）
- 8 个地址寄存器（A0-A7，其中 A7 用作栈指针）
- 多种寻址模式，实现灵活的内存访问
- 丰富的指令集，支持多种操作数大小
- 带有条件码标志的状态寄存器
- 内存映射 I/O

该架构在 RISC 设计的简洁性与 CISC 处理器的丰富功能之间取得了平衡，使其非常适合用于理解更复杂的处理器设计。

* 输入必须通过内存单元 `0x80` 传递
* 输出必须存入内存单元 `0x84`这个是要求，请你在这个基础上修改一下你画的图

## ISA 特定状态视图

- `D<n>:dec`、`D<n>:hex` -- 数据寄存器（D0-D7）。
- `A<n>:dec`、`A<n>:hex` -- 地址寄存器（A0-A7）。
- `PC:dec`、`PC:hex` -- 程序计数器。
- `SR:bin` -- 状态寄存器（标志位：N、Z、V、C）。

### 内存与寄存器使用

- **数据寄存器 (D0-D7):** 用于算术、逻辑和数据操作的通用寄存器。
- **地址寄存器 (A0-A7):** 用于内存寻址。A7 也用作栈指针 (SP)。
- **状态寄存器 (SR):** 包含条件码（标志位）：
  - **N (负):** 若操作结果为负则置位。
  - **Z (零):** 若操作结果为零则置位。
  - **V (溢出):** 若发生算术溢出则置位。
  - **C (进位):** 若算术操作中发生进位或借位则置位。

## 指令

指令长度因操作模式和使用的寻址模式而异。字节大小计算现在考虑了字节操作和长字操作之间的差异，其中字节操作通常比长字操作使用更少的内存。

### 操作模式

M68k 指令可以操作不同大小的数据：

- **字节 (`.b`):** 8 位操作
- **长字 (`.l`):** 32 位操作（默认）

示例：`add.b D0, D1` 仅操作 D0 和 D1 的最低有效字节。

> **关于字节大小实现的说明：** 指令的字节大小实现现在区分字节和长字操作。字节操作（`.b`）使用 1 个字节的数据，而长字操作（`.l`）使用 4 个字节。所有跳转和分支指令始终使用长字（6 字节）编码，而不考虑位移量大小。

### 寻址模式

M68k ISA 支持以下寻址模式：

1. **寄存器直接寻址**

   - **数据寄存器直接寻址**: `D0` 至 `D7`
   - **地址寄存器直接寻址**: `A0` 至 `A7`
2. **立即数寻址**: `value`

   - 示例：`move.l 42, D0`
3. **内存寻址**

   - **地址寄存器间接寻址**: `(An)`

     - 访问包含在 An 中的地址处的内存
     - 示例：`move.l (A0), D0`
   - **地址寄存器间接寻址（后增量）**: `(An)+`

     - 使用 An 中的地址，然后根据操作大小（字节为 1，长字为 4）增加 An 的值
     - 示例：`move.l (A0)+, D0`
   - **地址寄存器间接寻址（预减量）**: `-(An)`

     - 根据操作大小减小 An 的值，然后使用结果地址
     - 示例：`move.l -(A0), D0`
   - **地址寄存器间接寻址（带位移）**: `d(An)`

     - 使用 An 中的地址加上一个带符号的 16 位位移量 d
     - 示例：`move.l 8(A0), D0` 或 `move.l -4(A0), D0`
   - **地址寄存器间接寻址（带索引）**: `d(An,Xn)`

     - 使用 An 中的地址加上 Xn（可以是数据或地址寄存器）中的值，再加上一个带符号的位移量 d
     - 示例：`move.l 4(A0,D1), D0` 或 `move.l 8(A0,A1), D0`

### 数据传送指令

- **传送**

  - **语法:** `move.<size> <源操作数>, <目标操作数>`
  - **描述:** 将数据从源操作数传送到目标操作数。
  - **操作:** `<目标操作数> <- <源操作数>`
  - **示例:**

    ```assembly
    move.l D0, D1       ; 将 D0 复制到 D1 (32位)
    move.b D0, D1       ; 将 D0 的最低字节复制到 D1 的最低字节
    move.l 42, D0       ; 将立即数 42 加载到 D0
    move.l (A0), D0     ; 从 A0 指向的内存地址加载值到 D0
    move.l D0, (A1)     ; 将 D0 中的值存储到 A1 指向的内存地址
    move.l (A0)+, D0    ; 从 A0 指向的地址加载值，然后将 A0 增加 4
    move.l -(A0), D0    ; 将 A0 减小 4，然后从新地址加载值到 D0
    move.l 8(A0), D0    ; 从地址 A0+8 处加载值
    move.l -4(A0), D0   ; 从地址 A0-4 处加载值
    move.l 8(A0,D1), D0 ; 从地址 A0+D1+8 处加载值
    move.l 4(A0,A1), D0 ; 从地址 A0+A1+4 处加载值
    ```
- **传送至地址寄存器**

  - **语法:** `movea.l <源操作数>, <目标地址寄存器>`
  - **描述:** 将数据从源操作数传送到目标地址寄存器。
  - **操作:** `<目标地址寄存器> <- <源操作数>`
  - **示例:**

    ```assembly
    movea.l 1000, A0    ; 将立即数 1000 加载到 A0
    movea.l D0, A1      ; 将 D0 复制到 A1
    ```

### 逻辑指令

- **非**

  - **语法:** `not.<size> <目标操作数>`
  - **描述:** 对目标操作数执行按位非操作。
  - **操作:** `<目标操作数> <- ~<目标操作数>`
  - **示例:**

    ```assembly
    not.l D0            ; D0 <- ~D0 (32位)
    not.b D0            ; 对 D0 的最低字节执行 NOT 操作
    ```
- **与**

  - **语法:** `and.<size> <源操作数>, <目标操作数>`
  - **描述:** 将源操作数与目标操作数执行按位与操作。
  - **操作:** `<目标操作数> <- <目标操作数> & <源操作数>`
  - **示例:**

    ```assembly
    and.l D0, D1        ; D1 <- D1 & D0 (32位)
    and.b D0, D1        ; 对 D0 和 D1 的最低字节执行 AND 操作
    ```
- **或**

  - **语法:** `or.<size> <源操作数>, <目标操作数>`
  - **描述:** 将源操作数与目标操作数执行按位或操作。
  - **操作:** `<目标操作数> <- <目标操作数> | <源操作数>`
  - **示例:**

    ```assembly
    or.l D0, D1         ; D1 <- D1 | D0 (32位)
    or.b D0, D1         ; 对 D0 和 D1 的最低字节执行 OR 操作
    ```
- **异或**

  - **语法:** `xor.<size> <源操作数>, <目标操作数>`
  - **描述:** 将源操作数与目标操作数执行按位异或操作。
  - **操作:** `<目标操作数> <- <目标操作数> ^ <源操作数>`
  - **示例:**

    ```assembly
    xor.l D0, D1        ; D1 <- D1 ^ D0 (32位)
    xor.b D0, D1        ; 对 D0 和 D1 的最低字节执行 XOR 操作
    ```

### 算术指令

- **加法**

  - **语法:** `add.<size> <源操作数>, <目标操作数>`
  - **描述:** 将源操作数加到目标操作数上。
  - **操作:** `<目标操作数> <- <目标操作数> + <源操作数>`
  - **示例:**

    ```assembly
    add.l D0, D1        ; D1 <- D1 + D0 (32位)
    add.b D0, D1        ; 将 D0 和 D1 的最低字节相加
    add.l 10, D0        ; D0 <- D0 + 10
    add.b 5, D0         ; 将 5 加到 D0 的最低字节
    ```
- **减法**

  - **语法:** `sub.<size> <源操作数>, <目标操作数>`
  - **描述:** 从目标操作数中减去源操作数。
  - **操作:** `<目标操作数> <- <目标操作数> - <源操作数>`
  - **示例:**

    ```assembly
    sub.l D0, D1        ; D1 <- D1 - D0 (32位)
    sub.b D0, D1        ; 从 D1 的最低字节减去 D0 的最低字节
    sub.l 1, D0         ; D0 <- D0 - 1
    sub.b 1, D0         ; 从 D0 的最低字节减去 1
    ```
- **比较**

  - **语法:** `cmp.<size> <源操作数>, <目标操作数>`
  - **描述:** 通过用目标操作数减去源操作数来比较两者，并根据结果设置条件码，但不存储结果。
  - **操作:** `temp <- <目标操作数> - <源操作数>` （仅设置标志位）
  - **示例:**

    ```assembly
    cmp.l D0, D1        ; 比较 D1 与 D0 (32位)
    cmp.b D0, D1        ; 比较 D1 和 D0 的最低字节
    cmp.l 10, D0        ; 将 D0 与立即数 10 比较
    cmp.b 5, D0         ; 将 D0 的最低字节与 5 比较
    cmp.l (A0), D0      ; 将 D0 与 A0 指向的内存地址处的值比较
    ```
- **乘法**

  - **语法:** `mul.<size> <源操作数>, <目标操作数>`
  - **描述:** 将目标操作数乘以源操作数。
  - **操作:** `<目标操作数> <- <目标操作数> * <源操作数>`
  - **示例:**

    ```assembly
    mul.l D0, D1        ; D1 <- D1 * D0 (32位)
    mul.b D0, D1        ; 将 D0 和 D1 的最低字节相乘
    ```
- **除法**

  - **语法:** `div.<size> <源操作数>, <目标操作数>`
  - **描述:** 将目标操作数除以源操作数。
  - **操作:** `<目标操作数> <- <目标操作数> / <源操作数>`
  - **示例:**

    ```assembly
    div.l D0, D1        ; D1 <- D1 / D0 (32位)
    div.b D0, D1        ; 使用寄存器的最低字节进行除法
    ```

### 移位与循环指令

- **算术左移**

  - **语法:** `asl.<size> <源操作数>, <目标操作数>`
  - **描述:** 将目标操作数按源操作数指定的位数进行算术左移。
  - **操作:** `<目标操作数> <- <目标操作数> << <源操作数>`
  - **示例:**

    ```assembly
    asl.l 2, D0         ; D0 <- D0 << 2 (32位)
    asl.b 2, D0         ; 将 D0 的最低字节左移 2 位
    asl.l D1, D0        ; D0 <- D0 << D1
    ```
- **算术右移**

  - **语法:** `asr.<size> <源操作数>, <目标操作数>`
  - **描述:** 将目标操作数按源操作数指定的位数进行算术右移。
  - **操作:** `<目标操作数> <- <目标操作数> >> <源操作数>` （保留符号位）
  - **示例:**

    ```assembly
    asr.l 2, D0         ; D0 <- D0 >> 2 (32位)
    asr.b 2, D0         ; 将 D0 的最低字节右移 2 位
    asr.l D1, D0        ; D0 <- D0 >> D1
    ```
- **逻辑左移**

  - **语法:** `lsl.<size> <源操作数>, <目标操作数>`
  - **描述:** 将目标操作数按源操作数指定的位数进行逻辑左移。
  - **操作:** `<目标操作数> <- <目标操作数> << <源操作数>`
  - **示例:**

    ```assembly
    lsl.l 2, D0         ; D0 <- D0 << 2 (32位)
    lsl.b 2, D0         ; 将 D0 的最低字节左移 2 位
    lsl.l D1, D0        ; D0 <- D0 << D1
    ```
- **逻辑右移**

  - **语法:** `lsr.<size> <源操作数>, <目标操作数>`
  - **描述:** 将目标操作数按源操作数指定的位数进行逻辑右移。
  - **操作:** `<目标操作数> <- <目标操作数> >> <源操作数>` （零填充）
  - **示例:**

    ```assembly
    lsr.l 2, D0         ; D0 <- D0 >> 2 (32位)
    lsr.b 2, D0         ; 将 D0 的最低字节右移 2 位
    lsr.l D1, D0        ; D0 <- D0 >> D1
    ```

### 控制流指令

- **跳转**

  - **语法:** `jmp <标签>`
  - **描述:** 跳转到指定的标签。
  - **操作:** `PC <- <标签>`
  - **示例:**

    ```assembly
    jmp loop            ; 跳转到标签 "loop"
    ```
- **进位清除时分支**

  - **语法:** `bcc <标签>`
  - **描述:** 如果进位标志被清除，则分支到指定的标签。
  - **操作:** `if C == 0 then PC <- <标签>`
  - **示例:**

    ```assembly
    bcc loop            ; 如果 C 标志被清除，则跳转到 "loop"
    ```
- **进位置位时分支**

  - **语法:** `bcs <标签>`
  - **描述:** 如果进位标志被置位，则分支到指定的标签。
  - **操作:** `if C == 1 then PC <- <标签>`
  - **示例:**

    ```assembly
    bcs error           ; 如果 C 标志被置位，则跳转到 "error"
    ```
- **相等时分支**

  - **语法:** `beq <标签>`
  - **描述:** 如果零标志被置位，则分支到指定的标签。
  - **操作:** `if Z == 1 then PC <- <标签>`
  - **示例:**

    ```assembly
    beq done            ; 如果 Z 标志被置位，则跳转到 "done"
    ```
- **不相等时分支**

  - **语法:** `bne <标签>`
  - **描述:** 如果零标志被清除，则分支到指定的标签。
  - **操作:** `if Z == 0 then PC <- <标签>`
  - **示例:**

    ```assembly
    bne loop            ; 如果 Z 标志被清除，则跳转到 "loop"
    ```
- **小于时分支**

  - **语法:** `blt <标签>`
  - **描述:** 如果 N ≠ V，则分支到指定的标签。
  - **操作:** `if N != V then PC <- <标签>`
  - **示例:**

    ```assembly
    blt less            ; 如果结果小于，则跳转到 "less"
    ```
- **大于时分支**

  - **语法:** `bgt <标签>`
  - **描述:** 如果 Z = 0 且 N = V，则分支到指定的标签。
  - **操作:** `if Z == 0 and N == V then PC <- <标签>`
  - **示例:**

    ```assembly
    bgt greater         ; 如果结果大于，则跳转到 "greater"
    ```
- **小于或等于时分支**

  - **语法:** `ble <标签>`
  - **描述:** 如果 Z = 1 或 N ≠ V，则分支到指定的标签。
  - **操作:** `if Z == 1 or N != V then PC <- <标签>`
  - **示例:**

    ```assembly
    ble less_or_equal   ; 如果结果小于或等于，则跳转到 "less_or_equal"
    ```
- **大于或等于时分支**

  - **语法:** `bge <标签>`
  - **描述:** 如果 N = V，则分支到指定的标签。
  - **操作:** `if N == V then PC <- <标签>`
  - **示例:**

    ```assembly
    bge greater_or_equal ; 如果结果大于或等于，则跳转到 "greater_or_equal"
    ```
- **为负时分支**

  - **语法:** `bmi <标签>`
  - **描述:** 如果负标志被置位，则分支到指定的标签。
  - **操作:** `if N == 1 then PC <- <标签>`
  - **示例:**

    ```assembly
    bmi negative        ; 如果结果为负，则跳转到 "negative"
    ```
- **为正时分支**

  - **语法:** `bpl <标签>`
  - **描述:** 如果负标志被清除，则分支到指定的标签。
  - **操作:** `if N == 0 then PC <- <标签>`
  - **示例:**

    ```assembly
    bpl positive        ; 如果结果为正或零，则跳转到 "positive"
    ```
- **溢出清除时分支**

  - **语法:** `bvc <标签>`
  - **描述:** 如果溢出标志被清除，则分支到指定的标签。
  - **操作:** `if V == 0 then PC <- <标签>`
  - **示例:**

    ```assembly
    bvc no_overflow     ; 如果 V 标志被清除，则跳转到 "no_overflow"
    ```
- **溢出处位时分支**

  - **语法:** `bvs <标签>`
  - **描述:** 如果溢出标志被置位，则分支到指定的标签。
  - **操作:** `if V == 1 then PC <- <标签>`
  - **示例:**

    ```assembly
    bvs overflow        ; 如果 V 标志被置位，则跳转到 "overflow"
    ```
- **跳转至子程序**

  - **语法:** `jsr <标签>`
  - **描述:** 通过将返回地址保存到栈上并跳转到目标地址来调用子程序。
  - **操作:** 将 PC 压入栈，然后 PC <- 目标地址
  - **示例:**

    ```assembly
    jsr my_function    ; 调用位于 my_function 的子程序
    ```
- **从子程序返回**

  - **语法:** `rts`
  - **描述:** 通过从栈上弹出返回地址并跳转到该地址，从子程序返回。
  - **操作:** 从栈弹出 PC
  - **示例:**

    ```assembly
    rts                ; 从子程序返回
    ```
- **建立链接**

  - **语法:** `link <地址寄存器>, <偏移量>`
  - **描述:** 通过建立新的帧指针并为局部变量分配栈空间，为子程序创建栈帧。`link` 指令通常在函数开始时使用，用于设置局部变量存储的环境。
  - **详细操作:**

    1. 将指定的地址寄存器（通常是 A6，用作帧指针）的当前值压入栈中
    2. 将当前栈指针 (A7) 的值复制到指定的地址寄存器中，从而建立新的帧指针
    3. 将偏移量加到栈指针 (A7) 上，为局部变量预留空间
       - 偏移量应为负值以分配空间（例如，-4 分配 4 个字节）
       - 然后可以使用相对于帧指针的负偏移量来访问局部变量
  - **使用上下文:**

    - 通常与作为常规帧指针寄存器的 A6 一起使用
    - 局部变量通过帧指针加上负偏移量访问（例如 `-4(A6)`）
    - 通过栈传递的参数可以通过正偏移量访问（例如 `8(A6)`）
  - **示例:**

    ```assembly
    link A6, -8        ; 将旧的 A6 保存到栈上，设置 A6 = SP，从 SP 减去 8 以分配空间
    move.l D0, -4(A6)  ; 将 D0 存入第一个局部变量（距离帧指针 4 字节处）
    move.l D1, -8(A6)  ; 将 D1 存入第二个局部变量（距离帧指针 8 字节处）
    ```
- **解除链接**

  - **语法:** `unlk <地址寄存器>`
  - **描述:** 在子程序结束时释放栈帧，将栈指针和帧指针恢复到执行相应 `link` 指令之前的值。`unlk` 指令通常是在从函数返回之前的最后一个操作。
  - **详细操作:**

    1. 将帧指针（指定的地址寄存器，通常是 A6）复制到栈指针 (A7)
       - 这通过将栈指针恢复到分配前的位置，有效地移除了所有局部变量
    2. 从栈顶弹出值到指定的地址寄存器中
       - 这将恢复由 `link` 指令保存的先前帧指针值
  - **使用上下文:**

    - 始终与对应的 `link` 指令配对使用
    - 通常后跟 `rts`（从子程序返回）指令
    - 正确释放函数中创建的所有局部变量
  - **示例:**

    ```assembly
    unlk A6            ; 设置 SP = A6 (释放局部变量空间)，然后将保存的帧指针弹出到 A6
    rts                ; 从子程序返回
    ```
    完整函数示例：

    ```assembly
    my_function:
        link A6, -12         ; 创建栈帧，为局部变量预留 12 字节空间
        move.l 8(A6), D0     ; 访问通过栈传递的参数（位于正偏移量处）
        move.l D0, -4(A6)    ; 存储到局部变量（位于负偏移量处）
        ; ... 函数主体 ...
        unlk A6              ; 销毁栈帧
        rts                  ; 从子程序返回
    ```
- **停机**

  - **语法:** `halt`
  - **描述:** 停止机器。
  - **操作:** 停止执行
  - **示例:**

    ```assembly
    halt                ; 停止程序
    ```
