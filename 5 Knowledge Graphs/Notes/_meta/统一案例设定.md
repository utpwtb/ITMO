# 统一案例设定 / Единый учебный пример

> 版本：v0.1，2026-11-04。全部为**虚构教学数据**。
> 适用：L01 完整样稿、RDF 知识点样稿；后续讲次在此基础上扩展。
> 权威数据：[实例数据](../examples/library-v0.1.ttl)、[入门子集](../examples/rdf-sample.ttl)。本轮不使用或修改 `Project`。

## 命名与身份

命名空间固定为 `https://example.org/kg-course/library/`，前缀 `lib:`。这是教学 IRI，不要求在线解析，也不指向真实大学。类名用 PascalCase，属性用 lowerCamelCase，实体 ID 用类别加三位流水号。中文名称只是标签，重名或改名均不能直接改变实体身份；不同 IRI 也不能自动当作不同的现实对象。

## 核心类

| IRI 局部名 | 中文 | 含义与边界 |
|---|---|---|
| Work | 作品 | 抽象创作内容，如《知识图谱入门》；作者和主题在此层登记 |
| Edition | 版本 | 某作品的某次出版版本，关联语言、出版年等 |
| Copy | 馆藏副本 | 一个可以单独借出的实物，不与作品或版本合并 |
| Person | 人 | 作者、读者的上位类 |
| Author | 作者 | `Author` 是 `Person` 的子类；作者也可同时为读者 |
| Reader | 读者 | `Reader` 是 `Person` 的子类 |
| Subject | 学科或主题 | 入门阶段的主题资源；尚未宣称为某个外部学科标准或 SKOS 本体 |
| Library | 图书馆 | 持有馆藏的机构 |

以上是概念设定，v0.1 实例文件只声明实例类型；尚无完整 RDFS/OWL 本体文件。后续 L02 才实现公理并注明推理器。**8 个预定类不等于研讨课第249页作业已经完成。**

## 属性登记

| 属性 | 方向或值类型 | 中文含义 | 当前状态 |
|---|---|---|---|
| rdf:type | 实例 → 类 | 属于某类 | 已用，标准词汇 |
| rdfs:label | 资源 → 带语言字符串 | 中文显示名 | 已用，标准词汇 |
| lib:title | Work → 带语言字符串 | 作品标题 | 已用 |
| lib:authoredBy | Work → Author | 作品的作者 | 已用；不反向使用 |
| lib:about | Work → Subject | 作品主题 | 已用 |
| lib:editionOf | Edition → Work | 版本对应作品 | 已用 |
| lib:copyOf | Copy → Edition | 实物对应版本 | 已用 |
| lib:heldBy | Copy → Library | 馆藏所属馆 | 已用 |
| lib:teachingEditionId | Edition → xsd:string | 教学版本号 | 已用，不是 ISBN |
| lib:language | Edition → xsd:string | 出版语言代码 | 已用，`zh`；与字符串的 `@zh` 标签用途不同 |
| lib:publicationYear | Edition → xsd:gYear | 出版年份 | 已用，四位年份词法形式 |
| lib:inventoryId | Copy → xsd:string | 教学馆藏条码 | 已用，`DEMO-C` 加三位数字；在本教学数据内唯一 |
| lib:availability | Copy → xsd:string | 快照状态 | 已用；枚举 available、borrowed；不自动证明状态完整或实时 |
| lib:copyAbout | Copy → Subject | 沿版本和作品得到的副本主题 | 本轮规则示例的派生关系；不写回原始数据 |

这些方向和值类型是**教学建模约定**，尚未通过 RDFS domain/range 或 SHACL 施加。RDFS 推理、OWL 推理、SHACL 校验、Python 断言是不同操作。

## 作品、版本、副本与 ISBN

本课程选择在 Edition 层保存未来引入的 ISBN；作品本身和每本实物不各造一个 ISBN。现实目录可能有套装、多介质等更复杂安排，本模型暂不扩展。ED-001/ED-002 和 DEMO-C001/DEMO-C002 均为教学标识，不模仿有效 ISBN，不宣称通过 ISBN 校验。未来引入 `lib:isbn` 时，需明确 ISBN-13 词法和校验位规则及缺失策略，并升数据版本。

## 当前可回答的问题

1. 《知识图谱入门》的作者是谁？→ 林岚、梅雨。
2. 两部作品的共同作者是谁？→ 林岚。
3. 知识图谱主题的副本有哪些？→ Copy001、Copy002，需连接 Copy→Edition→Work→Subject。
4. 只按当前显式快照，哪些副本标为 available？→ Copy001；不等于“未标 borrowed 的都可借”。
5. 许宁借了哪本书？→ 当前数据不能回答；没有读者和副本之间的借阅事实。

## 扩展纪律与后续用途

借阅采用 `LoanEvent` 节点，关联读者、副本、借出/到期/归还时间；同一人多次借同一副本也必须能区分。采购和来源记录同样采用事件或记录节点，不在 L03 临时把 `authoredBy` 改为相反方向。

| 讲次 | 计划扩展 | 必须说明的转换或边界 |
|---|---|---|
| L02 | 类、公理、推理及完整本体作业 | 保留至少8类、6对象属性、10数据属性及关系特性和推理要求；当前未满足 |
| L03 | 查询与状态过滤 | 所需数据版本、显式/推理图、排序 |
| L04 | 来源记录、形状约束 | 来源附着层次；推理与数据校验分别验证 |
| L05 | 第二个虚构图书馆目录 | 源字段映射不同于实体同一性对齐 |
| L06 | 合作网络或主题网络 | 声明投影规则；本轮数据可导出林岚—梅雨、林岚—陈河两条无向合作边 |
| L07 | 链接预测数据划分 | 新增足量教学事实；不以这个微型图宣称模型性能；防止测试泄漏 |
| L08 | 节点特征、新作者等 | 特征维度；人为数字/训练所得；归纳图与训练图边界 |
| Extra1–3 | 采购属性图、合作社区、预约借还日志 | 与原始 RDF 数据保持可追踪映射；平台未运行须声明 |
