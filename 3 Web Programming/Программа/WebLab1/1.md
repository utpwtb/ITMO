在Helios上的文件结构：

```
~/
  httpd-root/
    conf/
      httpd.conf # тот самый httpd-helios.conf
    fcgi-bin/
      app.jar
    mutex-dir/ # оставить пустой
  
  .www/(web) # is mine
```

---

### 程序启动

1. 首先转移端口到本地：
   ssh -L 24888:localhost:24888 s407960@helios.cs.ifmo.ru -p 2222
2. 然后启动本地的HTTP服务器：
   cd httpd-root/conf
   httpd -f ~/httpd-root/conf/httpd-conf-template.conf -k start
3. 最后启动Jar文件：
   java -jar -DFCGI_PORT=24889 ~/httpd-root/fcgi-bin/WebLab1.jar
4. 打开浏览器输入+你自己在conf文件设定的端口号
   http://localhost:24888/
