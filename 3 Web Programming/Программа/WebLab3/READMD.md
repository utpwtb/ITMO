1. 为“Web 编程”课程第 3 次实验中的程序实现以下功能：
   * 实现一个 MBean，用于统计用户设置的总点数，以及未落入指定区域的点数。如果用户连续 3 次“未命中”，所开发的 MBean 应发送该事件的通知。
   * 实现一个 MBean，用于确定所得图形的面积。
2. 使用 JConsole 工具对程序进行监控：
   * 读取任务 1 中所开发的 MBean 类的指标。
   * 确定 JVM 的名称和版本、Java 虚拟机的供应商及其构建版本号。
3. 使用 VisualVM 工具对程序进行监控和分析：
   * 记录任务 1 中所开发的 MBean 类指标随时间变化的图表。
   * 确定消耗 CPU 时间百分比最高的线程名称。
4. 使用 VisualVM 工具以及 NetBeans、Eclipse 或 Idea IDE 中的分析器，定位并消除程序中的性能问题。根据问题的定位和解决结果，编写一份报告，报告中应包含以下信息：
   * 所发现问题的描述。
   * 解决所发现问题的途径描述。
   * 详细描述用于发现和定位问题的操作步骤（需附截图）。
   * 学生必须能够根据教师要求，重现问题查找和定位的过程。

**实验报告应包含：**

* 任务文本。
* 所开发的 MBean 类及相关类的源代码。
* JConsole 程序的截图及所读取的指标，以及监控结果的结论。
* VisualVM 程序的截图及所读取的指标，以及分析结果的结论。
* VisualVM 程序的截图及查找内存泄漏过程中的评论。
* 实验结论。

**实验答辩问题：**

* 监控与分析。基本概念。监控与分析的差异。
* JDK 中用于组织监控和分析的基础设施。JMX。
* MBean。基本概念。框架架构。
* JConsole 工具。功能、应用范围。
* VisualVM 工具。功能、应用范围。
* Java 平台上应用程序的远程监控与分析。
