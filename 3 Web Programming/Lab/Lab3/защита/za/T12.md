# JPA技术：特点、API及集成

## **中文**

### **JPA核心特点**

- **官方标准**：Java的ORM规范，不是具体实现
- **统一API**：一套接口，多种实现（Hibernate/EclipseLink等）
- **注解驱动**：用 `@Entity`、`@Id`等注解定义映射
- **对象查询**：JPQL语言，操作对象而非SQL表

### **主要API**

```java
// 核心接口
EntityManagerFactory // 创建EntityManager的工厂
EntityManager        // 主要操作接口（增删改查）
EntityTransaction    // 事务管理
Query/TypedQuery     // 查询接口
```

### **与ORM提供者集成**

1. **配置指定**：在 `persistence.xml`中指定使用哪个实现
2. **标准兼容**：所有提供者都必须实现JPA标准接口
3. **扩展功能**：可通过 `unwrap()`访问特定提供者的高级功能

### **示例配置**

```xml
<persistence-unit name="myApp">
    <!-- 指定提供者 -->
    <provider>org.hibernate.jpa.HibernatePersistenceProvider</provider>
    <!-- 或: org.eclipse.persistence.jpa.PersistenceProvider -->
  
    <properties>
        <!-- 数据库连接 -->
        <property name="javax.persistence.jdbc.url" 
                  value="jdbc:mysql://localhost/mydb"/>
        <!-- 提供者特定配置 -->
        <property name="hibernate.show_sql" value="true"/> <!-- Hibernate -->
        <!-- 或: <property name="eclipselink.logging.level" value="FINE"/> -->
    </properties>
</persistence-unit>
```

## **Русский**

### **Ключевые особенности JPA**

- **Официальный стандарт**：Спецификация ORM для Java, а не конкретная реализация
- **Единый API**：Один набор интерфейсов, много реализаций (Hibernate/EclipseLink и др.)
- **Аннотационно-ориентированный**：Использование аннотаций `@Entity`, `@Id` для определения отображения
- **Запросы к объектам**：Язык JPQL, оперирует объектами, а не SQL-таблицами

### **Основные API**

```java
// Основные интерфейсы
EntityManagerFactory // Фабрика для создания EntityManager
EntityManager        // Основной рабочий интерфейс (CRUD)
EntityTransaction    // Управление транзакциями
Query/TypedQuery     // Интерфейс запросов
```

### **Интеграция с ORM-провайдерами**

1. **Конфигурация**：Указание реализации в `persistence.xml`
2. **Стандартная совместимость**：Все провайдеры реализуют стандартные интерфейсы JPA
3. **Расширенные функции**：Доступ к специфичным функциям через `unwrap()`

### **Пример конфигурации**

```xml
<persistence-unit name="myApp">
    <!-- Указание провайдера -->
    <provider>org.hibernate.jpa.HibernatePersistenceProvider</provider>
    <!-- или: org.eclipse.persistence.jpa.PersistenceProvider -->
  
    <properties>
        <!-- Подключение к БД -->
        <property name="javax.persistence.jdbc.url" 
                  value="jdbc:mysql://localhost/mydb"/>
        <!-- Специфичная конфигурация провайдера -->
        <property name="hibernate.show_sql" value="true"/> <!-- Hibernate -->
        <!-- или: <property name="eclipselink.logging.level" value="FINE"/> -->
    </properties>
</persistence-unit>
```

## **核心要点 / Основные моменты**

| 方面 / Аспект    | 说明 / Объяснение           |
| ---------------------- | ------------------------------------- |
| **JPA是规范**    | 定义"应该做什么"，不关心"怎么做"      |
| **提供者是实现** | Hibernate、EclipseLink等具体实现规范  |
| **代码可移植**   | 使用标准API，可在不同提供者间切换     |
| **配置是关键**   | `persistence.xml`决定使用哪个提供者 |

**一句话总结：JPA是Java持久化的"宪法"，各ORM框架是遵循这部宪法的"地方政府"。**
