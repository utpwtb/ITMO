| 设计模式       | 核心思想                                     | 在 Java Web 中的典型应用                                                |
| :------------- | :------------------------------------------- | :---------------------------------------------------------------------- |
| 责任链模式     | 将请求沿一条链传递，每个处理器都有机会处理。 | Filter（过滤器）。多个 Filter 形成一个链，依次处理请求和响应。          |
| 前端控制器模式 | 为所有请求提供一个统一入口和集中管理点。     | Spring MVC 的 DispatcherServlet。所有请求先到达它，再由它分发。         |
| MVC 模式       | 分离数据模型、视图显示和用户输入控制。       | JSP + Servlet + JavaBean 或 Spring MVC 框架的基础架构。                 |
| 模板方法模式   | 定义算法骨架，子类重写特定步骤。             | HttpServlet 类。定义了 service() 方法骨架，子类重写 doGet(), doPost()。 |
| 观察者模式     | 一个对象状态改变，自动通知所有依赖它的对象。 | 监听器。如 ServletContextListener，当应用启动或停止时得到通知。         |
|                |                                              |                                                                         |

| Паттерн проектирования       | Основная идея                                                                                                                                                            | Типичное применение в Java Web                                                                                                                                                        |
| :------------------------------------------------ | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Цепочка обязанностей** | Передача запроса по цепочке, где каждый обработчик имеет шанс его обработать.                                       | **Filter (Фильтры)**. Несколько фильтров образуют цепь для обработки запроса и ответа.                                               |
| **Front Controller**                        | Обеспечение единой точки входа и централизованного управления для всех запросов.                               | **DispatcherServlet в Spring MVC**. Все запросы сначала поступают к нему для дальнейшего распределения.                                 |
| **MVC**                                     | Разделение модели данных, представления и управления пользовательским вводом.                                    | Основа фреймворков like**JSP + Servlet + JavaBean** или **Spring MVC**.                                                                                                  |
| **Шаблонный метод**           | Определение каркаса алгоритма, позволяя подклассам переопределять определенные шаги.                      | Класс**HttpServlet**. Определяет каркас метода `service()`, подклассы переопределяют `doGet()`, `doPost()`.                                |
| **Наблюдатель**                  | При изменении состояния одного объекта автоматически уведомляются все зависящие от него объекты. | **Слушатели**. Например, `ServletContextListener`, который получает уведомление при запуске или остановке приложения. |
