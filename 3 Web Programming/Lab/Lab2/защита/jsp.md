
* **`<%%>`** 用于编写在 **`_jspService` 方法内部**的代码，用于**控制请求处理逻辑**。
* **`<%!%>`** 用于为**整个 Servlet 类**添加成员，用于**定义类的属性和方法**。

---

### 详细对比

| 特性                   | `<% %>` (脚本片段)                                                                                                   | `<%! %>` (声明)                                                                                                            |
| :--------------------- | :--------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------- |
| **翻译后的位置** | 在**`_jspService(HttpServletRequest, HttpServletResponse)`** 方法内部。                                        | 在**生成的 Servlet 类体** 中，作为类的成员。                                                                           |
| **本质**         | 局部变量、方法内的逻辑流控制（如 `if`, `for`）。                                                                   | 类的**成员变量**（实例变量）和**成员方法**。                                                                     |
| **变量生命周期** | 随着每个请求的开始和结束而创建和销毁。                                                                                 | 与 Servlet 实例的生命周期相同（通常从加载到卸载）。                                                                          |
| **线程安全**     | **是线程安全的**。因为每个请求都在 `_jspService` 方法中有自己的局部变量和栈帧。                                | **不是线程安全的**！因为多个线程（请求）会同时访问同一个实例变量。                                                     |
| **主要用途**     | 1. 处理业务逻辑。`<br>`2. 使用 `out` 打印内容。`<br>`3. 使用 `request`, `response`, `session` 等内置对象。 | 1. 定义需要**在多次请求间共享**的变量（计数器、共享配置）。`<br>`2. 定义**辅助方法**，供页面中的脚本片段调用。 |

| Характеристика                                      | `<% %>` (Скриптлет)                                                                                                                                                                                                                          | `<%! %>` (Декларация)                                                                                                                                                                                                                                                                                                                       |
| :---------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Место в скомпилированном коде** | Внутри метода**`_jspService(HttpServletRequest, HttpServletResponse)`**.                                                                                                                                                            | В**теле сгенерированного сервлет-класса** в качестве члена класса.                                                                                                                                                                                                                          |
| **Сущность**                                        | Локальные переменные, управление потоком выполнения внутри метода (например,`if`, `for`).                                                                                         | **Переменные-члены** класса (переменные экземпляра) и **методы-члены** класса.                                                                                                                                                                                                   |
| **Жизненный цикл переменной**        | Создается и уничтожается с началом и концом каждого запроса.                                                                                                                                         | Совпадает с жизненным циклом экземпляра сервлета (обычно от загрузки до выгрузки).                                                                                                                                                                                                 |
| **Потокобезопасность**                    | **Потокобезопасно**. Так как каждый запрос имеет свои собственные локальные переменные и стек-фрейм в методе `_jspService`.                            | **Непотокобезопасно!** Поскольку множество потоков (запросов) одновременно обращаются к одной и той же переменной экземпляра.                                                                                                             |
| **Основное назначение**                   | 1. Обработка бизнес-логики.`<br>`2. Использование `out` для вывода контента.`<br>`3. Использование встроенных объектов: `request`, `response`, `session`. | 1. Определение переменных, которые нужно**разделять между несколькими запросами** (счетчики, общие настройки).`<br>`2. Определение **вспомогательных методов** для вызова из скриптлетов. |

### 代码示例与解释

假设我们有一个 JSP 页面，需要统计访问次数。

#### 示例1：错误的使用 `<% %>` 作为计数器

```jsp
<%
    // 这是一个在 _jspService 方法内部的局部变量
    int count = 0;
    count++;
%>
<p>页面访问次数：<%= count %></p>
```

**结果与分析**：

* 每次刷新页面，显示的结果**永远是 1**。
* **原因**：`count` 是一个局部变量。每个请求到来时，JSP 容器都会在新的 `_jspService` 调用中重新创建 `count` 并初始化为 0，然后自增为 1。请求结束后，这个变量就销毁了。

#### 示例2：正确的使用 `<%! %>` 作为计数器

```jsp
<%!
    // 这是一个在 Servlet 类中的成员变量（实例变量）
    int memberCount = 0;
%>
<%
    memberCount++;
%>
<p>页面访问次数：<%= memberCount %></p>
```

**结果与分析**：

* 每次刷新页面，数字会**持续增加**（1, 2, 3...）。
* **原因**：`memberCount` 是一个成员变量。它在 Servlet 实例被创建时初始化（通常是在第一次请求该 JSP 时），并且其生命周期与 Servlet 实例相同。后续的所有请求都由**同一个 Servlet 实例**处理，因此访问的是**同一个** `memberCount` 变量。

**⚠️ 重要警告**：上面的例子2有**严重的线程安全问题**！如果多个用户同时访问，`memberCount++` 这个非原子操作会导致数据竞争，计数不准。在实际开发中，对于共享成员变量，必须使用同步机制（如 `synchronized` 块），或者使用 `AtomicInteger`。

#### 示例3：使用 `<%! %>` 声明方法

这是 `<%! %>` 一个非常实用且安全的用途。

```jsp
<%!
    // 这是一个在 Servlet 类中定义的辅助方法
    // 它接收一个字符串，返回一个格式化后的日期字符串
    public String formatDate(String pattern) {
        return new java.text.SimpleDateFormat(pattern).format(new java.util.Date());
    }
%>

<%
    // 在脚本片段中调用上面声明的方法
    String today = formatDate("yyyy-MM-dd HH:mm:ss");
%>
<p>当前时间是：<%= today %></p>
```

**结果与分析**：

* 页面上会显示格式化的当前时间。
* **原因**：`formatDate` 方法被定义为生成的 Servlet 类的一个成员方法，因此可以在 `_jspService` 方法内部的脚本片段中调用它。这有助于将复杂的 Java 逻辑从页面表现中抽离出来，使 JSP 更整洁。

### 为什么需要两个标签？- 总结

1. **职责分离与生命周期管理**：

   * `<% %>` 负责处理**单个请求**范围内的逻辑。它的生命周期短暂，专注于“这次请求该怎么响应”。
   * `<%! %>` 负责定义**整个 Servlet 组件**的构成。它的生命周期长久，用于定义“这个页面组件本身具有什么属性和能力”。
2. **符合 Servlet 模型**：

   * JSP 最终就是一个 Servlet。`<%%>` 生成的是 `service()` 方法里的代码，而 `<%!%>` 生成的是类级别的代码。这两种代码在 Java 中本来就是存在于不同地方的，所以需要两种不同的标签来对应。
3. **功能互补**：

   * 如果没有 `<%! %>`，你就无法在 JSP 中方便地定义成员变量和方法，从而难以实现跨请求的状态共享和逻辑复用。
   * 如果没有 `<% %>`，你就无法在页面中嵌入灵活的逻辑控制流（如循环、条件判断）来动态生成 HTML。

**结论**：这两个标签不是为了重复功能而设计的，而是为了满足在将 JSP 翻译成 Servlet 时，代码需要被放置在不同位置（方法内还是类体内）的**根本性需求**。理解它们的区别，是编写正确、高效 JSP 代码的关键。在现代开发中，虽然纯 JSP 脚本已不推荐使用（被 JSTL/EL 取代），但理解其底层原理依然非常重要。
