# 🌿 CSS Наследование / CSS 继承

---

## 1️⃣ Что такое наследование?

### 什么是继承？

**🇷🇺 俄语说明：**

Наследование (inheritance) — это механизм, при котором дочерний элемент получает (наследует) некоторые свойства от своего родителя, если для этих свойств не указано собственное значение.

**🇨🇳 中文说明：**

CSS 的继承是指：如果某个元素没有为某个属性设置值，它就会从**父元素**那里“继承”这个属性的计算值（computed value）。

📘 **简单理解：**

> 子元素自动获得父元素的一部分样式。

---

## 2️⃣ Пример / 示例

```html
<div style="color: blue; font-family: Arial;">
  <p>这是段落文字（继承颜色和字体）</p>
</div>
```

**🇷🇺:** Здесь `<p>` не имеет своих свойств `color` и `font-family`, поэтому он **наследует** их от родителя `<div>`.

**🇨🇳:** `<p>` 没有设置 `color` 和 `font-family`，所以会**继承**父元素 `<div>` 的颜色和字体。

---

## 3️⃣ Какие свойства наследуются?

### 哪些属性会继承？

**🇷🇺:**

По умолчанию **только некоторые** свойства наследуются — в основном те, что связаны с текстом и шрифтами.

**🇨🇳:**

默认只有**部分属性**会继承，主要是和文字、排版相关的属性。

### ✅ **会继承的常见属性 / Наследуемые свойства:**

| Категория              | Свойства                                             | 中文含义   |
| ------------------------------- | ------------------------------------------------------------ | ---------- |
| Цвет текста           | `color`                                                    | 文字颜色   |
| Шрифты                    | `font-family`,`font-size`,`font-weight`,`font-style` | 字体相关   |
| Интервалы текста | `line-height`,`letter-spacing`,`word-spacing`          | 行高与字距 |
| Выравнивание        | `text-align`,`text-indent`                               | 对齐、缩进 |
| Видимость              | `visibility`                                               | 可见性     |
| Курсор                    | `cursor`                                                   | 鼠标样式   |

---

### ❌ **不会继承的属性 / Не наследуемые свойства:**

| Категория               | Свойства                            | 中文含义   |
| -------------------------------- | ------------------------------------------- | ---------- |
| Размер и отступы   | `margin`,`padding`,`width`,`height` | 盒模型尺寸 |
| Границы                   | `border`,`outline`                      | 边框       |
| Фон                           | `background`                              | 背景       |
| Позиционирование | `position`,`top`,`left`,`z-index`   | 定位属性   |
| Flex / Grid                      | `display`,`grid-template`               | 布局属性   |

---

## 4️⃣ Специальные ключевые слова

### 特殊关键字（控制继承）

CSS 提供了几个关键字，用来 **手动控制继承行为** 。

| Ключевое слово | 中文含义       | Описание / 说明                                      |
| --------------------------- | -------------- | ------------------------------------------------------------ |
| `inherit`                 | 继承父元素的值 | 强制从父元素继承，即使该属性默认不继承                       |
| `initial`                 | 初始值         | 使用 CSS 规范定义的初始默认值                                |
| `unset`                   | 自动判断       | 对继承属性等价于 `inherit`，对非继承属性等价于 `initial` |
| `revert`                  | 回退           | 恢复为浏览器默认样式或用户样式                               |

---

### 🔹 示例 / Пример

```css
button {
  color: inherit;   /* 继承父元素颜色 */
  background: initial; /* 使用默认背景 */
}
```

**🇷🇺:** Кнопка возьмёт цвет текста родителя, но фон вернётся к стандартному.

**🇨🇳:** 按钮会继承文字颜色，但背景恢复为默认。

---

## 5️⃣ Как принудительно наследовать?

### 如何“强制继承”

如果某个属性默认 **不会继承** ，但你希望它继承父元素的值，可以：

```css
.child {
  border: inherit;
  background-color: inherit;
}
```

**🇷🇺:** Теперь даже `border` и `background-color` будут унаследованы.

**🇨🇳:** 即使 `border`、`background-color` 默认不继承，也会被强制继承。

---

## 6️⃣ CSS 自定义属性与继承 / Пользовательские свойства (CSS Variables)

**🇷🇺:**

Пользовательские переменные CSS (напр. `--main-color`)  **всегда наследуются по умолчанию** .

**🇨🇳:**

CSS 自定义属性（如 `--main-color`） **默认会继承** ，这使它们非常适合用于主题或全局样式传递。

```css
body {
  --main-color: #1e90ff;
}

h1 {
  color: var(--main-color);
}
section {
  border-color: var(--main-color);
}
```

**➡️** `--main-color` 会从 `body` 继承到所有子元素。

---

## 7️⃣ Визуализация / 可视化理解

```
<body style="color: red">
 └── <div>
       └── <p>继承 color: red</p>
```

**🇷🇺:** Свойство `color` передаётся вниз по дереву элементов, пока не будет переопределено.

**🇨🇳:** `color` 会沿着 DOM 树向下传递，直到子元素自己定义了新值。

---

## 8️⃣ Пример полного кода / 完整示例

```html
<div class="parent">
  <p>普通继承属性：color</p>
  <button>非继承属性被强制继承</button>
</div>

<style>
.parent {
  color: green;
  border: 2px solid red;
}

button {
  border: inherit;  /* 强制继承边框 */
  color: inherit;   /* 强制继承文字颜色 */
  background: initial;
}
</style>
```

## 9️⃣ Основные выводы / 核心总结

| 🇷🇺 Пункт                                                                                          | 🇨🇳 要点                       |
| -------------------------------------------------------------------------------------------------------- | ------------------------------- |
| Только некоторые свойства наследуются по умолчанию.         | 只有部分属性默认继承。          |
| Можно использовать `inherit`, чтобы заставить наследование. | 可用 `inherit`强制继承。      |
| `initial`сбрасывает к начальному значению.                                | `initial`回到初始值。         |
| `unset`— умный гибрид: наследуемое →`inherit`, нет →`initial`.         | `unset`根据属性类型自动决定。 |
| Пользовательские свойства (`--var`) всегда наследуются.       | CSS 变量始终会继承。            |
