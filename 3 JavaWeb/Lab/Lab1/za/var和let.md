# ⚙️ Разница между `var` и `let` в JavaScript

# ⚙️ JavaScript 中 `var` 与 `let` 的区别

---

## 1️⃣ Определение

### 定义

**🇷🇺 (俄语)**

* `var` — старый способ объявления переменной (до ES6)。
* `let` — современный способ (с ES6, 2015 года)，рекомендуется использовать в новом коде。

**🇨🇳 (中文)**

* `var` 是早期（ES5 及以前）声明变量的关键字。
* `let` 是 ES6（2015）引入的新关键字，用来声明变量。

  👉 在现代 JavaScript 中，一般推荐用 `let`（或 `const`）。

---

## 2️⃣ Область видимости

### 作用域（Scope）

**🇷🇺:**

* `var` имеет **функциональную область видимости** — видна во всей функции。
* `let` имеет **блочную область видимости** — видна только внутри `{ ... }` блока。

**🇨🇳:**

* `var` 是 **函数作用域** ：在整个函数内有效。
* `let` 是 **块级作用域** ：只在最近的一对 `{}` 大括号中有效。

📘 **示例 / Пример:**

```js
function test() {
  if (true) {
    var x = 10;
    let y = 20;
  }
  console.log(x); // ✅ 10
  console.log(y); // ❌ ReferenceError: y is not defined
}
test();
```

👉 `var x` 在整个函数中都能访问；

👉 `let y` 只在 `if` 块中存在。

---

## 3️⃣ Hoisting / Поднятие

### 变量提升

**🇷🇺:**

Все объявления (`var`, `let`, `const`) поднимаются вверх области видимости,

но `var` инициализируется значением `undefined`,

а `let` существует в **временной мёртвой зоне** (TDZ — Temporal Dead Zone)。

**🇨🇳:**

`var` 和 `let` 都会“被提升（hoisting）”，

但区别是：

* `var` 提升后会被初始化为 `undefined`；
* `let` 也提升，但在声明之前 **不能使用** ，处于“暂时性死区（TDZ）”。

📘 **示例 / Пример:**

```js
console.log(a); // undefined （var 提升）
var a = 5;

console.log(b); // ❌ ReferenceError （let 提升但在 TDZ）
let b = 5;
```

---

## 4️⃣ Повторное объявление

### 是否允许重复声明

**🇷🇺:**

* `var` позволяет объявить одну и ту же переменную несколько раз。
* `let` запрещает повторное объявление в одной области видимости。

**🇨🇳:**

* `var` 在同一作用域内可以重复声明（但容易出错）。
* `let` 不允许重复声明。

📘 **示例 / Пример:**

```js
var name = "Ivan";
var name = "Olga"; // ✅ 允许重复声明

let age = 20;
let age = 25; // ❌ SyntaxError: Identifier 'age' has already been declared
```

---

## 5️⃣ Глобальная область

### 全局作用域绑定差异

**🇷🇺:**

Если `var` объявляется вне функции, оно **добавляется в объект `window`** (в браузере)。

`let` при этом создаёт переменную в глобальной области, но  **не добавляется в `window`** 。

**🇨🇳:**

在浏览器中：

* 使用 `var` 在全局定义的变量会成为 `window` 对象的属性；
* 使用 `let` 定义的不会。

📘 **示例 / Пример:**

```js
var a = 10;
let b = 20;

console.log(window.a); // 10 ✅
console.log(window.b); // undefined ❌
```

---

## 6️⃣ Циклы и замыкания

### 循环与闭包中的区别

**🇷🇺:**

В цикле `for` переменная `let` создаёт новую копию на каждой итерации,

а `var` — одну общую переменную для всех итераций。

**🇨🇳:**

在 `for` 循环中，`let` 每次循环都会创建一个新的作用域副本，

而 `var` 所有循环共享同一个变量。

📘 **示例 / Пример:**

```js
// 使用 var
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log('var i:', i), 100);
}
// 输出：var i: 3, var i: 3, var i: 3

// 使用 let
for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log('let j:', j), 100);
}
// 输出：let j: 0, let j: 1, let j: 2
```

👉 这是 `let` 非常重要的行为差异。

---

## 7️⃣ Поведение при удалении / 删除行为

**🇷🇺:**

Переменные, объявленные через `var`, можно удалить из `window` с помощью `delete`，

а `let` — нельзя。

**🇨🇳:**

`var` 声明的全局变量可以被 `delete` 删除（因为它是 `window` 的属性），

`let` 声明的全局变量则不能。

```js
var x = 10;
let y = 20;

console.log(delete x); // true ✅
console.log(delete y); // false ❌
```

## 8️⃣ Сравнение в таблице / 对比表格

| 特性 / Свойство | `var`                     | `let`                  |
| ----------------------- | --------------------------- | ------------------------ |
| 出现版本                | ES5（旧）                   | ES6（新）                |
| 作用域                  | 函数作用域 (function scope) | 块级作用域 (block scope) |
| 提升 (hoisting)         | 是，初始化为 `undefined`  | 是，但存在 TDZ           |
| 是否允许重复声明        | ✅ 允许                     | ❌ 不允许                |
| 是否绑定到 window       | ✅ 是                       | ❌ 否                    |
| 可删除性                | ✅ 可删除                   | ❌ 不可删除              |
| 循环行为                | 所有循环共享一个变量        | 每次循环独立作用域       |
| 推荐使用                | ❌ 不推荐                   | ✅ 推荐                  |
