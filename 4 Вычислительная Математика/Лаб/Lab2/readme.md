**2 任务的程序实现：**

**对于非线性方程：**

1. 所有数值方法（见表9）必须实现为独立的子程序/方法/类。
2. 用户从程序提供的方程中选择需要计算根（3-5个函数，包括超越函数）的方程。
3. 提供从文件或键盘输入初始数据（区间边界/根的初始近似值和计算误差）的功能，由最终用户选择。
4. 对初始数据进行验证。必须分析在输入的区间上是否存在根。如果区间上有多个根或者没有根，则输出相应信息。程序应对输入的错误数据做出反应。
5. 对于需要初始近似值的方法（牛顿法、单点弦截法、固定端点弦截法、简单迭代法），由程序计算选择初始近似值 x₀ (a或b)。
6. 对于简单迭代法，需在输入的区间上检验方法的充分收敛条件。
7. 提供将结果（求得的方程根、根处的函数值、迭代次数）输出到文件或屏幕的功能，由最终用户选择。
8. 组织输出函数图像，图像应完整显示整个研究区间。

**对于非线性方程组：**

1. 用户从程序提供的方程组中选择两个非线性方程的方程组（2-3个方程组）。
2. 组织输出函数图像。
3. 从键盘输入初始近似值。
4. 对于简单迭代法，检验充分收敛条件。
5. 组织输出未知向量：x₁, x₂。
6. 组织输出求得解所用的迭代次数。
7. 组织输出误差向量：|xᵢ⁽ᵏ⁾ - xᵢ⁽ᵏ⁻¹⁾|。
8. 验证非线性方程组解的正确性。
