**实验室工作第6号：**
**《常微分方程的数值解法》**

**实验室工作目的：** 使用数值方法求解常微分方程的柯西问题。
实验室工作的变体编号由ISU系统中小组名单上的编号决定。

**1. 工作执行顺序**

2. 在程序中，求解常微分方程的数值方法应以单独的类/方法/函数的形式实现。
3. 用户从程序提供的方程中选择形式为 `y′ = f(x, y)` 的常微分方程（不少于三个方程）。
4. 提供从键盘输入初始数据的功能：初始条件 `y0 = y(x0)`，微分区间 `[x0, xn]`，步长 `h`，精度 `ε`。
5. 用于研究的方法应包含单步法和多步法（见表1）。
6. 对于程序中实现的所有方法，编制满足初始条件的微分方程近似积分值的表格。
7. 使用龙格法则评估单步法的精度。
8. 使用问题的精确解评估多步法的精度：**ε = max |y_i精确 - y_i|**，其中 `0 ≤ i ≤ n`。
9. 绘制精确解和所得近似解的图形（使用不同颜色）。
10. 程序必须在不同的数据集（包括不正确的数据）上进行测试。
11. 分析程序运行结果。

**2. 报告的要求和内容**

报告应包含以下部分：

* 标题页
* 工作目的
* 问题求解算法的描述
* 所用方法的工作公式
* 程序清单（至少包括所用方法的代码）
* 在不同初始数据下（不少于三组）程序运行结果的截图
* 精确解和所得近似解的图形
* 结论。

**3. 任务选项**

单步法：

1. 欧拉法
2. 改进的欧拉法
3. 四阶龙格-库塔法

多步法（预测-校正法）：

4. 亚当斯法
5. 米尔恩法
