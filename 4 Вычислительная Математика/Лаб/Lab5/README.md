**实验目的：** 解决插值问题，求出函数在给定自变量值（非节点处）的函数值。

实验由两部分组成：计算部分和编程部分。

实验作业的变体编号根据ISU（可能指学生信息系统）中的小组名单序号确定。

研究需使用：

* 拉格朗日多项式；
* 牛顿多项式；
* 高斯多项式。

**必做任务（最多85分）**

**计算任务实现：**

1. 从表1中选择根据变体指定的函数表 y = f(x)（表1.1 – 表1.5）；
2. 为给定的表格构建有限差分表。在报告中列出该表格；
3. 使用牛顿第一或第二插值公式，计算自变量 X1（见表1）处的函数值。注意确定应具体使用哪个公式；
4. 使用高斯第一或第二插值公式，计算自变量 X2（见表1）处的函数值。注意确定应具体使用哪个公式；
5. 使用拉格朗日多项式计算自变量 X1 和 X2 处的函数值；
6. 在报告中给出详细的计算过程。

**编程任务实现：**

1. 初始数据通过三种方式给定：
   a) 以数据集形式（x, y 表格），用户从键盘输入数值；
   b) 以文件中生成的数据形式（准备不少于三个测试变体）；
   c) 基于程序提供的所选函数（例如 sin x）。用户选择方程、研究区间以及区间内的点数（不少于两个函数）。
2. 构建并输出均差/有限差分表（取决于变体）；
3. 使用指定的方法（见表2）计算从键盘输入的自变量值的函数近似值。比较所得结果；

4. 绘制给定函数（标记插值节点）和牛顿/高斯插值多项式（用不同颜色）的图形；
5. 程序必须使用各种数据集（包括不正确的数据集）进行测试。
6. 分析程序运行结果。

**选做任务（最多15分）**

1. 在程序中实现使用斯特林公式计算从键盘输入的自变量值的函数值；
2. 在程序中实现使用贝塞尔公式计算从键盘输入的自变量值的函数值。
