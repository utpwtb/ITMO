## 实验室工作 3.02

## 电流源的特性

## 工作目的

1. 研究总功率、有用功率、损耗功率、外电路电压降以及电源效率与电路中电流强度的关系。
2. 求电源参数的值：电动势和内阻，并评估其误差。

## 引言

如果将一个具有内阻 r 的电流源（图 1）接入外电阻 R，那么根据闭合电路的欧姆定律，电源两端电压 U 可以表示为：

\[U = \mathcal{E} - Ir, \qquad (1)\]

其中 ε 是电动势，I 是电路中的电流强度。

<center>图 1. 实验室设备的原理电路图</center>

===== 第 2 页 =====

电压 U 随电流强度 I 变化的曲线图如图 2 所示。在理想情况下，该依赖关系的图形是一条直线：(a)。该直线与电压轴（I = 0）的交点位于 Θ = U 处，而与电流轴（U = 0）的交点则给出了电源的短路电流值 IK = r。

<center>图 2. 负载两端电压对电流强度的依赖关系图</center>

对于实际电源，在电流接近 IK 时，电压随电流强度变化的线性关系会被破坏（情况 (b)）。对于某些电源，这是由于在如此大的电流下电动势减小；对于另一些电源，是由于内阻增加；还有一些电源，则是这两个原因同时影响的结果。

将方程 (1) 的两边乘以流过电路的电流强度，并利用电路部分的欧姆定律 U = IR，我们得到以下关系式：

\[ \mathcal{E}I = I^2R + I^2r, \qquad (2) \]

它可以表示为：

\[ P = P_R + P_S, \qquad (3) \]

===== 第 3 页 =====

<center>图 3. 总功率 (P)、有用功率 (PR) 和损耗功率 (PS) 对电流强度的依赖关系。</center>

我们来研究这些功率随电流强度的变化关系。总功率对电流强度的依赖关系 P = εI 的图形（见图 3）是一条通过坐标原点的直线。根据(2)，有用功率可以表示为：

\[P_R = \mathcal{E}I - I^2r. \qquad (4)\]

这是一个二次函数，其图形是一条抛物线。容易求出使有用功率为零的电流强度值（即方程 (4) 的根）：

\[I_{1,2} = \begin{cases} I_K = \frac{\mathcal{E}}{r}; \\ 0. \end{cases} \qquad (5)\]

===== 第 4 页 =====

鉴于抛物线的对称性质，其顶点位于与根等距的位置：

\[I^* = \frac{I_1 + I_2}{2} = \frac{\mathcal{E}}{2r}. \qquad (6)\]

正是在这个电流强度值下，负载获得的有用功率达到最大：

\[P_{Rmax} = P_R(I^*) = \frac{\mathcal{E}^2}{4r}. \qquad (7)\]

注意，根据关系式 (6) 和全电路欧姆定律 I = R + r 可以得出，当 I = I* 时，满足等式 R = r，即当负载电阻等于电源内阻时，有用功率 PR 最大。这种负载称为与电源匹配的负载。

电源中的损耗功率也按二次规律依赖于电流强度：P S = I 2 r。该依赖关系的图形（见图 3）是一条顶点在坐标原点、开口向上的抛物线。在 r > 0 的物理意义明确的取值范围内，我们使用的是该抛物线的右支。

电流源的效率 (η) 是一个量，等于有用功率与电源总功率之比：

\[ \eta = \frac{P_R}{P} = \frac{U I}{\mathcal{E} I} = \frac{U}{\mathcal{E}}. \qquad (8) \]

将表达式 (1) 中的电压 U 代入 (8)，我们可以找到效率对电流强度的依赖关系：

\[ \eta = \frac{\mathcal{E} - I r}{\mathcal{E}} = 1 - \frac{I r}{\mathcal{E}}. \qquad (9) \]

从方程 (9) 可知，效率对电流强度的依赖关系是一条直线（图 4），从电流 I = 0 时的 η = 1 下降到电流强度 IK = r 时的 η = 0。

===== 第 5 页 =====

<center>图 4. 电源效率对电流强度的依赖关系</center>

这个电流值就是前面提到的“短路”电流。从(1)可知，当外电阻 R = 0 时，电流强度达到最大值，而有用功率 PR 降至零。在短路电流 I = IK 时，电源的总功率 P = εIK 和损耗功率 PS = I²r 达到最大值并且彼此相等：

\[P_{max} = P_{Smax} = \frac{\mathcal{E}^2}{r}. \qquad (10)\]

我们求一下在有用功率最大时的效率值以及功率 P, PR, PS 之间的关系。如前所述，有用功率在 R = r 时最大，此时的效率等于：

\[ \eta = \frac{U}{\mathcal{E}} = \frac{IR}{IR + Ir} = 50\%. \qquad (11) \]

因此，在最大电流 I = I* 时，有用功率等于 P R = 0,5P，并且考虑到(3)，有用功率等于损耗功率：P R = P S。

电压 U 对电流强度 I 的线性依赖关系特性，使得我们可以通过所谓的“短路和断路”方法来确定电源的参数。在一定范围内改变电阻 R，测量相应的电流强度和电压值。根据测量值绘制 U 对 I 的线性关系图。将其延长至与电压轴相交，得到“断路”电压 Ux = ε；延长至与电流轴相交，得到短路电流 IK。之后，电源电动势的内阻通过以下公式确定：

\[r = \frac{I_K}{\epsilon}. \qquad (12)\]

## 测量结果处理

1. 根据测量结果绘制 U(I) 关系图。目视确认其线性。
2. 使用任何一种寻找线性关系参数的标准方法（最小二乘法、成对点法），求出所得关系的参数：斜率 - 其绝对值对应于电源内阻 r；以及相对于坐标原点的偏移 - 其对应于电动势 ε。评估这些量的误差。将内阻值与其标称值进行比较。
3. 利用电压 U 和电流强度 I 的测量结果（见表 1）以及之前求出的 ε 和 r 值，计算并将有用功率 PR = UI、总功率 P = εI 以及损耗功率 PS = I²r 的值填入表中。
4. 绘制所有功率随电流强度变化的曲线图，并且将所有曲线绘制在同一个图形区域内。利用 PR = PR(I) 的关系图，求出有用功率达到最大值时的电流强度 I* 值。
5. 将 PRmax 和 I* 的值代入公式 PR = I²R，求出对应于负载和电源匹配模式下的电阻 R。将该电阻与电源内阻 r 进行比较。
6. 求出作为电流强度函数的效率值 η = P R，并绘制相应的曲线图，将其外推至与坐标轴相交。
7. 根据 η = η(I) 图，确定对应于 η = 0.5 的电流值 I*，并将其与第 4 点中得到的结果进行比较。
