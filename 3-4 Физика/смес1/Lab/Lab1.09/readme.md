**引言**

在描述刚体转动动力学时，使用了转动惯量的概念。物体的转动惯量——是刚体在旋转运动时的惯性度量。该物理量与物体进行平移运动时的质量概念类似。如果质量表征物体保持其线速度或抵抗其变化的特性，那么转动惯量则决定了在外力矩作用下物体角速度变化的快慢程度。对于由 n 个质点组成的系统，该概念的严格数学定义如下：相对于某轴的转动惯量称为标量物理量 I，等于各点质量 \( m_i \) 与它们到该轴距离平方的乘积之和：

\[I = \sum_{i=1}^n m_i r_i^2. \tag{1}\]

===== 第 3 页 =====

在质量连续分布在某刚体体积 \( V \) 内的情况下，计算转动惯量使用对整个体积的积分，而不是对系统元素的求和：

\[I = \int_V r_\perp^2 dm = \int_V \rho(\vec{r})r_\perp^2 dV, \tag{2}\]

其中 \(\rho(\vec{r})\) —— 在具有径矢量 \(\vec{r}\) 的点附近物体的密度值，而 \(dm = \rho dV\) —— 体积为 \(dV\) 的物体小微元的质量，该微元距所选轴的距离为 \(r_\perp\)。

转动惯量取决于质量在物体体积内的分布，并且是一个可加量，即物体相对于某轴的总转动惯量等于物体所有部分相对于同一轴的转动惯量之和。

在某些情况下，为求转动惯量，方便使用惠更斯-施泰纳定理，其表述如下：如果物体相对于通过质心的某旋转轴的转动惯量为 \(I_c\)，则相对于距离为 \(\ell\) 且与第一轴平行的任何其他轴，其转动惯量等于

\[I = I_c + m\ell^2, \tag{3}\]

其中 \(m\) 是物体的质量。

为了验证惠更斯-施泰纳定理，在本实验室工作中，当使用带有两个重物的水平杆系统或实心圆盘作为测量对象时，可以改变距离 \(\ell\)。

转动惯量的实验测定可以通过扭摆振动来完成——这是一个物体在弹性力作用下相对于某固定轴周期性地改变其角位置的过程。

===== 第 5 页 =====

为使系统偏离平衡位置，需要将研究对象转动某个角度 \(\varphi_0\)。此时螺旋弹簧也扭转相同的角度。弹簧产生恢复力矩 \(\vec{M}\)，试图使系统回到平衡状态。在此力矩作用下，系统增加其角速度并试图接近平衡位置，但由于惯性，它会以最大速度通过平衡位置并向相反方向偏离。随后，这个过程周期性地重复。这样就产生了弱阻尼的扭摆振动。在本实验室装置中，可以忽略耗散力的作用，并认为在最初几个振动周期内系统几乎没有能量损失。

刚体转动动力学的基本方程具有以下形式：

\[M = I \cdot \varepsilon, \tag{4}\]

其中 \(M\) —— 作用于物体上的合外力矩在旋转轴上的投影，\(I\) —— 物体的转动惯量，\(\varepsilon = \frac{d\omega}{dt}\) —— 其角加速度。

在螺旋弹簧发生弹性扭转的情况下，恢复力矩 \(M\) 与角度 \(\varphi\) 成正比：

\[M = -k \cdot \varphi, \tag{5}\]

其中 \(k\) —— 角刚度系数。\(k\) 的值由弹簧本身的参数（其几何尺寸和材料）决定。

考虑到（5）和角加速度的定义 \(\varepsilon = \frac{d^2\varphi}{dt^2}\)，方程

===== 第 6 页 =====

（4）变为：

\[\frac{d^2\varphi}{dt^2} + \frac{k}{I} \varphi = 0. \tag{6}\]

方程（6）描述了无阻尼简谐振动，其固有圆频率为 \(\omega = \sqrt{\frac{k}{I}}\)。其通解是函数

\[\varphi(t) = \varphi_0 \sin (\omega t + \theta_0), \tag{7}\]

其中 \(\varphi_0\) —— 振动振幅，\(\theta_0\) —— 振动的初相位；这两个量由振动过程的初始条件设定。振动周期由振动系统的固有参数 I 和 k 决定：

\[T = \frac{2\pi}{\omega} = 2\pi \sqrt{\frac{I}{k}}. \tag{8}\]

因此，确定转动惯量的工作公式为：

\[I = \frac{kT^2}{4\pi^2}. \tag{9}\]

参数 \(k\) 的数值可以通过测量为产生静态扭转角 \(\varphi\) 所需的外力矩 \(M\) 来实验确定。将杆固定在旋转轴上，并对其施加外力 \(F\)，方向垂直于旋转轴和杆本身。使用测力计确定力 \(F\) 的大小，并测量偏离角 \(\varphi\)。考虑到力矩的一般定义 \(M = r_\perp \cdot F\)，其中 \(r_\perp\) 是从旋转轴到力作用线的距离，我们得到角刚度系数的

===== 第 7 页 =====

工作公式

\[k = \left| \frac{M}{\phi} \right| = \left| \frac{r_{\perp} \cdot F}{\phi} \right|. \tag{10}\]

由于研究对象是“物体 + 杆”机械系统的一部分，因此为了获得物体本身的转动惯量 \(I_0\)，需要从 \(I\) 值中减去杆本身的转动惯量 \(I_{rod}\)，该值应单独求出：\(I_0 = I - I_{rod}\)。

在推导工作公式（9）时，假设系数 \(k\) 是某个常量，不依赖于弹簧的扭转角。但是，即使当方程（5）只是近似成立，且恢复力矩与弹簧扭转角之间的关系不是线性时，在恒定振幅的振动下，其周期的平方将与转动惯量成正比。让我们通过使用能量方法来考察扭摆振动过程来证明这一点。旋转物体的动能等于

\[E_K (\omega) = \frac{I \omega^2}{2}, \tag{11}\]

而弹簧变形的势能为：

\[E_P (\varphi) = \int_{0}^{\varphi} M(\hat{\varphi}) d\hat{\varphi}. \tag{12}\]

如果阻尼足够小，则在最初几个振动周期内，能量守恒定律成立：

\[E_K (\omega) + E_P (\varphi) = E = Const, \tag{13}\]

===== 第 8 页 =====

其中 _E_ 是振动系统的总机械能。从
（13）可以得到角速度
\(\omega\) 与旋转角 \(\varphi\) 之间的关系方程：

\[\omega (\varphi) = \sqrt{\frac{2 (E - E_P (\varphi))}{I}}. \tag{14}\]

通过计算物体从平衡位置转到极限（振幅）位置的时间来求振动周期：

\[T = 4 \int_0^{\varphi_0} \frac{d\varphi}{\omega (\varphi)} = 4 \int_0^{\varphi_0} \frac{d\varphi}{\sqrt{\frac{2 (E - E_P (\varphi))}{I}}}. \tag{15}\]

（15）中的被积表达式仅依赖于角度 \(\varphi\)，记 \(F\) 为其原函数，得到最终方程：
\[T = \sqrt{\frac{I}{2}} (F(\varphi_0) - F(0)). \tag{16}\]

括号中的差值仅取决于振动振幅，因此，在固定振幅下，振动周期的平方严格正比于旋转物体的转动惯量，与弹簧的弹性特性是否为线性无关。
