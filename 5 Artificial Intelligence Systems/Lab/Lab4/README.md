# Лабораторная работа № 4. Метод k ближайших соседей

Реализация kNN для классификации Wine и регрессии Diabetes. Модель и
метрики написаны на NumPy. Scikit-learn используется для загрузки данных
и разбиения выборок, Matplotlib используется для построения графиков.

## Файлы

- `src/experiment.py` запускает обе задачи. В `src/` также находятся
  класс KNN, метрики и функции визуализации.
- `results/wine/` и `results/diabetes/` содержат описательную статистику,
  разбиение, 12 валидационных оценок и результаты выбранной модели на тесте.
  Столбец `row` отсчитывается от нуля в исходном датасете.
- `report/main.pdf` содержит отчёт. `report/main.tex`, остальные файлы
  `.tex`, графики и шрифты входят в исходники отчёта. Листинги подключены
  напрямую из `src/`.
- [Контрольные вопросы](control_questions.md) с ответами на русском и китайском языках.

## Воспроизведение

Из каталога `Lab4`, используя Python 3.12:

```powershell
python -m pip install -r requirements.txt
python -B src/experiment.py
```

Датасеты входят в установленный пакет scikit-learn. Программа обновляет
CSV в `results/` и шесть графиков в `report/figures/`. Для записи в другие
каталоги можно указать `--results` и `--figures`.

Для сборки отчёта запустите XeLaTeX дважды из каталога `report`:

```powershell
xelatex -halt-on-error main.tex
xelatex -halt-on-error main.tex
```

Результаты, включённые в таблицы и текст отчёта, соответствуют запуску
со стандартными параметрами и фиксированными начальными состояниями
генератора случайных чисел 42 и 43.
