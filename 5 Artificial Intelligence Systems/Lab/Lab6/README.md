# Лабораторная работа 6 Распознавание рукописных цифр MNIST

Полносвязная сеть, градиенты, Adam и чтение IDX реализованы на NumPy и стандартной библиотеке Python. Сравниваются четыре архитектуры. Тестовая выборка используется для финальной оценки конфигурации и эпохи, выбранных по валидационной точности.

## Запуск эксперимента

В каталоге `Lab6` с Python 3.10 или новее выполните:

```text
python -m pip install -r requirements.txt
python -B src/experiment.py
```

Используются четыре оригинальных IDX-файла из [задания на Kaggle](https://www.kaggle.com/datasets/hojjatk/mnist-dataset). Они лежат в `data/mnist/` в формате gzip. Загрузчик также принимает распакованные файлы с именами из архива Kaggle. Обучение использует 12 эпох и фиксированные seed. Числа на последних знаках могут зависеть от версии NumPy и реализации BLAS.

## Демонстрация без обучения

```text
python -B src/inference.py data/drawings/2.png
```

Замените путь на свой рисунок одной цифры. Программа загружает `models/best_model.npz` и печатает класс и вероятности 0–9. Для защиты установите `jupyterlab`, запустите `python -m jupyterlab` из `Lab6`, откройте [defense.ipynb](defense.ipynb), задайте путь к изображению и выполните ячейки. В ноутбуке видны оригинал и вход модели после обработки.

## Состав работы

- `src/mnist.py` читает IDX, `src/network.py` реализует сеть и проверку градиентов, `src/experiment.py` выполняет обучение и оценку, `src/figures.py` строит графики, `src/inference.py` обрабатывает внешний рисунок.
- `data/drawings/` содержит три оригинальных цифровых эскиза по заданным вручную траекториям штрихов. Имена файлов задают истинные цифры.
- `models/` содержит веса модели D с эпохи 12. Валидационная точность составила 98,12 %, тестовая — 98,18 %.
- `results/` содержит распределения классов, журнал по эпохам, сводку архитектур, тестовые метрики, матрицу ошибок, внешние предсказания и итоговые иллюстрации. В CSV точность и вероятности выражены долями.
- [Отчёт PDF](report/main.pdf), [исходник LaTeX](report/main.tex) и [контрольные вопросы на русском и китайском](control_questions.md).

Для пересборки отчёта выполните `xelatex main.tex` дважды из каталога `report/`. Шрифты находятся в `report/fonts/`, рисунки подключаются из `results/`.
