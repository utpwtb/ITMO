| 中文 Chinese               | 俄语 Russian                                                                                          | 备注 / 用法                                                                                                         |
| :------------------------- | :---------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| **设/令**            | **Пусть**                                                                                  | 用于引入假设或定义变量。例如：**Пусть** \( \epsilon > 0 \).                                              |
| **已知**             | **Известно, что** / **Дано**                                               | 引用已知条件或公理。                                                                                                |
| **假设**             | **Предположим, что**                                                              | 引入一个假设，通常用于反证法或归纳法。                                                                              |
| **需要证明**         | **Требуется доказать**                                                         | 明确陈述需要证明的目标。                                                                                            |
| **证明**             | **Доказательство**                                                                | 用于开始正式的证明过程。                                                                                            |
| **因为**             | **Так как** / **Поскольку**                                                | 引出原因或已知条件。                                                                                                |
| **所以/因此/从而**   | **Следовательно** / **Таким образом** / **Поэтому** | **Следовательно** 最正式，最接近“从而”。**Таким образом** 意为“这样一来”。 |
| **由此得出**         | **Отсюда следует**                                                                 | 强调从前文直接推导出结论。                                                                                          |
| **如果...那么...**   | **Если ..., то ...**                                                                      | 标准的条件语句结构。                                                                                                |
| **当且仅当**         | **Тогда и только тогда, когда**                                           | 表达充要条件。                                                                                                      |
| **根据定义**         | **По определению**                                                                 | 依据定义进行推导。                                                                                                  |
| **另一方面**         | **С другой стороны**                                                              | 引入另一个角度或相反的论点。                                                                                        |
| **另一方面（补充）** | **С одной стороны**                                                                | 与“С другой стороны”搭配使用，表示“一方面...另一方面...”。                                        |
| **矛盾**             | **Противоречие**                                                                    | 用于反证法的结尾。                                                                                                  |
| **证毕**             | **Что и требовалось доказать (ч.т.д.)**                               | 放在证明结尾，表示证明完成。                                                                                        |
| **同理/类似地**      | **Аналогично**                                                                        | 表示类似的论证方法也适用于其他情况。                                                                                |
| **考虑**             | **Рассмотрим**                                                                        | 引导读者考虑一个特定的对象或情况。                                                                                  |
| **我们得到**         | **Получаем**                                                                            | 表示经过推导后得到了某个结果。                                                                                      |
| **这意味着**         | **Это означает, что**                                                             | 用于解释前一个结论的含义。                                                                                          |
| **综上所述**         | **В заключение** / **В итоге**                                           | 用于总结整个论证。                                                                                                  |
| **对于任意**         | **Для любого**                                                                         | 全称量词的表达。                                                                                                    |
| **存在**             | **Существует**                                                                        | 存在量词的表达。                                                                                                    |
| **使得**             | **Такой, что**                                                                          | 与“存在”连用，表示“存在一个...使得...”。**Существует** \( x \) **такой, что**...  |
| **成立**             | **Выполняется** / **Имеет место**                                    | 表示某个等式或关系式成立。                                                                                          |
