\section{Проверка на Helios}
Проверка выполнена 10 ноября 2026 года. Apache JMeter 5.6.3 запускался на Helios и обращался к Payara Micro по адресу \texttt{127.0.0.1:40797}. Приложение использовало persistence unit \texttt{movies-helios-test} и таблицы PostgreSQL с префиксом \texttt{lab2\_4101\_test\_}. Для записи применялись \texttt{READ COMMITTED}, блокировка строки AppState и проверка версии редактируемого или удаляемого объекта.

\subsection{Функциональная проверка}
Пройдены 17 HTTP-проверок. Они охватывают вход и независимость сеансов, CSRF, ограничения multipart-загрузки, синтаксис JSON и запрет назначения роли при регистрации. Обычный пользователь получил 404 при запросе чужой операции, администратор смог открыть ту же запись. Успешный импорт двух фильмов отразился в истории со счётчиком 2. Для отклонённого импорта сохранён статус FAILED с пустым счётчиком.

В отдельной проверке файл содержал корректный первый фильм и недопустимое значение \texttt{length=0} у второго. Сервер вернул HTTP 400 с путём \path{movies[1].length}. Число фильмов, людей, координат и мест осталось прежним, как и версия коллекции.
