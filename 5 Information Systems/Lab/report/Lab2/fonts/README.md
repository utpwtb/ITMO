# CMU fonts used by the report

The `.otf` files are Computer Modern Unicode fonts by Andrey V. Panov and contributors. Source: [CTAN cm-unicode](https://ctan.org/pkg/cm-unicode), version 0.7.0. They are distributed under the SIL Open Font License; the license text is included as `OFL.txt`.

The report uses CMU Serif for the main text and CMU Typewriter Text for Russian monospaced fragments.
