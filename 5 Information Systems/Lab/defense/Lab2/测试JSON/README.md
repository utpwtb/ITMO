# 实验二地点唯一性测试

地点的唯一键是 `name`、`x`、`y` 的组合。三个值都相同时，导入会复用已有地点，手动新建或改成已有地点则会被拒绝。

在网页的 **Импорт → Выбрать файл → Загрузить** 中依次上传以下文件。每次上传后可以在 **История импорта** 查看结果，在 **Места** 查看地点。

| 文件 | 预期结果 |
| --- | --- |
| `04-location-base.json` | 导入 1 部电影，导演 Анна 使用地点 `Парк (10, 20)`。 |
| `05-location-reuse.json` | 导入 1 部电影，导演 Борис 也使用 `Парк (10, 20)`。在 **Люди** 中能看到两位导演，在 **Места** 中只有一条 `Парк (10, 20)`。 |
| `06-location-different.json` | 导入 3 部电影。`Парк (10, 21)` 只改 `y`，`Сквер (10, 20)` 只改名称，`Парк (11, 20)` 只改 `x`，三条地点均可新增。 |

验证拒绝时，在 **Места** 手动添加名称 `Парк`、`x = 10`、`y = 20`。也可以编辑已有的 `Парк (10, 21)`，把 `y` 改成 `20`。两种操作都应显示 «Место с таким названием и координатами уже существует»，接口返回 `409 DUPLICATE_LOCATION`。

`location-crud.json` 是 `POST /movie-lab/api/locations` 的请求体。用网页测试时，直接把其中三个值填到 **Места** 的新增表单。
