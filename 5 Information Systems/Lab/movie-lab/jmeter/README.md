# Конкурентная проверка лабораторной работы № 2

В плане `lab2-concurrency.jmx` три сценария. Каждый поток получает отдельный сеанс и CSRF-токен. Перед целевым запросом потоки проходят барьер с тайм-аутом 20 секунд. Сценарий редактирования и удаления также проверяет исходную версию объекта. Параметры и данные передаются из `scripts/lab2-jmeter.py`.

| Сценарий | Потоки | Что проверяется |
|---|---:|---|
| C01 | 2 | Два администратора редактируют и удаляют один фильм с одной исходной версией. При победе редактирования проверяются новый слоган и версия. При победе удаления фильм больше не доступен. |
| C02 | 10 | Пользователи создают фильмы с одинаковым названием и идентификатором режиссёра. В каждом раунде сохраняется ровно один фильм с этим ключом. |
| C03 | 2 | Каждый файл сначала добавляет свой фильм, затем пытается добавить общий фильм. Проигравший получает конфликт на `movies[1].director`. Сохраняются только фильмы файла-победителя. Снимки PostgreSQL подтверждают отсутствие лишних связанных объектов. |

## Запуск на Helios

1. В каталоге `/home/studs/s407960/is-lab2-4101` подготовьте отдельные таблицы `lab2_4101_test_`. Для первого запуска используйте `python3.11 scripts/helios.py init-test`. Действующие тестовые таблицы можно использовать повторно.
2. Запустите экземпляр командой `env MOVIE_ISOLATION='READ COMMITTED' python3.11 scripts/helios.py start-test` и дождитесь готовности `http://127.0.0.1:40797/movie-lab/api/auth`. Рабочий экземпляр и тестовый экземпляр используют один PID-файл и порт. Скрипт проверяет активный persistence unit перед подготовкой данных.
3. Выполните `env MOVIE_TARGET=test python3.11 scripts/lab2-functional.py accounts`. Тестовые пароли находятся в закрытом файле `.runtime/lab2-users.json`. Ожидаемый путь JMeter 5.6.3 — `tools/apache-jmeter-5.6.3/bin/jmeter`, Java — `/usr/local/openjdk21`.

```sh
# Все три сценария, по 20 раундов
python3.11 scripts/lab2-jmeter.py verification/Lab2/my-run-01

# Короткая проверка создания дубликатов
env JMETER_ROUNDS=2 python3.11 scripts/lab2-jmeter.py verification/Lab2/my-pilot-01 C02
```

Для каждого запуска указывайте новый каталог. Скрипт сохраняет `summary.json`, `assertions.json`, JTL, HTML-отчёт, исходные ответы, входные данные и снимки PostgreSQL. Ответы 404/409 засчитываются только в ожидаемых ветвях. В C03 дополнительно проверяются путь ошибки, имена обеих сохранившихся записей, отсутствие остатков в четырёх таблицах и статусы истории для обоих файлов.

Валидацию полей и права на просмотр истории проверяет отдельный сценарий `lab2-functional.py`. Его следует запускать отдельно от JMeter, чтобы посторонние записи не повлияли на сравнение снимков.
