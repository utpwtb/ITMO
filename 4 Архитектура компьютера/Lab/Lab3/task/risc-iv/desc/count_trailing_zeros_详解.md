# RISC-IV 汇编程序：`count_trailing_zeros.s` 详细解释（嵌套过程版本）

## 程序功能

计算一个 32 位整数二进制表示中**尾部零（trailing zeros）**的个数，即从最低位开始连续 `0` 的数量。

| 输入 (n) | 二进制                                  | 尾部零个数 | 说明                 |
| -------- | --------------------------------------- | ---------- | -------------------- |
| 1        | `00000000 00000000 00000000 00000001` | 0          | 最低位是 1，无尾部零 |
| 2        | `00000000 00000000 00000000 00000010` | 1          | 最低 1 位是 0        |
| 16       | `00000000 00000000 00000000 00010000` | 4          | 最低 4 位是 0        |
| 0        | `00000000 00000000 00000000 00000000` | 32         | 特殊情况：全零       |

---

## 程序整体结构

本程序由**三个子程序**组成，体现了**嵌套过程调用**（nested procedure calls）：

```
_start                              (入口：I/O + 调度)
  │
  ├─ jal ra, count_trailing_zeros    ← 第 1 层调用
  │     │
  │     │  栈帧: sp-12, 保存 ra, s0, s1  (非叶函数)
  │     │
  │     └─→ ctz_loop:
  │            jal ra, is_bit_set    ← 第 2 层调用（嵌套）
  │              │
  │              │  纯寄存器操作  (叶函数，无需栈)
  │              └─→ jr ra
  │            bnez a0, done
  │            count++, n >>= 1
  │
  └─ sw a0, 输出端口
```

```
┌──────────────────────────────────────────────────────┐
│  .data  段                                          │
│    input_addr:  .word  0x80                         │
│    output_addr: .word  0x84                         │
├──────────────────────────────────────────────────────┤
│  .text  段                                          │
│    .org 0x200    ← 代码从 0x200 开始，避开 I/O 端口   │
│                                                     │
│    _start:                                          │
│      ① 初始化栈指针 sp = 0x1000                      │
│      ② 从内存映射 I/O (0x80) 读入 n → a0            │
│      ③ jal ra, count_trailing_zeros  ──────────────→│
│      ④ 将结果 a0 写入输出端口 (0x84)                 │
│      halt                                           │
│                                                     │
│    count_trailing_zeros:    ← 非叶函数               │
│      ⑤ 栈帧: sp -= 12, 保存 ra, s0, s1             │
│      ⑥ 循环: 调用 is_bit_set(n, 0) ────────────────→│
│      ⑦ 结果放入 a0                                  │
│      ⑧ 恢复 s0, s1, ra, sp += 12                   │
│      jr ra  ───────────────────────────────────────→│  返回 ④
│                                                     │
│    is_bit_set:              ← 叶函数（叶子）          │
│      ⑨ t0 = n >> bit                                │
│      ⑩ a0 = t0 & 1                                  │
│      jr ra ────────────────────────────────────────→│  返回 ⑥
└──────────────────────────────────────────────────────┘
```

## 内存布局

由于嵌套过程使代码段增大（从约 108 字节增至约 152 字节），原来从 `0x08` 开始的代码会延伸到 I/O 端口区域 `0x80` 造成冲突。因此使用 `.org 0x200` 将代码段上移，确保代码与 I/O 端口分离。

```
地址
0x0000 ┌──────────────────┐
       │ input_addr: 0x80 │  ← .data 段（2 个 .word = 8 字节）
0x0004 │ output_addr: 0x84│
       ├──────────────────┤
       │    (未使用)       │
0x0080 ├──────────────────┤  ← I/O 端口（memory_mapped_io）
       │  输入: 0x80      │     程序从 0x80 读入数据
0x0084 │  输出: 0x84      │     程序向 0x84 写入结果
       ├──────────────────┤
       │    (未使用)       │
0x0200 ├──────────────────┤
       │   _start         │  ← .text 段（从 0x200 开始）
       │   ...            │
0x0230 │ c_t_zeros        │  ← count_trailing_zeros
       │   ...            │
0x0288 │ is_bit_set       │  ← 叶函数
0x0298 ├──────────────────┤
       │    (未使用)       │
0x0FF4 │   栈: ra, s0, s1 │  ← sp 初始 = 0x1000
0x1000 └──────────────────┘      push 后 sp = 0x0FF4
```

## 逐段详解

### 1. 数据段（.data）

```assembly
input_addr:      .word  0x80
output_addr:     .word  0x84
```

- `input_addr`（地址 `0x00`）和 `output_addr`（地址 `0x04`）存放 I/O 端口常量
- 这两个地址是**内存映射 I/O**：读 `0x80` 获取输入，写 `0x84` 输出结果
- 程序使用 `lui`/`addi` 标准模式来获取这些地址指针，确保地址可以是任意 32 位值

### 2. 主入口（_start）

```assembly
    .text
    .org     0x200                   ; 代码从 0x200 开始，避免与 I/O 端口 0x80-0x87 冲突

_start:
    lui      sp, %hi(0x1000)         ; 栈指针 = 内存顶端
    addi     sp, sp, %lo(0x1000)
```

#### 2.1 加载输入并调用外层函数

```assembly
    lui      t0, %hi(input_addr)     ; t0 = &input_addr (= 0x00)
    addi     t0, t0, %lo(input_addr)
    lw       t0, 0(t0)               ; t0 = *input_addr = 0x80
    lw       a0, 0(t0)               ; a0 = n（参数放入 a0）

    jal      ra, count_trailing_zeros ; 调用：ra = pc+4, pc → count_trailing_zeros
```

`jal`（Jump And Link）指令的语义：

```
ra ← pc + 4       ; 保存返回地址（下一指令的地址）
pc ← target       ; 跳转到目标标签
```

调用示意：

```
          _start                       count_trailing_zeros
         ┌─────────────┐              ┌─────────────────────┐
         │  ...        │              │ addi sp, sp, -12    │
         │  jal ra,ctz │─────────────→│ sw ra, 0(sp)        │
         │  sw a0,0(t0)│← ra 指向这里  │ ...                 │
         │  halt       │              │ jr ra ──────────────┘
         └─────────────┘              └─────────────────────┘
```

#### 2.2 存储结果

```assembly
    lui      t0, %hi(output_addr)
    addi     t0, t0, %lo(output_addr)
    lw       t0, 0(t0)               ; t0 = 0x84
    sw       a0, 0(t0)               ; *0x84 = a0（结果）
    halt
```

### 3. 外层过程（count_trailing_zeros）—— 非叶函数

> **非叶函数** = 该函数内部还会调用其他函数。因此 `ra` 寄存器**必定**被内部调用覆盖，必须保存到栈上。

#### 3.1 栈帧创建（序言）

```assembly
count_trailing_zeros:
    addi     sp, sp, -12              ; 分配 12 字节栈帧
    sw       ra, 0(sp)                ; ┐ 保存返回地址
    sw       s0, 4(sp)                ; ├ 保存 callee-saved 寄存器
    sw       s1, 8(sp)                ; ┘
```

**为什么必须保存这三样？**

| 寄存器 | 用途                          | 保存原因                                                                       |
| ------ | ----------------------------- | ------------------------------------------------------------------------------ |
| `ra` | 返回地址                      | **必须**。本函数调用 `is_bit_set` 时 `jal` 会覆盖 `ra`，不保存则无法返回       |
| `s0` | 计数器（count）               | s0-s11 是 callee-saved 寄存器，被调用者有义务恢复原值；本函数用它暂存 count    |
| `s1` | 输入 n 的副本                 | 同上。`a0` 在每次调用 `is_bit_set` 时用作参数传入，不适合跨调用保存             |

栈帧布局：

```
高地址  0x1000 ─── 初始 sp
       ┌──────┐
       │      │
       │  ... │
       ├──────┤
       │  s1  │ ← sp+8   ── n 的副本（跨调用存活）
       ├──────┤
       │  s0  │ ← sp+4   ── 计数器
       ├──────┤
       │  ra  │ ← sp+0   ── 返回地址（jal is_bit_set 会覆盖 ra）
低地址  └──────┘ ← 分配后 sp = 0xFF4
```

#### 3.2 核心算法

```assembly
    beqz     a0, ctz_return_32       ; n == 0 → 直接返回 32

    mv       s1, a0                   ; s1 = n（跨调用保存的副本）
    addi     s0, zero, 0              ; s0 = count = 0

ctz_loop:
    mv       a0, s1                   ; arg0 = n
    addi     a1, zero, 0              ; arg1 = bit = 0（检查第 0 位）
    jal      ra, is_bit_set           ; ★★★ 嵌套调用！ra 被覆盖 ★★★

    bnez     a0, ctz_done             ; 如果 bit 0 = 1，结束循环
    addi     s0, s0, 1                ; count++
    addi     t0, zero, 1
    srl      s1, s1, t0               ; n >>= 1
    j        ctz_loop
```

算法以 n = 12（`1100₂`）为例：

```
迭代 1:  is_bit_set(12, 0) → (12>>0) & 1 = 0  → count=1, n = 12>>1 = 6
迭代 2:  is_bit_set(6, 0)  → (6>>0) & 1  = 0  → count=2, n = 6>>1  = 3
迭代 3:  is_bit_set(3, 0)  → (3>>0) & 1  = 1  → 循环结束
结果: count = 2 ✓
```

**关键点：** 每次循环迭代都是一次 `jal ra, is_bit_set` → `jr ra` 的完整过程调用链。

```
count_trailing_zeros:                    is_bit_set:
  ┌────────────────────┐                ┌───────────────────┐
  │ ctz_loop:          │                │ srl t0, a0, a1    │
  │   jal ra, is_bit ──┼───────────────→│ addi t1, zero, 1  │
  │   bnez a0, done  ←─┼── jr ra ───────│ and a0, t0, t1    │
  │   ...              │                └───────────────────┘
  └────────────────────┘
```

#### 3.3 栈帧释放（尾声）

```assembly
ctz_done:
    mv       a0, s0                   ; a0 = count（返回值）

    lw       s1, 8(sp)                ; 恢复 s1
    lw       s0, 4(sp)                ; 恢复 s0
    lw       ra, 0(sp)                ; 恢复 ra
    addi     sp, sp, 12               ; 释放栈帧
    jr       ra                       ; 返回调用者（_start）
```

释放是创建的严格逆序：

```
创建:  sp -= 12  →  sw ra(0), sw s0(4), sw s1(8)
释放:  lw s1(8), lw s0(4), lw ra(0)  →  sp += 12  →  jr ra
```

### 4. 内层过程（is_bit_set）—— 叶函数

> **叶函数**（leaf function）= 不再调用其他函数的函数。其 `ra` 不会被覆盖，因此**无需保存到栈上**。

```assembly
is_bit_set:
    srl      t0, a0, a1               ; t0 = n >> bit
    addi     t1, zero, 1              ; t1 = 1
    and      a0, t0, t1               ; a0 = (n >> bit) & 1
    jr       ra                       ; 直接返回
```

| 输入             | 含义                |
| ---------------- | ------------------- |
| `a0` (= `x10`) | 待检查的整数 n      |
| `a1` (= `x11`) | 要检查的位号 (0-31) |

| 输出 | 含义                                    |
| ---- | --------------------------------------- |
| `a0` | `0` = 该位为 0；`1` = 该位为 1 |

**为什么用 `t0`、`t1` 而非 `s0`-`s11`？** 因为 `t0-t6` 是临时寄存器（caller-saved），调用者不期望它们在子程序返回后仍保持原值，所以叶函数可以随意使用而无需保存/恢复。

---

## 叶函数 vs 非叶函数对比

本程序是展示二者区别的绝佳示例：

| 特性             | `is_bit_set`（叶函数）          | `count_trailing_zeros`（非叶函数）     |
| ---------------- | ------------------------------- | -------------------------------------- |
| 是否调用其他函数 | 否                              | 是（调用 `is_bit_set`）               |
| `ra` 会被覆盖    | 不会                            | 会（`jal ra, is_bit_set` 写入 ra）     |
| 必须保存 ra      | 否                              | **是**                                |
| 栈帧大小         | 0 字节                          | 12 字节（ra + s0 + s1）               |
| 使用的寄存器     | t0, t1（临时寄存器，无需保存）    | s0, s1（callee-saved，需保存恢复）      |
| 参数传递         | a0 = n, a1 = bit                | a0 = n（传入 a0，通过 s1 跨调用存活）  |
| 返回值           | a0 = 0 或 1                     | a0 = 0..32                            |

## 寄存器使用一览

| 寄存器         | 别名    | 用途                          | 在哪使用                | 约定                        |
| -------------- | ------- | ----------------------------- | ----------------------- | --------------------------- |
| `x0`         | `zero`| 硬连线零值                    | 全局                    | 只读                        |
| `x1`         | `ra`  | 返回地址                      | _start, ctz             | caller-saved                |
| `x2`         | `sp`  | 栈指针                        | _start, ctz             | 必须指向有效内存            |
| `x5`-`x7`  | `t0`-`t2` | 临时变量               | ctz, is_bit_set（移位、与运算） | caller-saved（跨调用不保留）  |
| `x8`         | `s0`  | 计数器（count）               | ctz                     | callee-saved（ctz 负责保存） |
| `x9`         | `s1`  | n 的副本                      | ctz                     | callee-saved（ctz 负责保存） |
| `x10`        | `a0`  | 第 1 参数 / 返回值            | 全局                    | caller-saved                |
| `x11`        | `a1`  | 第 2 参数（位号）             | ctz → is_bit_set       | caller-saved                |

## 调用约定总结

1. **参数传递**：前两个参数通过 `a0`、`a1` 传递
2. **返回值**：通过 `a0` 返回
3. **返回地址**：
   - `jal ra, label` — 将 `pc+4` 写入 `ra`，跳转到 `label`
   - `jr ra` — 将 `pc` 设为 `ra`，实现返回
4. **栈管理**：
   - 栈**向下增长**（高地址 → 低地址），`sp` 初始指向内存顶端
   - 函数在序言中递减 `sp` 分配栈帧，在尾声中递增 `sp` 释放
   - 分配和释放必须严格配对
5. **寄存器保存规则**：
   - **caller-saved**（`t0`-`t6`, `a0`-`a7`, `ra`）：调用者负责保存；子程序可随意修改
   - **callee-saved**（`s0`-`s11`, `sp`）：被调用者负责保存并在返回前恢复
6. **叶函数优化**：如果函数不再调用其他函数，则无需保存 `ra`（本程序中 `is_bit_set` 正是这种情况）
