# Acc32 指令集架构（ISA）文档

Acc32 ISA 是一个基于累加器的简单指令集，专为教育目的而设计。本文档概述了 Acc32 ISA 中可用的指令、它们的语法和语义。

## 架构概述

Acc32 架构是一个 32 位基于累加器的架构。其主要特点包括：

- 一个通用累加器寄存器（Acc）
- 两个状态标志：溢出（V）和进位（C）
- 内存映射 I/O
- 专注于累加器操作的简单指令集

该架构非常适合初学者理解计算机体系结构的基础知识，而无需面对多寄存器的复杂性。

Acc32 汇编代码中的注释以 `;` 字符表示。

## ISA 特定状态视图

- `Acc:dec`、`Acc:hex` —— `Acc` 寄存器。
- `V` —— 溢出标志。
- `C` —— 进位标志。

## 指令

指令大小：操作码 1 字节，绝对操作数 4 字节，相对操作数 2 字节。控制流、立即/间接/地址加载/存储使用绝对地址，其他指令使用相对地址。

### 数据传送指令

- **立即加载**

  - **语法：** `load_imm <address>`
  - **描述：** 将立即数加载到累加器中。
  - **操作：** `acc <- <address>`
- **加载**

  - **语法：** `load <offset>`
  - **描述：** 从相对地址加载值到累加器。
  - **操作：** `acc <- mem[pc + <offset>]`
- **存储**

  - **语法：** `store <offset>`
  - **描述：** 将累加器的值存储到相对地址。
  - **操作：** `mem[pc + <offset>] <- acc`
- **加载地址**

  - **语法：** `load_addr <address>`
  - **描述：** 从指定地址加载值到累加器。
  - **操作：** `acc <- mem[<address>]`
- **存储地址**

  - **语法：** `store_addr <address>`
  - **描述：** 将累加器的值存储到指定地址。
  - **操作：** `mem[<address>] <- acc`
- **间接加载**

  - **语法：** `load_acc`
  - **描述：** 以累加器中的值作为地址，从该地址加载值到累加器。
  - **操作：** `acc <- mem[acc]`
- **间接存储**

  - **语法：** `store_ind <address>`
  - **描述：** 将累加器的值存储到间接地址（即 `mem[<address>]` 所指向的地址）。
  - **操作：** `mem[mem[<address>]] <- acc`

### 算术指令

- **加法**

  - **语法：** `add <address>`
  - **描述：** 将指定地址的值与累加器相加。
  - **操作：** `acc <- acc + mem[<address>]`，并设置 `C` 和 `V` 标志。
- **减法**

  - **语法：** `sub <address>`
  - **描述：** 从累加器中减去指定地址的值。
  - **操作：** `acc <- acc - mem[<address>]`，并设置 `V` 标志。
- **乘法**

  - **语法：** `mul <address>`
  - **描述：** 将累加器与指定地址的值相乘。
  - **操作：** `acc <- acc * mem[<address>]`，并设置 `V` 标志。
- **除法**

  - **语法：** `div <address>`
  - **描述：** 将累加器除以指定地址的值。
  - **操作：** `acc <- acc / mem[<address>]`
- **取余**

  - **语法：** `rem <address>`
  - **描述：** 计算累加器除以指定地址的值的余数。
  - **操作：** `acc <- acc % mem[<address>]`
- **清除溢出**

  - **语法：** `clv`
  - **描述：** 清除溢出标志。
  - **操作：** `overflow <- 0`
- **清除进位**

  - **语法：** `clc`
  - **描述：** 清除进位标志。
  - **操作：** `carry <- 0`

### 位运算指令

- **左移**

  - **语法：** `shiftl <address>`
  - **描述：** 将累加器左移指定地址所指定的位数（不使用进位标志）。
  - **操作：** `acc <- acc << mem[<address>]`
- **右移**

  - **语法：** `shiftr <address>`
  - **描述：** 将累加器算术右移指定地址所指定的位数，保持符号位（不使用进位标志）。
  - **操作：** `acc <- acc >> mem[<address>]`
- **按位与**

  - **语法：** `and <address>`
  - **描述：** 将累加器与指定地址的值按位与。
  - **操作：** `acc <- acc & mem[<address>]`
- **按位或**

  - **语法：** `or <address>`
  - **描述：** 将累加器与指定地址的值按位或。
  - **操作：** `acc <- acc | mem[<address>]`
- **按位异或**

  - **语法：** `xor <address>`
  - **描述：** 将累加器与指定地址的值按位异或。
  - **操作：** `acc <- acc ^ mem[<address>]`
- **按位取反**

  - **语法：** `not`
  - **描述：** 将累加器按位取反。
  - **操作：** `acc <- ~acc`

### 控制流指令

- **跳转**

  - **语法：** `jmp <address>`
  - **描述：** 跳转到指定地址。
  - **操作：** `pc <- <address>`
- **等于零则分支**

  - **语法：** `beqz <address>`
  - **描述：** 如果累加器为零，则跳转到指定地址。
  - **操作：** `if acc == 0 then pc <- <address>`
- **不等于零则分支**

  - **语法：** `bnez <address>`
  - **描述：** 如果累加器不为零，则跳转到指定地址。
  - **操作：** `if acc != 0 then pc <- <address>`
- **大于零则分支**

  - **语法：** `bgt <address>`
  - **描述：** 如果累加器大于零，则跳转到指定地址。
  - **操作：** `if acc > 0 then pc <- <address>`
- **小于零则分支**

  - **语法：** `ble <address>`
  - **描述：** 如果累加器小于零，则跳转到指定地址。
  - **操作：** `if acc < 0 then pc <- <address>`
- **溢出则分支**

  - **语法：** `bvs <address>`
  - **描述：** 如果溢出标志被设置，则跳转到指定地址。
  - **操作：** `if overflow == 1 then pc <- <address>`
- **无溢出则分支**

  - **语法：** `bvc <address>`
  - **描述：** 如果溢出标志被清除，则跳转到指定地址。
  - **操作：** `if overflow == 0 then pc <- <address>`
- **进位则分支**

  - **语法：** `bcs <address>`
  - **描述：** 如果进位标志被设置，则跳转到指定地址。
  - **操作：** `if carry == 1 then pc <- <address>`
- **无进位则分支**

  - **语法：** `bcc <address>`
  - **描述：** 如果进位标志被清除，则跳转到指定地址。
  - **操作：** `if carry == 0 then pc <- <address>`
- **停机**

  - **语法：** `halt`
  - **描述：** 停止机器。
