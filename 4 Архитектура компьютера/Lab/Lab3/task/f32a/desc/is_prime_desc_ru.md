# Подробное описание программы demo2.s

## Обзор

`demo2.s` — это программа для проверки простых чисел, разработанная для архитектуры F32a. Программа считывает 32-битное целое число из адреса отображаемого ввода-вывода `0x80`, определяет, является ли оно простым числом, и записывает результат (1 означает простое число, 0 — не простое число) в адрес ввода-вывода `0x84`.

## Структура программы

Программа состоит из двух основных частей:

1. **Сегмент данных (.data)**: хранит глобальные переменные
2. **Сегмент кода (.text)**: хранит исполняемый код

---

## Подробное описание сегмента данных

```asm
    .data
.org 0x200

input_addr:   .word 0x80    ; адрес входного порта
output_addr:  .word 0x84    ; адрес выходного порта
divisor:      .word 0       ; хранение делителя (для функции mod)
n_store:      .word 0       ; хранение проверяемого числа n
i_store:      .word 0       ; хранение текущего делителя i
```

| Имя переменной | Адрес | Назначение                                                                                |
| --------------------------- | ---------- | --------------------------------------------------------------------------------------------------- |
| `input_addr`              | 0x200      | хранит адрес входного порта (0x80)                                          |
| `output_addr`             | 0x204      | хранит адрес выходного порта (0x84)                                        |
| `divisor`                 | 0x208      | временное хранение делителя, используемое функцией mod |
| `n_store`                 | 0x20C      | хранение проверяемого числа                                                |
| `i_store`                 | 0x210      | хранение текущего итерационного делителя                       |

## Подробное описание сегмента кода

### 1. Точка входа программы `_start`

```asm
_start:
    @p input_addr b!    ; загрузить значение input_addr (0x80) в регистр B
    @b                  ; считать данные из адреса, на который указывает регистр B (т.е. считать входное значение n из 0x80)

    dup                 ; дублировать n
    lit 1
    subtract            ; вычислить n - 1
    dup                 ; дублировать n - 1
    -if check_one       ; если n - 1 >= 0 (т.е. n >= 1), перейти к check_one
    drop drop           ; иначе (n < 1), удалить значения из стека
    lit -1              ; поместить -1
    @p output_addr b!   ; загрузить адрес вывода в B
    !b                  ; вывести -1 (метка ошибки)
    halt                ; останов
```

**Описание логики**:

- Сначала проверяется случай `n <= 1`
- Если `n <= 1`, происходит переход к `check_one` для дальнейшей проверки
- Если `n > 1`, выводится -1 (этот случай фактически не произойдёт, так как при `n - 1 > 0` условие `-if` не выполняется)

### 2. Проверка, равно ли n единице (`check_one`)

```asm
check_one:
    drop                ; удалить верхнее значение стека n - 1
    dup                 ; дублировать n
    lit 1
    subtract            ; вычислить n - 1
    dup                 ; дублировать n - 1
    if is_one          ; если n - 1 = 0 (т.е. n = 1), перейти к is_one
    drop                ; n == 1, удалить n - 1
  
    dup                 ; дублировать n (в данный момент n = 1)
    lit 2
    subtract            ; вычислить n - 2
    dup                 ; дублировать n - 2
    if is_two           ; если n - 2 != 0 (т.е. n != 2), перейти к is_two
    drop                ; n == 2, удалить n - 2
  
    dup                 ; дублировать n
    lit 1
    and                 ; вычислить n & 1 (проверка чётности)
    if is_even          ; если n & 1 != 0 (т.е. n нечётное), перейти к is_even
  
    loop_start ;        ; иначе (n чётное и n > 2), начать цикл проверки простых чисел
```

**Описание логики**:

- Проверка `n == 1`: 1 не является простым числом, вывод 0
- Проверка `n == 2`: 2 является простым числом, вывод 1
- Проверка чётности `n`: чётные числа (кроме 2) не являются простыми, вывод 0
- Если `n` — нечётное число больше 2, вход в основной цикл

### 3. Обработка граничных случаев

#### `is_one`: случай n = 1

```asm
is_one:
    drop drop           ; удалить значения из стека
    lit 0               ; вывести 0 (1 не является простым числом)
    @p output_addr b!
    !b
    halt
```

#### `is_two`: случай n == 2

```asm
is_two:
    drop drop           ; удалить значения из стека
    lit 1               ; вывести 1 (2 является простым числом)
    @p output_addr b!
    !b
    halt
```

#### `is_even`: случай чётного n

```asm
is_even:
    drop                ; удалить значения из стека
    lit 0               ; вывести 0 (чётные числа не являются простыми, кроме 2)
    @p output_addr b!
    !b
    halt
```

### 4. Основной цикл (`loop_start` и `loop_i`)

```asm
loop_start:
    !p n_store          ; сохранить n в n_store
  
    lit 3               ; начать проверку с i = 3
    loop_i ;            ; перейти к loop_i

loop_i:
    !p i_store          ; сохранить текущее i в i_store
  
    @p i_store          ; загрузить i
    dup                 ; дублировать i
    a!                  ; сохранить i в регистр A (для умножения)
    mul                 ; вычислить i * i
    @p n_store          ; загрузить n
    subtract            ; вычислить i² - n
    dup                 ; дублировать результат
    if not_prime        ; если i² == n, перейти к not_prime (n — полный квадрат, не простое число)
    -if is_prime        ; если i² - n >= 0 (т.е. i² >= n), перейти к is_prime (n — простое число)
  
    @p n_store          ; загрузить n
    @p i_store          ; загрузить i
    a!                  ; сохранить i в регистр A (для деления)
    mod                 ; вычислить n mod i
  
    dup                 ; дублировать остаток
    if not_prime        ; если остаток == 0, значит n делится на i, перейти к not_prime
  
    drop                ; остаток == 0, удалить остаток
    @p i_store          ; загрузить i
    lit 2
    +                   ; i += 2 (пропуск чётных)
    loop_i ;            ; продолжить следующую итерацию цикла
```

**Описание алгоритма**:

1. Начиная с `i = 3`, каждый раз увеличивая на 2 (проверяются только нечётные)
2. Вычисление `i²` и сравнение с `n`:
   - Если `i² == n`: n — полный квадрат, не простое число
   - Если `i² > n`: все возможные делители проверены, n — простое число
   - Если `i² < n`: продолжить проверку, делится ли n на i
3. Вычисление `n mod i`:
   - Если остаток равен 0: n делится на i, не простое число
   - Если остаток не равен 0: продолжить проверку следующего i

### 5. Вывод результата

#### `not_prime`: n делится на i

```asm
not_prime:
    drop
    lit 0               ; вывести 0 (не простое число)
    @p output_addr b!
    !b
    halt
```

#### `is_prime`: n — простое число

```asm
is_prime:
    lit 1               ; вывести 1 (простое число)
    @p output_addr b!
    !b
    halt
```

## Вспомогательные функции

### 1. Функция вычитания (`subtract`)

```asm
subtract:
    inv                 ; инвертировать верхнее значение стека (побитовое отрицание)
    lit 1
    +                   ; добавить 1 (реализация отрицания: -x = ~x + 1)
    +                   ; сложить результат со вторым значением стека
    ;
```

**Принцип работы**:

- `inv` выполняет побитовое отрицание верхнего значения стека
- `lit 1` и `+` реализуют добавление 1
- Последний `+` завершает вычитание: `a - b = a + (-b) = a + (~b + 1)`

**Изменение состояния стека**:

```
Перед вызовом: [a, b, ...]
inv:           [a, ~b, ...]
lit 1:         [a, ~b, 1, ...]
+:             [a, ~b + 1, ...]
+:             [a + (~b + 1), ...] = [a - b, ...]
```

### 2. Функция умножения (`mul`)

```asm
mul:
    dup                 ; дублировать множитель
    a!                  ; сохранить множитель в регистр A
    lit 0               ; инициализировать аккумулятор значением 0
  
    lit 31              ; установить счётчик цикла равным 31
    >r                  ; поместить счётчик в стек возврата
  
mul_loop:
    +*                  ; выполнить один микрошаг умножения
    next mul_loop       ; если R != 0, R-- и переход; иначе продолжить
  
    drop drop           ; очистка стека
    a                   ; результат находится в регистре A
    ;
```

**Описание инструкции `+*`**:
Инструкция `+*` — это микрошаг аппаратного умножения архитектуры F32a, выполняющий следующие операции:

1. Если младший бит A равен 1, то T = T + S
2. A и T сдвигаются вправо на один бит (младший бит T сдвигается в старший бит A)

**Пояснение к количеству циклов**:

- Поведение инструкции `next`: если R != 0, то R-- и переход; иначе извлечь из стека возврата и продолжить
- Установка R = 31, цикл выполняется 32 раза (первый раз без проверки, затем 31 проверка)

**Изменение состояния стека**:

```
Перед вызовом: [множимое, множитель, ...]
dup:           [множимое, множитель, множитель, ...]
a!:            [множимое, множитель, ...]  (A = множитель)
lit 0:         [множимое, множитель, 0, ...]
После цикла:   [множимое, множитель, старшая часть результата, ...]
drop drop:     [старшая часть результата, ...] (фактически не нужна)
a:             [произведение, ...]
```

### 3. Функция взятия остатка (`mod`)

```asm
mod:
    a                   ; сохранить  значение A (делитель) в верхнее стека 
    lit divisor b!      ; загрузить адрес divisor в B
    !b                  ; сохранить делитель в переменной divisor
  
    a!                  ; сохранить делимое в регистре A
  
    lit 0               ; инициализировать частное значением 0
    lit 0               ; инициализировать остаток значением 0
  
    lit 31              ; установить счётчик цикла
    >r                  ; поместить в стек возврата
  
mod_loop:
    +/                  ; выполнить один микрошаг деления
    next mod_loop       ; управление циклом
  
    drop                ; отбросить частное, оставить остаток
    ;
```

**Описание инструкции `+/`**:
Инструкция `+/` — это микрошаг аппаратного деления архитектуры F32a, выполняющий деление с восстановлением остатка:

1. Сдвинуть A влево на один бит в S
2. Попытаться выполнить S = S - делитель
3. Если результат отрицательный, восстановить S и установить бит частного в 0
4. Если результат неотрицательный, установить бит частного в 1

**Изменение состояния стека**:

```
Перед вызовом: [делимое, делитель, ...]
a:             [делимое, ...] (A = делитель)
После сохранения делителя: [делимое, ...]
a!:            [...] (A = делимое)
lit 0:         [0, ...]
lit 0:         [0, 0, ...]
После цикла:   [частное, остаток, ...]
drop:          [остаток, ...]
```

## Подробное описание инструкции `next`

`next` — это инструкция архитектуры F32a для реализации компактных циклов:

```
next <метка>
```

**Логика выполнения**:

1. Извлечь значение из стека возврата в R
2. Если R != 0:
   - R = R - 1
   - Поместить R обратно в стек возврата
   - Перейти к `<метка>`
3. Если R == 0:
   - Продолжить выполнение следующей инструкции

**Расчёт количества циклов**:

- Установка R = N, цикл выполняется N + 1 раз
- Для выполнения 32 раз `+*` или `+/`, нужно установить R = 31

```

  │
  ▼

  │
  ▼

  │
 Нет
  │
  ▼
n == 2? ──Да──> Вывод 1 (простое число)
  │
 Нет
  │
  ▼
n чётное? ──Да──> Вывод 0 (не простое число)
  │
 Нет
  │
  ▼
i = 3
  │
  ▼
┌─────────────────┐
│   Начало цикла  │
│ i² == n? ──Да──>│ Вывод 0
│      │          │
│     Нет         │
│      │          │
│ i² > n? ──Да──> │ Вывод 1 (простое число)
│      │          │
│     Нет         │
│      │          │
│ n mod i == 0?   │
│      │          │
│ Да ──┴──> Вывод 0 (не простое число)
│      │          │
│     Нет         │
│      │          │
│  i = i + 2      │
│      │          │
└──────┴──────────┘
```

**Преимущества**:

1. **Лаконичность кода**: с 32 строк до 4 строк
2. **Удобство поддержки**: изменение количества циклов требует изменения только одного числа
3. **Экономия пространства кода**: уменьшение требований к хранению программы

### Математическая оптимизация

1. **Проверка только нечётных чисел**: начиная с i = 3, каждый раз увеличивая на 2, пропуская все чётные числа
2. **Досрочное завершение**: остановка при i² > n, нет необходимости проверять до n-1
3. **Обработка граничных случаев**: быстрая обработка случаев n ≤ 2 и чётных чисел
