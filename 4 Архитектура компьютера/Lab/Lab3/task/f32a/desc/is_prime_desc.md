# demo2.s 程序详解

## 概述

`demo2.s` 是一个用于 F32a 架构的素数判断程序。该程序从内存映射 I/O 地址 `0x80` 读取一个 32 位整数，判断其是否为素数，并将结果（1 表示素数，0 表示非素数）写入 I/O 地址 `0x84`。

## 程序结构

程序分为两个主要部分：

1. **数据段 (.data)**: 存储全局变量
2. **代码段 (.text)**: 存储可执行代码

---

## 数据段详解

```asm
    .data
.org 0x200

input_addr:   .word 0x80    ; 输入端口地址
output_addr:  .word 0x84    ; 输出端口地址
divisor:      .word 0       ; 除数存储（用于 mod 函数）
n_store:      .word 0       ; 存储待检测的数 n
i_store:      .word 0       ; 存储当前除数 i
```

| 变量名          | 地址  | 用途                       |
| --------------- | ----- | -------------------------- |
| `input_addr`  | 0x200 | 存储输入端口地址 (0x80)    |
| `output_addr` | 0x204 | 存储输出端口地址 (0x84)    |
| `divisor`     | 0x208 | mod 函数使用的除数临时存储 |
| `n_store`     | 0x20C | 存储待检测的数             |
| `i_store`     | 0x210 | 存储当前迭代除数           |

## 代码段详解

### 1. 程序入口 `_start`

```asm
_start:
    @p input_addr b!    ; 将 input_addr 的值 (0x80) 加载到 B 寄存器
    @b                  ; 从 B 寄存器指向的地址读取数据（即从 0x80 读取输入值 n）

    dup                 ; 复制 n
    lit 1
    subtract            ; 计算 n - 1
    dup                 ; 复制 n - 1
    -if check_one       ; 如果 n - 1 >= 0（即 n >= 1），跳转到 check_one
    drop drop           ; 否则（n < 1），丢弃栈上的值
    lit -1              ; 压入 -1
    @p output_addr b!   ; 加载输出地址到 B
    !b                  ; 输出 -1（错误标记）
    halt                ; 停机
```

**逻辑说明**：

- 首先检查 `n <= 1` 的情况
- 如果 `n <= 1`，跳转到 `check_one` 进行进一步检查
- 如果 `n > 1`，输出 -1（这种情况实际上不会发生，因为 `n - 1 > 0` 时 `-if` 不跳转）

### 2. 检查 n 是否为 1 (`check_one`)

```asm
check_one:
    drop                ; 丢弃栈顶的 n - 1
    dup                 ; 复制 n
    lit 1
    subtract            ; 计算 n - 1
    dup                 ; 复制 n - 1
    if is_one          ; 如果 n - 1 = 0（即 n = 1），跳转到 is_one
    drop                ; n == 1，丢弃 n - 1
  
    dup                 ; 复制 n（此时 n = 1）
    lit 2
    subtract            ; 计算 n - 2
    dup                 ; 复制 n - 2
    if is_two           ; 如果 n - 2 != 0（即 n != 2），跳转到 is_two
    drop                ; n == 2，丢弃 n - 2
  
    dup                 ; 复制 n
    lit 1
    and                 ; 计算 n & 1（检查奇偶性）
    if is_even          ; 如果 n & 1 != 0（即 n 是奇数），跳转到 is_even
  
    loop_start ;        ; 否则（n 是偶数且 n > 2），开始素数检测循环
```

**逻辑说明**：

- 检查 `n == 1`：1 不是素数，输出 0
- 检查 `n == 2`：2 是素数，输出 1
- 检查 `n` 是否为偶数：偶数（除了 2）不是素数，输出 0
- 如果 `n` 是大于 2 的奇数，进入主循环

### 3. 边界情况处理

#### `is_one`: n = 1 的情况

```asm
is_one:
    drop drop           ; 丢弃栈上的值
    lit 0               ; 输出 0（1 不是素数）
    @p output_addr b!
    !b
    halt
```

#### `is_two`: n == 2 的情况

```asm
is_two:
    drop drop           ; 丢弃栈上的值
    lit 1               ; 输出 1（2 是素数）
    @p output_addr b!
    !b
    halt
```

#### `is_even`: n 是偶数的情况

```asm
is_even:
    drop                ; 丢弃栈上的值
    lit 0               ; 输出 0（偶数不是素数，除了 2）
    @p output_addr b!
    !b
    halt
```

### 4. 主循环 (`loop_start` 和 `loop_i`)

```asm
loop_start:
    !p n_store          ; 将 n 存储到 n_store
  
    lit 3               ; 从 i = 3 开始检测
    loop_i ;            ; 跳转到 loop_i

loop_i:
    !p i_store          ; 将当前 i 存储到 i_store
  
    @p i_store          ; 加载 i
    dup                 ; 复制 i
    a!                  ; 将 i 存入 A 寄存器（用于乘法）
    mul                 ; 计算 i * i
    @p n_store          ; 加载 n
    subtract            ; 计算 i² - n
    dup                 ; 复制结果
    if not_prime        ; 如果 i² == n，跳转到 not_prime（n 是完全平方数，不是素数）
    -if is_prime        ; 如果 i² - n >= 0（即 i² >= n），跳转到 is_prime（n 是素数）
  
    @p n_store          ; 加载 n
    @p i_store          ; 加载 i
    a!                  ; 将 i 存入 A 寄存器（用于除法）
    mod                 ; 计算 n mod i
  
    dup                 ; 复制余数
    if not_prime        ; 如果余数 == 0，说明 n 能被 i 整除，跳转到 not_prime
  
    drop                ; 余数 == 0，丢弃余数
    @p i_store          ; 加载 i
    lit 2
    +                   ; i += 2（跳过偶数）
    loop_i ;            ; 继续下一轮循环
```

**算法说明**：

1. 从 `i = 3` 开始，每次增加 2（只检查奇数）
2. 计算 `i²`，与 `n` 比较：
   - 如果 `i² == n`：n 是完全平方数，不是素数
   - 如果 `i² > n`：已经检查完所有可能的除数，n 是素数
   - 如果 `i² < n`：继续检查 n 是否能被 i 整除
3. 计算 `n mod i`：
   - 如果余数为 0：n 能被 i 整除，不是素数
   - 如果余数不为 0：继续检查下一个 i

### 5. 结果输出

#### `not_prime`: n 能被 i 整除

```asm
not_prime:
    drop
    lit 0               ; 输出 0（不是素数）
    @p output_addr b!
    !b
    halt
```

#### `is_prime`: n 是素数

```asm
is_prime:
    lit 1               ; 输出 1（是素数）
    @p output_addr b!
    !b
    halt
```

## 辅助函数

### 1. 减法函数 (`subtract`)

```asm
subtract:
    inv                 ; 将栈顶值取反（按位取反）
    lit 1
    +                   ; 加 1（实现取负：-x = ~x + 1）
    +                   ; 将结果与第二个栈顶值相加
    ;
```

**工作原理**：

- `inv` 对栈顶值进行按位取反
- `lit 1` 和 `+` 实现加 1
- 最后 `+` 完成减法：`a - b = a + (-b) = a + (~b + 1)`

**栈状态变化**：

```
调用前: [a, b, ...]
inv:    [a, ~b, ...]
lit 1:  [a, ~b, 1, ...]
+:      [a, ~b + 1, ...]
+:      [a + (~b + 1), ...] = [a - b, ...]
```

### 2. 乘法函数 (`mul`)

```asm
mul:
    dup                 ; 复制乘数
    a!                  ; 将乘数存入 A 寄存器
    lit 0               ; 初始化累加器为 0
  
    lit 31              ; 设置循环计数器为 31
    >r                  ; 将计数器压入返回栈
  
mul_loop:
    +*                  ; 执行一次乘法微步骤
    next mul_loop       ; 如果 R != 0，R-- 并跳转；否则继续
  
    drop drop           ; 清理栈
    a                   ; 结果在 A 寄存器中
    ;
```

**`+*` 指令说明**：
`+*` 是 F32a 的硬件乘法微步骤指令，执行以下操作：

1. 如果 A 的最低位为 1，则 T = T + S
2. A 和 T 都右移一位（T 的最低位移入 A 的最高位）

**循环次数说明**：

- `next` 指令的行为：如果 R != 0，则 R-- 并跳转；否则弹出返回栈并继续
- 设置 R = 31，循环执行 32 次（第一次不检查，然后检查 31 次）

**栈状态变化**：

```
调用前: [被乘数, 乘数, ...]
dup:    [被乘数, 乘数, 乘数, ...]
a!:     [被乘数, 乘数, ...]  (A = 乘数)
lit 0:  [被乘数, 乘数, 0, ...]
循环后: [被乘数, 乘数, 高位结果, ...]
drop drop: [高位结果, ...]（实际不需要）
a:      [乘积, ...]
```

### 3. 取模函数 (`mod`)

```asm
mod:
    a                   ; 将A值（除数）存入栈顶
    lit divisor b!      ; 将 divisor 地址加载到 B
    !b                  ; 将除数存储到 divisor 变量
  
    a!                  ; 将被除数存入 A 寄存器
  
    lit 0               ; 初始化商为 0
    lit 0               ; 初始化余数为 0
  
    lit 31              ; 设置循环计数器
    >r                  ; 压入返回栈
  
mod_loop:
    +/                  ; 执行一次除法微步骤
    next mod_loop       ; 循环控制
  
    drop                ; 丢弃商，保留余数
    ;
```

**`+/` 指令说明**：
`+/` 是 F32a 的硬件除法微步骤指令，执行恢复余数除法：

1. 将 A 左移一位到 S
2. 尝试 S = S - 除数
3. 如果结果为负，恢复 S 并设置商位为 0
4. 如果结果非负，设置商位为 1

**栈状态变化**：

```
调用前: [被除数, 除数, ...]
a:      [被除数, ...] (A = 除数)
存储除数后: [被除数, ...]
a!:     [...] (A = 被除数)
lit 0:  [0, ...]
lit 0:  [0, 0, ...]
循环后: [商, 余数, ...]
drop:   [余数, ...]
```

## `next` 指令详解

`next` 是 F32a 架构中用于实现紧凑循环的指令：

```
next <label>
```

**执行逻辑**：

1. 从返回栈弹出值到 R
2. 如果 R != 0：
   - R = R - 1
   - 将 R 压回返回栈
   - 跳转到 `<label>`
3. 如果 R == 0：
   - 继续执行下一条指令

**循环次数计算**：

- 设置 R = N，循环执行 N + 1 次
- 要执行 32 次 `+*` 或 `+/`，需要设置 R = 31
