# is_prime.s 程序详解

## 概述

本程序在 F32a 架构上实现质数判断功能。程序从内存映射 I/O 地址 `0x80` 读取输入整数 n，判断其是否为质数，并将结果（1 表示质数，0 表示非质数，-1 表示无效输入）写入地址 `0x84`。

## F32a 架构简介

F32a 是一种 32 位栈式处理器架构，主要特点：

- **数据栈**：用于运算和临时存储
- **返回栈**：用于子程序调用
- **寄存器**：A 寄存器（地址/数据）、B 寄存器（地址）
- **内存映射 I/O**：通过特定内存地址进行输入输出

## 程序结构

### 数据段 (.data)

```
.org 0x200

input_addr:   .word 0x80    # 输入端口地址
output_addr:  .word 0x84    # 输出端口地址
divisor:      .word 0       # 除法运算时存储除数
n_store:      .word 0       # 存储待检测的数 n
i_store:      .word 0       # 存储循环变量 i
```

数据段从地址 `0x200` 开始，定义了程序使用的变量。

### 代码段 (.text)

代码段从地址 `0x400` 开始。

## 主程序流程

### 1. 入口 (_start)

```
@p input_addr b!    # B = 0x80
@b                  # 从 0x80 读取 n，压入栈
```

首先设置 B 寄存器指向输入端口地址，然后读取输入值 n。

### 2. 边界检查

```
dup                 # [n, n]
lit 1               # [n, n, 1]
sub                 # [n, n-1]
dup                 # [n, n-1, n-1]
-if check_one       # 如果 n-1 >= 0，跳转到 check_one
```

这段代码检查 n 是否小于 1：
- 计算 `n - 1`
- `-if` 指令：如果栈顶值 >= 0 则跳转（注意：这是 F32a 的特殊语义）
- 如果 n < 1（即 n-1 < 0），继续执行，返回 -1

**关键点**：`-if label` 的语义是"如果 T >= 0 则跳转"，这与直觉相反！

### 3. 特殊值处理

#### check_one 标签

```
drop                # [n]
dup                 # [n, n]
lit 1               # [n, n, 1]
sub                 # [n, n-1]
dup                 # [n, n-1, n-1]
if not_one          # 如果 n-1 == 0（即 n==1），跳转到 not_one
drop                # [n]
loop_start ;        # 进入主循环
```

处理 n == 1 的情况：1 不是质数，输出 0。

#### not_one 标签

```
drop drop           # []
lit 0               # [0]
@p output_addr b!   # B = 0x84
!b                  # 输出 0
halt
```

### 4. 主循环 (loop_start 和 loop_i)

#### 循环初始化

```
loop_start:
    !p n_store      # 存储 n 到内存
    lit 2           # i = 2
    loop_i ;        # 开始循环
```

#### 循环体

```
loop_i:
    !p i_store      # 存储 i
    
    # 检查 i*i > n
    @p i_store      # [i]
    dup             # [i, i]
    a!              # [i], A = i
    mul             # [i*i]
    @p n_store      # [i*i, n]
    sub             # [i*i - n]
    dup             # [i*i - n, i*i - n]
    if check_equal  # 如果 i*i == n，跳转
    dup             # [i*i - n, i*i - n]
    -if is_prime    # 如果 i*i >= n，是质数
    drop            # []
```

**算法核心**：
- 循环变量 i 从 2 开始
- 当 `i * i > n` 时，n 是质数
- 当 `i * i == n` 时，n 是完全平方数，非质数
- 否则检查 `n % i == 0`

#### 整除性检查

```
    @p n_store      # [n]
    @p i_store      # [n, i]
    a!              # [n], A = i
    mod             # [n % i]
    
    dup             # [n%i, n%i]
    if not_prime    # 如果 n%i == 0，非质数
    
    # 继续循环
    drop            # []
    @p i_store      # [i]
    lit 1           # [i, 1]
    +               # [i+1]
    loop_i ;        # 继续
```

### 5. 结果输出

#### check_equal（完全平方数）

```
drop
lit 0
@p output_addr b!
!b
halt
```

#### not_prime（发现因子）

```
drop
lit 0
@p output_addr b!
!b
halt
```

#### is_prime（质数）

```
lit 1
@p output_addr b!
!b
halt
```

## 子程序

### 减法子程序 (sub)

```
sub:
    inv         # T = ~T（按位取反）
    lit 1       # 
    +           # T = T + 1（相当于 -T）
    +           # S = S + T = S - 原T
    ;
```

**原理**：利用补码计算 `S - T`
- `-T = ~T + 1`（补码表示）
- `S - T = S + (-T) = S + ~T + 1`

### 乘法子程序 (mul)

```
mul:
    dup             # [i, i]
    a!              # [i], A = i
    lit 0           # [i, 0]
    
    +* +* +* +* +* +* +* +*
    +* +* +* +* +* +* +* +*
    +* +* +* +* +* +* +* +*
    +* +* +* +* +* +* +* +*
    
    drop drop       # []
    a               # [A]
    ;
```

**`+*` 乘法步进指令**：

操作：`T <- T + (if A[0] then S else 0); A <- A >> 1; if T[0] then A[31] <- 1 else A[31] <- 0; T <- T >> 1`

这是硬件乘法的移位-加法实现：
- 初始状态：S = 乘数，T = 0，A = 被乘数
- 每次执行检查 A 的最低位，如果为 1 则将 S 加到 T
- A 右移，T 右移（结果从 T 移入 A 的高位）
- 执行 32 次后，结果在 A 寄存器中

**调用约定**：
- 入口：栈顶有 i，A = i
- 出口：栈顶有 i*i

### 取模子程序 (mod)

```
mod:
    a               # [dividend, divisor]
    lit divisor b!  # B = &divisor
    !b              # mem[divisor] = divisor
    
    a!              # A = dividend
    
    lit 0           # [0]
    lit 0           # [0, 0]
    
    +/ +/ +/ +/ +/ +/ +/ +/
    +/ +/ +/ +/ +/ +/ +/ +/
    +/ +/ +/ +/ +/ +/ +/ +/
    +/ +/ +/ +/ +/ +/ +/ +/
    
    drop            # [remainder]
    ;
```

**`+/` 除法步进指令**：

操作（恢复余数除法）：
1. `S <- S << 1`
2. `if A[31] then S[0] <- 1`
3. `A <- A << 1`
4. `T <- T << 1`
5. `if S >= mem[B] then S <- S - mem[B], T[0] <- 1`

- 初始状态：A = 被除数，mem[B] = 除数，S = 0，T = 0
- 执行 32 次后：S = 余数，T = 商

**调用约定**：
- 入口：A = 除数，栈顶有被除数
- 出口：栈顶有余数

## 关键技术点

### 1. 栈操作

F32a 是栈式机器，所有运算都在栈上进行：
- `dup`：复制栈顶
- `drop`：丢弃栈顶
- `over`：交换栈顶两个值

### 2. 条件跳转

- `if label`：如果 T == 0 则跳转（会弹出 T）
- `-if label`：如果 T >= 0 则跳转（会弹出 T）

**注意**：`if` 和 `-if` 都会弹出栈顶值！

### 3. 内存访问

- `@p addr`：从指定地址读取
- `!p addr`：写入指定地址
- `@b`：从 B 寄存器指向的地址读取
- `!b`：写入 B 寄存器指向的地址

### 4. 寄存器操作

- `a`：将 A 压入栈
- `a!`：将栈顶弹出到 A
- `b!`：将栈顶弹出到 B

---

## 算法复杂度

- 时间复杂度：O(√n) 次迭代
- 每次迭代：O(1) 次硬件指令（乘法和除法各 32 步）
- 总体：O(√n) 硬件指令
