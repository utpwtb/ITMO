# F32a 指令集架构 (ISA) 文档

F32a ISA 是一种基于栈的指令集，专为教育目的而设计。本文档概述了 F32a ISA 中可用的指令、它们的语法和语义。

## 架构概述

F32a 架构是一种受 Forth 系统启发的 32 位基于栈的架构。其特点包括：

- 两个主栈：数据栈和返回栈
- 两个通用寄存器：A 和 B
- 面向栈的操作，简化了许多编程任务
- 用于依赖进位操作的扩展算术模式 (EAM)
- 用于算术运算的进位标志
- 内存映射 I/O

这种基于栈的架构提供了与基于寄存器的架构不同的编程范式，非常适合理解替代计算模型。

F32a 汇编代码中的注释由 `\` 字符表示。

灵感来源于 [F18a](https://www.greenarraychips.com/home/documents/greg/DB001-221113-F18a.pdf)

## ISA 特定状态视图

- `A:dec`, `A:hex` -- `A` 寄存器。
- `B:dec`, `B:hex` -- `B` 寄存器。
- `T:dec`, `T:hex` -- 数据栈顶。
- `S:dec`, `S:hex` -- 数据栈中的第二个值。
- `R:dec`, `R:hex` -- 返回栈顶。
- `stack:dec`, `stack:hex` -- 整个数据栈。
- `rstack:dec`, `rstack:hex` -- 整个返回栈。
- `EAM` -- 扩展算术模式（启用时为 1，禁用时为 0）。
- `C` -- 进位标志（设置时为 1，清除时为 0）。

## 指令

指令大小：操作码为 1 字节，每个参数为 4 字节。

### 扩展算术模式 (EAM)

扩展算术模式 (EAM) 是一种允许使用进位位进行加法的模式。详见 `add` 指令说明。

### 进位标志

大多数指令会丢弃进位标志。例外情况：`add`, `dup`。

### 数据移动指令

- **立即数**

  - **语法:** `lit <value>`
  - **描述:** 将一个立即数压入数据栈。
  - **操作:** `dataStack.push(<value>)`
- **从地址读取**

  - **语法:** `@p <address>`
  - **描述:** 将指定地址的值压入数据栈。
  - **操作:** `dataStack.push(mem[<address>])`
- **读取**

  - **语法:** `@`
  - **描述:** 将寄存器 A 中地址所指向的值压入数据栈。
  - **操作:** `dataStack.push(mem[A])`
- **读取并自增**

  - **语法:** `@+`
  - **描述:** 将寄存器 A 中地址所指向的值压入数据栈，并将 A 自增 1。
  - **操作:** `dataStack.push(mem[A]); A <- A + 1`
- **读取 B**

  - **语法:** `@b`
  - **描述:** 将寄存器 B 中地址所指向的值压入数据栈。
  - **操作:** `dataStack.push(mem[B])`
- **存入地址**

  - **语法:** `!p <address>`
  - **描述:** 将数据栈顶的值存入指定地址。
  - **操作:** `mem[<address>] <- dataStack.pop()`
- **存入**

  - **语法:** `!`
  - **描述:** 将数据栈顶的值存入寄存器 A 中地址所指向的内存单元。
  - **操作:** `mem[A] <- dataStack.pop()`
- **存入并自增**

  - **语法:** `!+`
  - **描述:** 将数据栈顶的值存入寄存器 A 中地址所指向的内存单元，并将 A 自增 1。
  - **操作:** `mem[A] <- dataStack.pop(); A <- A + 1`
- **存入 B**

  - **语法:** `!b`
  - **描述:** 将数据栈顶的值存入寄存器 B 中地址所指向的内存单元。
  - **操作:** `mem[B] <- dataStack.pop()`
- **存入 A**

  - **语法:** `a!`
  - **描述:** 将数据栈顶的值存入寄存器 A。
  - **操作:** `A <- dataStack.pop()`
- **存入 B**

  - **语法:** `b!`
  - **描述:** 将数据栈顶的值存入寄存器 B。
  - **操作:** `B <- dataStack.pop()`
- **读取 A**

  - **语法:** `a`
  - **描述:** 将寄存器 A 的值压入数据栈。
  - **操作:** `dataStack.push(A)`

### 算术指令

- **加法**

  - **语法:** `+`
  - **描述:** 将数据栈顶的两个值相加。
  - **操作 (无 EAM):** `dataStack.push(dataStack.pop() + dataStack.pop()), 设置进位标志`
  - **操作 (EAM 模式):** `dataStack.push(dataStack.pop() + dataStack.pop() + carry), 设置进位标志`
- **乘法步进**

  - **语法:** `+*`
  - **描述:** 执行一个乘法步进操作。
  - **操作:** `T <- T + (if A[0] then S else 0); A <- A >> 1; if T[0] then A[31] <- 1 else A[31] <- 0; T <- T >> 1`
- **除法步进**

  - **语法:** `+/`
  - **描述:** 执行一个**恢复余数除法**的微步进操作。
    - 被除数 -- `A`
    - 除数 -- `mem[B]`
    - 部分余数 -- `S`
    - 部分商 -- `T`
  - **操作:**
    1. `S <- S << 1`
    2. `if A[31] then S[0] <- 1`
    3. `A <- A << 1`
    4. `T <- T << 1`
    5. `if S >= mem[B] then`
       - `S <- S - mem[B]`
       - `T[0] <- 1`
  - [**Python 示例**](https://github.com/ryukzak/wrench/blob/master/example/step-by-step-div.py)
- **左移**

  - **语法:** `2*`
  - **描述:** 将数据栈顶的值左移一位。
  - **操作:** `dataStack.push(dataStack.pop() << 1)`
- **右移**

  - **语法:** `2/`
  - **描述:** 将数据栈顶的值右移一位，保持符号（算术移位）。
  - **操作:** `dataStack.push(dataStack.pop() >> 1)`
- **按位取反**

  - **语法:** `inv`
  - **描述:** 将数据栈顶的值按位取反。
  - **操作:** `dataStack.push(~dataStack.pop())`
- **扩展算术指令**

  - **语法:** `eam`
  - **描述:** 从数据栈弹出一个值并设置 EAM 标志。
  - **操作:** `eam <- dataStack.pop()`

### 按位运算指令

- **按位与**

  - **语法:** `and`
  - **描述:** 对数据栈顶的两个值执行按位与运算。
  - **操作:** `dataStack.push(dataStack.pop() & dataStack.pop())`
- **按位异或**

  - **语法:** `xor`
  - **描述:** 对数据栈顶的两个值执行按位异或运算。
  - **操作:** `dataStack.push(dataStack.pop() ^ dataStack.pop())`

### 栈操作指令

- **丢弃**

  - **语法:** `drop`
  - **描述:** 移除数据栈顶的值。
  - **操作:** `dataStack.pop()`
- **复制**

  - **语法:** `dup`
  - **描述:** 复制数据栈顶的值。
  - **操作:** `dataStack.push(dataStack.top()), 进位标志不变`
- **覆盖**

  - **语法:** `over`
  - **描述:** 交换数据栈顶的两个值。
  - **操作:** `T <- dataStack.pop(); S <- dataStack.pop(); dataStack.push(T); dataStack.push(S)`

### 控制流指令

- **返回**

  - **语法:** `;`
  - **描述:** 从子程序返回。
  - **操作:** `p <- returnStack.pop()`
- **调用**

  - **语法:** `<label>`
  - **描述:** 调用指定标签处的子程序。
  - **操作:** `returnStack.push(p); p <- <label>`
- **跳转**

  - **语法:** `<label> ;`
  - **描述:** 跳转到指定标签。
  - **操作:** `p <- <label>`
- **循环**

  - **语法:** `next <label>`
  - **描述:** 循环到指定标签，同时递减 R。
  - **操作:**
    - `if R != 0 then`
      - `R <- R - 1`
      - `p <- <label>`
    - `else returnStack.pop()`
- **条件跳转 (零)**

  - **语法:** `if <label>`
  - **描述:** 如果数据栈顶的值为零，则跳转到指定标签。
  - **操作:** `if dataStack.pop() == 0 then p <- <label>`
- **条件跳转 (非负)**

  - **语法:** `-if <label>`
  - **描述:** 如果数据栈顶的值非负，则跳转到指定标签。
  - **操作:** `if dataStack.pop() >= 0 then p <- <label>`
- **停机**

  - **语法:** `halt`
  - **描述:** 停止机器。

### 寄存器操作指令

- **返回栈顶到数据栈**

  - **语法:** `r>`
  - **描述:** 将返回栈顶的值移动到数据栈。
  - **操作:** `dataStack.push(returnStack.pop())`
- **数据栈顶到返回栈**

  - **语法:** `>r`
  - **描述:** 将数据栈顶的值移动到返回栈。
  - **操作:** `returnStack.push(dataStack.pop())`
