# Wrench 文档

Wrench 是一个旨在探索不同类型处理器架构的教育项目。本文档说明了如何编写汇编代码和配置仿真，这些方法适用于所有支持的指令集架构（ISA）。

## 文件类型与格式

Wrench 使用多种类型的文件：

- **汇编文件**（扩展名 `.s`）——使用特定 ISA 汇编语言编写的源代码
- **配置文件**（扩展名 `.yaml`）——控制仿真参数的 YAML 文件
- **输出**——结果和报告输出到标准输出（stdout）

完整的工作程序示例请参见：

- [示例目录](/example)
- [测试 golden 目录](/test/golden)

## 支持的架构

Wrench 目前支持以下架构，每种架构都有其自己的指令集和语义：

- [Acc32](./acc32.md) —— 基于累加器的 32 位架构
- [F32a](./f32a.md) —— 基于栈的 32 位架构
- [M68k](./m68k.md) —— 受 Motorola 68000 启发的架构
- [RISC-IV](./risc-iv.md) —— 受 RISC-V 启发的 32 位架构
- [VLIW-IV](./vliw-iv.md) —— 受 RISC-V 启发的 VLIW 32 位架构

## 汇编程序结构

Wrench 中的汇编程序遵循一种通用的结构，无论使用哪种特定的 ISA。本节介绍所有汇编程序都应包含的通用组成部分。

汇编程序由**数据段**（包含变量、常量和其他数据）和**代码段**（指令）组成。这些段可以在文件中以任意顺序多次定义。汇编器会将同一类型的所有段合并为一个程序。所有汇编程序都应保存为扩展名为 `.s` 的文件。

### 注释

注释用于为代码添加解释性说明。注释字符可能因 ISA 而异：

- 大多数架构使用 `;` 表示注释
- 某些架构可能使用其他字符（请查阅特定 ISA 的文档）

注释字符之后同一行上的所有内容都会被汇编器忽略：

```assembly
    load_addr input_addr      ; 这是一个解释指令的注释
```

### 标签

标签用于标记代码或数据段中的特定位置。它们作为内存地址的符号名称，使代码更易读、更易维护。

- 标签由名称后跟冒号 `:` 定义
- 程序中定义的所有标签必须唯一
- 标签可以在指令或数据声明中用于引用内存位置

```assembly
loop_start:       ; 这定义了一个名为 "loop_start" 的标签
    instruction
    instruction
    jmp loop_start ; 跳回该标签
```

### 数据段

数据段用于定义程序使用的变量、常量和其他数据。它以 `.data` 伪指令开始。

数据段中的一行通常包含一个标签、一个伪指令和一个或多个值：

```assembly
label:    directive    value(s)
```

- **label**：标识符后跟冒号 `:`，标记该内存位置
- **directive**：指定所定义数据的类型和大小
- **value(s)**：要存储的实际数据（多个值可用逗号分隔）

常见的数据伪指令包括：

- `.word` —— 定义字大小的数据（通常为 32 位）
- `.byte` —— 定义字节大小的数据（8 位）

示例：

```assembly
.data
counter:        .word 0        ; 定义一个初始化为 0 的字大小变量
message:        .byte 'H', 'e', 'l', 'l', 'o', 0  ; 以空字符结尾的字符串
large_number:   .word 0xFFFFFFFF  ; 十六进制值
neg_one:        .word -1       ; 负值
c_string:       .byte 'Hello, World!\0'  ; 带空终止符的 C 风格字符串
pascal_string:  .byte 13, 'Hello, World!'  ; 带长度前缀的 Pascal 风格字符串
```

### 代码段

代码段包含程序的可执行代码（指令）。它以 `.text` 伪指令开始。

可用的特定指令取决于所使用的 ISA，但通用结构为：

```assembly
.text
label:                    ; 可选标签
    instruction operands  ; 指令及其操作数
    instruction operands
    ...
```

有关 ISA 特有的细节（指令、寄存器等），请参阅相应文档：

- [Acc32](./acc32.md) —— 基于累加器的架构
- [RISC-IV](./risc-iv.md) —— 受 RISC-V 启发的架构
- [F32a](./f32a.md) —— 基于栈的架构
- [M68k](./m68k.md) —— 受 Motorola 68000 启发的架构
- [VLIW-IV](./vliw-iv.md) —— 受 RISC-V 启发的 VLIW 32 位架构

如果在文档中找不到某些细节，[源代码](/src/wrench/Wrench/Isa) 包含了最新的信息。

### 设置段地址

`.org` 伪指令用于设置段的起始地址。当需要将代码或数据放在特定内存地址时非常有用：

```assembly
.data
.org 0x1000       ; 数据段从地址 0x1000 开始
value:  .word 42

.text
.org 0x2000       ; 代码段从地址 0x2000 开始
_start:
    load_ind value
```

如果未指定 `.org`，汇编器将从第一个段的地址 `0x0000` 开始自动分配地址，并将其他段顺序放置。

## 配置文件

Wrench 使用 YAML 配置文件（扩展名 `.yaml`）来控制仿真参数。这些文件允许您：

1. 设置执行限制
2. 定义输入/输出流
3. 配置内存
4. 生成和检查报告

### 配置文件结构

配置文件通常包含以下部分：

```yaml
# 执行限制
limit: 1000            # 最大执行指令数
memory_size: 8192      # 内存大小（字节）

# I/O 配置
memory_mapped_io:
  0x80: [5, 6, 7]      # 地址 0x80 的输入值
  0x84: []             # 地址 0x84 的仅输出端口

# 报告配置
reports:
  - name: "执行跟踪"
    slice: all
    view: |
      {pc}: {instruction} {pc:label}

  - name: "结果验证"
    slice: last
    view: |
      numio[0x84]: {io:0x84:dec}
    assert: |
      numio[0x84]: [] >>> [120]
```

### 配置选项

#### `limit`

- **类型：** 整数
- **描述：** 指定仿真可以执行的最大指令数。如果仿真超过此限制，将被终止。
- **命令行覆盖：** `--instruction-limit LIMIT` 设置该选项的上限。
- **示例：**

  ```yaml
  limit: 40
  ```

#### `memory_size`

- **类型：** 整数
- **描述：** 指定内存大小（字节）。
- **命令行覆盖：** `--memory-limit SIZE` 设置该选项的上限。
- **示例：**

  ```yaml
  memory_size: 40
  ```

#### `memory_mapped_io`

- **类型：** 十进制或十六进制地址到输入列表的映射
- **描述：** 定义仿真的内存映射 I/O 流。每个键是一个内存地址，值是一个列表，表示应馈送到该地址的输入。如果只定义输出端口，则将列表留空。
- **示例：**

  ```yaml
  memory_mapped_io:
    0x80: [5]  # 地址 0x80 的输入端口，值为 5
    132: []    # 地址 132（十进制）的仅输出端口
  ```

#### `reports`

- **类型：** 报告配置列表
- **描述：** 指定仿真期间要生成的报告。每个报告配置包括名称、切片、过滤器、检查器和断言等设置。
- **示例：**

  ```yaml
  reports:
    - name: 分步日志
      slice: all
      view: |
        {pc}: {instruction} {pc:label}
  ```

每个报告配置可以包含以下字段：

##### `name`

- **类型：** 字符串（可选）
- **描述：** 报告的名称，在生成的输出中用作标题。
- **示例：**

  ```yaml
  name: 分步日志
  ```

##### `slice`

- **类型：** 字符串或列表
- **描述：** 指定报告中应包含仿真记录的哪一部分。可能的值：

  - `"all"`：包含所有记录。
  - `["head", n]`：包含前 `n` 条记录。
  - `["tail", n]`：包含最后 `n` 条记录。
  - `"last"`：仅包含最后一条记录。
- **示例：**

  ```yaml
  slice: all
  ```

##### `view`

- **类型：** 字符串（模板）
- **描述：** 用于打印日志记录的文本模板。在模板中，可以使用花括号括起状态视图表达式。
- **示例：** `program counter: {pc}`

所有 ISA 通用的状态视图表达式：

- `pc:dec`、`pc:hex` —— 以十进制或十六进制格式打印程序计数器。
- `pc:label` —— 如果当前程序计数器对应一个标签，则打印 `@标签名`。
- `instruction` —— 打印当前指令。
- `memory:<a>:<b>` —— 打印地址 `<a>` 到 `<b>` 之间的内存转储。
- `io:<a>:dec`、`io:<a>:sym`、`io:<a>:hex` —— 以十进制、符号或十六进制格式打印特定地址的输入输出流状态。可打印字符代码：[32, 126]。`\0`、`\n` 会原样打印。其他不可打印字符将被替换为 `?`。

有关 ISA 特定的状态视图，请参阅相应的架构文档。

##### `assert`

- **类型：** 字符串（可选）
- **描述：** 指定仿真的预期最终状态。如果实际最终状态不匹配，将报告断言失败。
- **示例：**

  ```yaml
  assert: |
    numio[0x80]: [] >>> []
    numio[0x84]: [] >>> [120]
  ```
