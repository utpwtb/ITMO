 # 实验作业 No5 «函数插值»

**实验作业目标：** 解决插值问题，在给定自变量值（不同于节点值）的情况下求出函数值。

实验作业由两部分组成：计算部分和程序部分。作业变体编号按照ISU系统中的班级名单序号确定。

**研究需使用：** 
- 拉格朗日多项式；
- 牛顿多项式；
- 高斯多项式。

## 必做任务（最高85分）

### 计算实现：
1. 从表1中选择对应变体的表格 y=f(x)（表1.1–表1.5）；
2. 为给定表格构建有限差分表，并在报告中反映；
3. 使用牛顿第一或第二插值公式计算自变量 X1（见表1）的函数值，注意应使用哪个具体公式；
4. 使用高斯第一或第二插值公式计算自变量 X2（见表1）的函数值，注意应使用哪个具体公式；
5. 使用拉格朗日多项式计算自变量 X1 和 X2 的函数值；
6. 在报告中给出详细计算过程。

### 程序实现：
1. 原始数据通过三种方式输入：
   a) 以数据集形式（x,y表），用户从键盘输入数值；
   b) 以文件中形成的数据形式（准备不少于三个测试变体）；
   c) 基于程序提供的选定函数，例如 sin x。用户选择方程、研究区间和区间上的点数（不少于两个函数）。
2. 构建并输出差分/有限差分表（视变体而定）；
3. 使用指定方法（见表2）计算键盘输入的自变量值的函数近似值，比较所得结果；
4. 绘制给定函数的图像，标出插值节点和牛顿/高斯插值多项式（用不同颜色）；
5. 程序应在不同数据集上进行测试，包括不正确的数据；
6. 分析工作结果。
