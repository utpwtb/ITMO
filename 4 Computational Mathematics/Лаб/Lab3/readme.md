# 第3号实验室作业. 数值积分

**目的：** 使用各种数值方法，以要求的精度求出定积分的近似值。方案编号根据信息系统（ISU）中的班级名单序号确定。实验室作业由两部分组成：计算部分和编程部分。

## 必做任务（最高80分）

### 初始数据：

1. 用户从程序提供的函数（3-5个）中选择需要计算积分的函数。
2. 积分上下限由用户输入。
3. 计算精度由用户输入。
4. 积分区间初始分割数：n=4。
5. 初始数据通过键盘输入。

### 任务的程序实现：

1. 在程序中根据用户选择实现以下方法：
   * 矩形法（3种变体：左矩形、右矩形、中矩形）
   * 梯形法
   * 辛普森法
2. 这些方法应编写为独立的函数/类。
3. 函数值的计算应编写为独立的函数/类。
4. 使用龙格法则来估计误差并结束计算过程。
5. 程序需输出结果：积分值，以及为达到要求精度所需的积分区间分割数。

### 任务的计算实现：

1. 精确计算表1中给出的积分。
2. 使用 n=6 时的牛顿-柯特斯公式计算积分。
3. 使用 n=10 时的中矩形法、梯形法和辛普森法计算积分。
4. 将结果与积分的精确值进行比较。
5. 确定每种方法的计算相对误差。
6. 报告中需体现逐步计算的过程。

## 非必做任务（最高20分）

1. 判断所研究的第二类广义积分（2-3个函数）的收敛性。如果积分发散，则输出消息："积分不存在"。
2. 如果积分收敛，在程序中实现计算第二类广义积分（使用指定的数值方法）。
3. 考虑被积函数发生无穷间断的情况：1) 在 a 点，2) 在 b 点，3) 在积分区间内部。

## 实验报告撰写要求

报告应包含以下内容：

1. 封面页。
2. 实验目的。
3. 实验步骤。
4. 各方法的计算公式。
5. 程序代码清单。
6. 程序运行结果。
7. 指定积分的计算过程。
8. 结论。
