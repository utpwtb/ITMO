**选项 №397857：iPhone - https://www.iphones.ru/**

根据（所选选项）制定对正在开发的网站的要求列表。要求应分为以下几类：

* 功能要求。
  * 网站用户的要求。
  * 网站所有者的要求。
* 非功能要求。

要求必须按照 RUP 模板（SRS 文档 - 软件需求规格说明书）进行格式化。对于每个要求，需要指明其属性（根据 RUP 方法），并评估和论证实施该要求所需的大致小时数。

对于功能要求，需要绘制描述实现它们的用例的 UML UseCase 图。

实验报告应包含：

1. 软件需求规格说明书文档，包含网站的要求列表。
2. 实现功能要求的用例的 UseCase 图。
3. 实验结论。

实验答辩问题：

1. 软件开发方法论。统一过程。
2. 要求及其分类。要求属性。
3. UML 语言。
4. 用例。UseCase 图 - 组成、关系类型。


Составить список требований, предъявляемых к разрабатываемому веб-сайту (в соответствии с вариантом). Требования должны делиться на следующие категории:* Функциональные.

* Требования пользователей сайта.
* Требования владельцев сайта.
* Нефункциональные.

Требования необходимо оформить в соответствии с шаблонами RUP (документ SRS - Software Requirements Specification). Для каждого из требований нужно указать его атрибуты (в соответствии с методологией RUP), а также оценить и аргументировать приблизительное количество часов, требующихся на реализацию этого требования.

Для функциональных требований нужно составить UML UseCase-диаграммы, описывающие реализующие их прецеденты использования.

**Отчёт по лабораторной работе должен содержать:**

1. Документ Software Requirements Specification, содержащий список требований к сайту.
2. UseCase-диаграммы прецедентов использования, реализующих функциональные требования.
3. Выводы по работе.
