# Лекция 11. 线性回归分析 / Линейная регрессия

> **课程 (Курс):** Математическая статистика
> **来源 (Источник):** Лекция 11.pdf
> **主题:** 简单线性回归模型、最小二乘估计(МНК)、估计量性质、决定系数、贝叶斯回归

---

## 📋 本讲概览 (Обзор лекции)

本讲引入统计学中最重要的建模工具之一——**线性回归**。从实际场景（预测房价）出发，讲解了如何用一条直线来描述两个变量之间的关系。核心方法是最小二乘法（МНК），推导了参数 $\theta_0, \theta_1$ 的估计公式。

进一步讨论了估计量的统计性质（无偏性、方差、Gauss-Markov 定理、相合性），以及衡量模型解释力的决定系数 $R^2$。最后介绍了与经典频率学派不同的**贝叶斯回归方法**——将参数视为随机变量，通过先验分布与数据更新得到后验分布。

---

## 🎯 核心知识点 (Ключевые понятия)

### 知识点 1: 回归函数与线性回归模型 / Функция регрессии и линейная модель

**定义 (Определение):**
> **Функцией регрессии** случайной величины $Y$ на $X$ называется функция $E(Y \mid X = x)$, если соответствующее условное математическое ожидание существует.

> Модель **простой линейной регрессии:**
> $$Y_i = \theta_0 + \theta_1 X_i + \varepsilon_i, \quad i = 1, \ldots, n$$
> где $\theta_0, \theta_1$ — неизвестные параметры, $\varepsilon_i$ — случайные ошибки.

**中文解释:**
回归分析研究的是一个变量（因变量 $Y$）如何随另一个变量（自变量 $X$）的变化而变化。"回归"本质上是在寻找 $E(Y|X=x)$，即在给定 $X$ 的条件下 $Y$ 的平均值。

**经典线性模型的五个假设:**

| # | 假设 (Предположение) | 含义 |
|:--|:--|:--|
| (1) | 对参数线性 | $\theta_0, \theta_1$ 是线性的，$X$ 可以是 $X^2, \ln X$ 等 |
| (2) | 零条件均值 | $E(\varepsilon_i \mid X_i) = 0$，从而 $E(Y_i \mid X_i) = \theta_0 + \theta_1 X_i$ |
| (3) | 同方差性 | $D(\varepsilon_i \mid X_i) = \sigma^2 = \text{const}$ |
| (4) | 无自相关 | $\text{Cov}(\varepsilon_i, \varepsilon_j) = 0, \; i \neq j$ |
| (5) | 正态性 | $\varepsilon_i \mid X_i \sim N(0, \sigma^2)$ |

### 知识点 2: 最小二乘法 (МНК) / Метод наименьших квадратов

**定义 (Определение):**
> Оценки МНК минимизируют сумму квадратов вертикальных расстояний от точек до прямой:
> $$S = \sum_{i=1}^{n} (Y_i - \theta_0 - \theta_1 X_i)^2$$

**为什么用平方？** ① 对大误差惩罚更重（一个偏离 10 比两个偏离 5 更差）；② 对称性（正负偏离同等对待）；③ 平方函数光滑，容易求导。

**定理 (Теорема).** 最小化 $S$ 的估计量为：
$$\hat{\theta}_1 = \frac{\sum_{i=1}^{n} (X_i - \bar{X})(Y_i - \bar{Y})}{\sum_{i=1}^{n} (X_i - \bar{X})^2}, \quad \hat{\theta}_0 = \bar{Y} - \hat{\theta}_1 \bar{X}$$

**直觉解释:** $\hat{\theta}_1 = \frac{\text{cov}(X,Y)}{\text{var}(X)}$ — X 和 Y 如何一起变化，除以 X 自身的变化。

**推导 (Доказательство):**
对 $S(\theta_0, \theta_1)$ 求偏导数，令其为零，解正规方程组：
$$\begin{cases} \frac{\partial S}{\partial \theta_0} = -2\sum(Y_i - \theta_0 - \theta_1 X_i) = 0 \\ \frac{\partial S}{\partial \theta_1} = -2\sum X_i(Y_i - \theta_0 - \theta_1 X_i) = 0 \end{cases}$$

**公式等价变形:**
$$\hat{\theta}_1 = \frac{\frac{1}{n}\sum X_i Y_i - \bar{Y} \cdot \bar{X}}{\frac{1}{n}\sum X_i^2 - \bar{X}^2} = \frac{\sum(X_i - \bar{X})(Y_i - \bar{Y})}{\sum(X_i - \bar{X})^2}$$

---

### 知识点 3: 估计量的统计性质 / Свойства оценок МНК

估计量是随机变量，需要评估其质量。

**定理 (无偏性).** 在假设 (1)–(4) 下，OLS 估计量是无偏的：
$$E(\hat{\theta}_1) = \theta_1, \quad E(\hat{\theta}_0) = \theta_0$$

**推导思路:** 将 $\hat{\theta}_1$ 表示为 $\hat{\theta}_1 = \sum w_i Y_i$，其中 $w_i = \frac{X_i - \bar{X}}{S_{xx}}$。代入真实模型后取期望，利用 $\sum w_i = 0$ 和 $\sum w_i X_i = 1$ 即得。

**定理 (方差).** 在假设 (1)–(4) 下：
$$D(\hat{\theta}_1) = \frac{\sigma^2}{\sum_{i=1}^{n} (X_i - \bar{X})^2} = \frac{\sigma^2}{S_{xx}}$$
$$D(\hat{\theta}_0) = \sigma^2 \left( \frac{1}{n} + \frac{\bar{X}^2}{S_{xx}} \right)$$

**定理 (Gauss-Markov / Гаусса-Маркова).** 在假设 (1)–(4) 下，OLS 估计量 $\hat{\theta}_1$ 在所有线性无偏估计量中具有最小方差（BLUE — Best Linear Unbiased Estimator）。

**定理 (相合性 / Состоятельность).** 当 $\frac{1}{n}\sum(X_i - \bar{X})^2 \to Q > 0$ 时：
$$\hat{\theta}_1 \xrightarrow{P} \theta_1 \quad (n \to \infty)$$

**中文解释:**
- **无偏性:** 多次重复实验，估计量的平均值等于真实参数
- **有效性:** Gauss-Markov 定理保证 OLS 是最优线性无偏估计
- **相合性:** 样本量越大，估计越接近真值

## 📝 重要定理与结论 (Теоремы и выводы)

### 决定系数 $R^2$ / Коэффициент детерминации

**定义 (Определение):**
$$R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

где:
- $SST = \sum (Y_i - \bar{Y})^2$ — 总变差 (общая сумма квадратов)
- $SSR = \sum (\hat{Y}_i - \bar{Y})^2$ — 回归解释的变差 (объясненная)
- $SSE = \sum (Y_i - \hat{Y}_i)^2$ — 残差变差 (остаточная)

**分解恒等式:** $SST = SSR + SSE$

**性质:**
- $0 \leq R^2 \leq 1$
- $R^2$ 表示模型解释的 $Y$ 的方差比例

**解读指南:**

| $R^2$ | 解释 |
|:--|:--|
| 0.0 | 模型无用 |
| 0.3–0.5 | 中等相关 |
| 0.7–0.9 | 强相关 |
| 1.0 | 完美拟合 |

### 贝叶斯回归 / Байесовский подход

**核心区别:**

| | 频率学派 (Частотный) | 贝叶斯学派 (Байесовский) |
|:--|:--|:--|
| 参数 $\theta$ | 固定未知常数 | 随机变量 |
| 数据 $Y$ | 随机 | 固定（已观测） |
| 问题 | 给定参数，数据的概率？ | 给定数据，参数的概率？ |

**贝叶斯更新定理:**
$$P(\theta \mid Y, X) = \frac{P(Y \mid X, \theta) \cdot P(\theta)}{P(Y \mid X)}$$

即：**后验 ∝ 似然 × 先验**

**贝叶斯简单线性回归:**

假设先验 $\theta_0 \sim N(\mu_0^{(0)}, \sigma_0^2)$，$\theta_1 \sim N(\mu_0^{(1)}, \sigma_1^2)$，误差 $\varepsilon_i \sim N(0, \sigma^2)$。

后验分布 $\theta_1 \mid Y, X \sim N(\mu^{(1)}, \sigma_1^2)$，其中：
$$\mu^{(1)} = \sigma_1^2 \left( \frac{\mu_0^{(1)}}{\sigma_1^2} + \frac{S_{xy}}{\sigma^2} \right), \quad \frac{1}{\sigma_1^2} = \frac{1}{\sigma_1^2} + \frac{S_{xx}}{\sigma^2}$$

**贝叶斯方法的点估计:**
- 后验均值 $E(\theta \mid Y, X) = \mu^{(1)}$ — 最常用，最小化均方误差
- 后验众数 — 最可能值
- 后验中位数 — 对离群值稳健

**何时使用贝叶斯方法？**

| ✅ 适合 | ❌ 不适合 |
|:--|:--|
| 数据少但有先验知识 | 数据足够多（先验会被"遗忘"） |
| 需要完整的 uncertainty 分布 | 需要快速回答 |
| 做风险决策（需要概率） | 没有合理的先验 |
| 复杂模型（分层、缺失数据） | 简单解释比精度更重要 |
