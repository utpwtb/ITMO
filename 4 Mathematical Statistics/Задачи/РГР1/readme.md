## 附录 A. 理论参考

### A.1. 经验分布函数

设 \(X = (X_1, \ldots, X_n)\) 为样本，\(x = (x_1, \ldots, x_n)\) 为其实现值。

经验频数 \(\nu_n(x)\) —— 样本中小于 \(x\) 的元素个数。

经验分布函数定义为
\[
F_n(x) = \frac{\nu_n(x)}{n}.
\]

### A.2. 样本特征

样本均值：
\[
\overline{X} = \frac{1}{n} \sum_{i=1}^{n} X_i, \quad \overline{x} = \frac{1}{n} \sum_{i=1}^{n} x_i.
\]

样本方差（有偏）：
\[
S^2 = \frac{1}{n} \sum_{i=1}^{n} (X_i - \overline{X})^2, \quad S = \sqrt{S^2}.
\]

无偏样本方差（校正后）：
\[
\hat{\sigma}^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \overline{X})^2, \quad \hat{\sigma} = \sqrt{\hat{\sigma}^2}.
\]

（对数据进行计算时，将 \(x_i\) 代入 \(X_i\)，\(\bar{x}\) 代入 \(\overline{X}\)。）

### A.3. 直方图组距选择（示例）

* **斯科特规则**：\(h = 3.5 \, S \, n^{-1/3}\)。
* **弗里德曼–迪亚科尼斯规则**：\(h = 2 \, IQR \, n^{-1/3}\)，其中 \(IQR = q_{0.75} - q_{0.25}\)。
* **斯特吉斯规则**：\(k = 1 + \lfloor \log_2 n \rfloor\)。

### A.4. 矩法

思想：令理论值 \(EX\) 和 \(DX\) 等于相应的样本估计值，解关于参数的方程组。

### A.5. 最大似然法

设 \(f(x \mid \theta)\) 为密度函数（或概率函数）。似然函数：
\[
L(\theta) = \prod_{i=1}^{n} f(x_i \mid \theta), \quad \ell(\theta) = \ln L(\theta) = \sum_{i=1}^{n} \ln f(x_i \mid \theta).
\]
最大似然估计：\(\hat{\theta} = \arg \max_{\theta} L(\theta)\)（等价于 \(\arg \max_{\theta} \ell(\theta)\)）。

### A.6. 所用模型的估计公式

#### A.6.1. 正态分布 \(N(a, \sigma)\)

理论：\(EX = a\)，\(DX = \sigma^2\)。

**矩法**：\(\hat{a} = \bar{x}\)，\(\hat{\sigma}^2 = S^2\)（或 \(\hat{\sigma} = S\)）。

**最大似然法**：\(\hat{a} = \bar{x}\)，\(\hat{\sigma}^2 = S^2\)（或 \(\hat{\sigma} = S\)）。（通常还会与无偏估计 \(\hat{\sigma}^2\) 进行比较。）

#### A.6.2. 均匀分布 \(U(a, b)\)

理论：\(EX = \frac{a+b}{2}\)，\(DX = \frac{(b-a)^2}{12}\)。

**矩法**：
\[
\hat{a} = \bar{x} - \sqrt{3S^2}, \quad \hat{b} = \bar{x} + \sqrt{3S^2}.
\]

**最大似然法**：
\[
\hat{a} = \min\{x_1, \ldots, x_n\}, \quad \hat{b} = \max\{x_1, \ldots, x_n\}.
\]

#### A.6.3. 带位移的指数分布 \(Exp(\lambda, c)\)

这里 \(Exp(\lambda, c)\) 指具有如下密度的分布：
\[
f(x) = \lambda e^{-\lambda(x-c)}, \quad x \geq c, \quad \lambda > 0.
\]

理论：\(EX = c + \frac{1}{\lambda}\)，\(DX = \frac{1}{\lambda^2}\)。

**矩法**：
\[
\hat{\lambda} = \frac{1}{S}, \quad \hat{c} = \bar{x} - \frac{1}{\hat{\lambda}}.
\]

**最大似然法**：
\[
\hat{c} = \min\{x_1, \ldots, x_n\}, \quad \hat{\lambda} = \frac{1}{\bar{x} - \hat{c}}.
\]

### A.7. 基于分组数据的矩估计

设样本值范围被划分为 \(m\) 个区间，第 \(k\) 个区间内有 \(n_k\) 个观测值，\(\hat{X}_k\) 为第 \(k\) 个区间的中点。则估计值计算公式为：
\[
\hat{X}_g = \frac{1}{n} \sum_{k=1}^{m} n_k \hat{X}_k, \quad
\hat{\sigma}_g^2 = \frac{1}{n-1} \sum_{k=1}^{m} n_k (\hat{X}_k - \hat{X}_g)^2.
\]

### A.8. 置信区间

#### A.8.1. \(EX\) 的渐近置信区间

\[
EX \in \left( \bar{x} - z_{1-\alpha/2} \frac{\hat{\sigma}}{\sqrt{n}}, \; \bar{x} + z_{1-\alpha/2} \frac{\hat{\sigma}}{\sqrt{n}} \right).
\]

#### A.8.2. 正态分布参数的精确置信区间

如果 \(X_1, \ldots, X_n \sim N(\mu, \sigma^2)\)，则
\[
\frac{\overline{X} - a}{\hat{\sigma}/\sqrt{n}} \sim t_{n-1}, \quad
\frac{(n-1)\hat{\sigma}^2}{\sigma^2} \sim \chi_{n-1}^2,
\]
其中 \(\hat{\sigma}^2 = \frac{1}{n-1} \sum_{i=1}^{n} (X_i - \overline{X})^2\)。由此可得：
\[
a \in \left( \bar{x} - t_{1-\alpha/2, n-1} \frac{\hat{\sigma}}{\sqrt{n}}, \; \bar{x} + t_{1-\alpha/2, n-1} \frac{\hat{\sigma}}{\sqrt{n}} \right),
\]
\[
\sigma^2 \in \left( \frac{(n-1)\hat{\sigma}^2}{\chi_{1-\alpha/2, n-1}^2}, \; \frac{(n-1)\hat{\sigma}^2}{\chi_{\alpha/2, n-1}^2} \right).
\]
