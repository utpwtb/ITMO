## 4. 任务（必修部分）

### 4.1. 数据初步分析

对于您的变体，需要：

1. 加载包含原始数据的CSV文件；
2. 指明变体来自哪个真实数据集；
3. 如果使用切片，简要描述其获取规则；
4. 构建散点图 $(x_i, y_i)$；
5. 根据图表提出关于 $x$ 和 $y$ 之间关系形式和方向的假设。

### 4.2. 构建三个回归模型

为您的数据构建三个模型：

1. **线性模型**
   $$y = a + bx;$$

2. **二次模型**
   $$y = a + bx + cx^2;$$

3. **附加模型**，在变体卡片中指定：
   $$y = ae^{bx}, \quad y = ax^b, \quad y = a + b\ln x, \quad y = a + \frac{b}{x}$$
   
   *(仅使用其中一种模型——变体中指定的那种)。*

> **注。** 在估计某些模型的参数时，通过标准变量替换将其预先转换为线性形式是方便的。线性化所需的公式见附录。

对于每个模型，需要：

1. 找到参数估计值；
2. 写出最终的回归方程；
3. 在原始数据背景下构建模型图；
4. 获得预测值 $\hat{y}_i$。

### 4.3. 模型比较

对于构建的三个模型：

1. 计算决定系数 $R^2$；
2. 计算平均近似误差；
3. 分析残差图或模型与数据的偏差特征；
4. 得出结论，哪个模型更好地描述了观察到的依赖关系。

> **注。** 比较模型时，不仅要考虑 $R^2$ 的值，还要考虑模型的实质性意义以及残差的特征。

### 4.4. 线性模型的详细统计分析

对线性模型进行完整计算：

1. 找到系数估计值 $\hat{a}$ 和 $\hat{b}$；
2. 计算预测值 $\hat{y}_i$ 和残差 $e_i = y_i - \hat{y}_i$；
3. 计算残差平方和
   $$RSS = \sum_{i=1}^{n} e_i^2;$$
4. 计算误差方差的无偏估计
   $$s^2 = \frac{RSS}{n-2}, \quad s = \sqrt{s^2};$$
5. 构建线性回归系数的95%置信区间；
6. 检验假设
   $$H_0: b = 0, \quad H_1: b \neq 0$$
   关于 $x$ 的系数在显著性水平 $\alpha = 0.05$ 下的统计显著性；
7. 得出关于 $x$ 系数统计显著性的结论。

### 4.5. 预测与解释

对于变体卡片中给定的 $x^*$ 值：

1. 根据三个模型分别获得预测 $\hat{y}(x^*)$；
2. 指明您选择哪个模型作为主要预测模型；
3. 用学科领域的语言解释获得的结果。

### 4.6. 最终结论

在报告末尾总结工作的总体结果（7-12行）：

- 研究了哪个真实数据集；
- 研究了哪种依赖关系；
- 构建了哪些模型；
- 哪个模型更优及原因；
- 如何实质性地解释发现的依赖关系。

## 附录A. 理论参考

### A.1. 简单线性回归

考虑模型
$$Y_i = \theta_0 + \theta_1 X_i + \varepsilon_i, \quad i = 1, \ldots, n,$$

其中 $Y_i$ 为因变量，$X_i$ 为解释变量，$\theta_0, \theta_1$ 为未知参数，$\varepsilon_i$ 为随机误差。

随机变量 $Y$ 对 $X$ 的回归函数是指函数
$$m(x) = \mathrm{E}(Y \mid X = x),$$

如果相应的条件数学期望存在。

### A.2. 线性模型的最小二乘估计

设
$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i, \quad \bar{y} = \frac{1}{n}\sum_{i=1}^{n} y_i,$$
$$S_{xx} = \sum_{i=1}^{n}(x_i - \bar{x})^2, \quad S_{xy} = \sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y}).$$

则线性回归系数的估计值为
$$\hat{\theta}_1 = \frac{S_{xy}}{S_{xx}}, \quad \hat{\theta}_0 = \bar{y} - \hat{\theta}_1\bar{x}.$$

线性回归的最终方程：
$$\hat{y} = \hat{\theta}_0 + \hat{\theta}_1 x.$$

### A.3. 残差与误差方差估计

第 $i$ 个观测的残差：
$$e_i = y_i - \hat{y}_i.$$

残差平方和：
$$RSS = \sum_{i=1}^{n} e_i^2.$$

误差方差的无偏估计：
$$s^2 = \frac{RSS}{n-2}, \quad s = \sqrt{s^2}.$$

### A.4. 线性模型系数的置信区间

系数的标准误差：
$$SE(\hat{\theta}_1) = \frac{s}{\sqrt{S_{xx}}},$$
$$SE(\hat{\theta}_0) = s\sqrt{\frac{1}{n} + \frac{\bar{x}^2}{S_{xx}}}.$$

设 $t = t_{1-\alpha/2; n-2}$ 为Student分布的分位数。则95%置信区间为
$$\hat{\theta}_1 \pm t \cdot SE(\hat{\theta}_1), \quad \hat{\theta}_0 \pm t \cdot SE(\hat{\theta}_0).$$

如果系数 $\theta_1$ 的置信区间不包含零，则认为 $x$ 和 $y$ 之间的线性依赖在相应显著性水平下是统计显著的。

### A.5. 检验 $x$ 系数显著性的假设

检验线性模型斜率系数的统计显著性时，考虑假设
$$H_0: \theta_1 = 0, \quad H_1: \theta_1 \neq 0.$$

使用Student统计量
$$t_{\text{obs}} = \frac{\hat{\theta}_1}{SE(\hat{\theta}_1)},$$

在假设 $H_0$ 成立时，该统计量服从自由度为 $n-2$ 的Student分布。

在显著性水平 $\alpha$ 下，如果
$$|t_{\text{obs}}| > t_{1-\alpha/2; n-2}$$

则拒绝假设 $H_0$。

等价地，当且仅当零不包含在系数 $\theta_1$ 的置信区间内时，拒绝假设 $H_0$。

### A.6. 决定系数

总平方和：
$$TSS = \sum_{i=1}^{n}(y_i - \bar{y})^2.$$

决定系数：
$$R^2 = 1 - \frac{RSS}{TSS}.$$

$R^2$ 系数表示因变量的变异中有多少比例可以由构建的模型解释。

### A.7. РГР №3允许的模型

工作中使用以下模型类型：

| 模型 | 方程 |
|------|------|
| 线性： | $y = a + bx$ |
| 二次： | $y = a + bx + cx^2$ |
| 指数： | $y = ae^{bx}$ |
| 幂函数： | $y = ax^b$ |
| 半对数： | $y = a + b\ln x$ |
| 双曲线： | $y = a + \dfrac{b}{x}$ |

估计参数时，以下模型可以转换为线性形式：

- **指数模型：** $\ln y = \ln a + bx$；
- **幂函数模型：** $\ln y = \ln a + b\ln x$；
- **半对数模型** 已经具有 $y = a + b\ln x$ 的形式；
- **双曲线模型：** $y = a + bz$，其中 $z = 1/x$。

> **重要。** 使用转换时，必须注意变量的允许值域。例如，在指数和幂函数模型中，对数必须正确定义。

### A.8. 平均近似误差

作为模型质量的度量之一，可以使用平均相对近似误差
$$A = \frac{100\%}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right|,$$

前提是 $y_i$ 值非零。

4. 线性模型的统计显著性如何？
